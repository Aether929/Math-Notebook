# 概率空间与事件

> 概率论的公理化基础——Kolmogorov 公理体系。

## 1. 随机试验与样本空间

### 1.1 基本概念

**随机试验** $E$：满足以下条件的试验：
1. 可在相同条件下重复
2. 结果不止一个，且事先可知所有可能结果
3. 每次试验前无法确定具体结果

**样本空间** $\Omega$：随机试验所有可能结果的集合。

**样本点** $\omega$：$\Omega$ 中的元素。

**事件** $A$：$\Omega$ 的子集（$A \subseteq \Omega$）。

**推论 1.1**　必然事件 $= \Omega$，不可能事件 $= \emptyset$。

### 1.2 事件的运算

| 运算 | 含义 |
|------|------|
| $A \cup B$ | $A$ 或 $B$ 发生 |
| $A \cap B$ | $A$ 且 $B$ 发生 |
| $A \setminus B$ | $A$ 发生但 $B$ 不发生 |
| $A^c$ | $A$ 不发生 |
| $A \subseteq B$ | $A$ 发生必导致 $B$ 发生 |

**De Morgan 公式**：

$$(A \cup B)^c = A^c \cap B^c, \quad (A \cap B)^c = A^c \cup B^c$$

**推广**：$\left(\bigcup_{i=1}^n A_i\right)^c = \bigcap_{i=1}^n A_i^c$，$\left(\bigcap_{i=1}^n A_i\right)^c = \bigcup_{i=1}^n A_i^c$。

**推论 1.2**　De Morgan 公式对可数个事件也成立。

## 2. 概率空间

### 2.1 Kolmogorov 公理

**定义 2.1**　$(\Omega, \mathcal{F}, P)$ 构成**概率空间**，其中：

- $\Omega$：样本空间
- $\mathcal{F}$：$\Omega$ 上的 $\sigma$-代数（事件域）
- $P: \mathcal{F} \to [0, 1]$：概率测度

**概率测度的公理**：

1. **非负性**：$P(A) \geq 0$
2. **规范性**：$P(\Omega) = 1$
3. **可数可加性**：$A_1, A_2, \ldots$ 互不相交 $\Rightarrow P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)$

> **意义**：Kolmogorov 公理是现代概率论的基础——概率是测度。

### 2.2 $\sigma$-代数

**定义 2.2**　$\mathcal{F}$ 是 $\Omega$ 上的 $\sigma$-代数：
- $\emptyset \in \mathcal{F}$
- $A \in \mathcal{F} \Rightarrow A^c \in \mathcal{F}$
- $A_n \in \mathcal{F} \Rightarrow \bigcup A_n \in \mathcal{F}$

> **直觉**：$\sigma$-代数定义了"哪些子集可以谈论概率"。

**推论 2.1**　$\sigma$-代数对可数交也封闭。

**例子**：
- $\{\emptyset, \Omega\}$：最粗的 $\sigma$-代数
- $2^\Omega$：最细的 $\sigma$-代数（$\Omega$ 可数时）
- Borel $\sigma$-代数 $\mathcal{B}(\mathbb{R})$：由开集生成

## 3. 概率的性质

### 3.1 基本性质

| 性质 | 公式 |
|------|------|
| 补事件 | $P(A^c) = 1 - P(A)$ |
| 单调性 | $A \subseteq B \Rightarrow P(A) \leq P(B)$ |
| 加法公式 | $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ |
| 容斥原理 | $P\left(\bigcup A_i\right) = \sum P(A_i) - \sum P(A_i \cap A_j) + \cdots$ |

**推论 3.1**　$P(A \cup B) \leq P(A) + P(B)$（次可加性）。

**推论 3.2**　$P(A \cap B) \geq P(A) + P(B) - 1$（Bonferroni 不等式）。

### 3.2 连续性

**定理 3.1**：
- **下连续**：$A_n \uparrow A \Rightarrow P(A_n) \to P(A)$
- **上连续**：$A_n \downarrow A \Rightarrow P(A_n) \to P(A)$

**证明提示**：下连续用可数可加性，上连续用下连续和补集。

### 3.3 古典概型

**条件**：$\Omega$ 有限，每个样本点等可能。

$$P(A) = \frac{|A|}{|\Omega|} = \frac{\text{事件 } A \text{ 包含的样本点数}}{\text{样本点总数}}$$

**常用计数**：
- 排列：$P_n^k = \frac{n!}{(n-k)!}$
- 组合：$\binom{n}{k} = \frac{n!}{k!(n-k)!}$

**推论 3.3**　$\binom{n}{k} = \binom{n}{n-k}$（对称性）。

**推论 3.4**　$\sum_{k=0}^n \binom{n}{k} = 2^n$（二项式定理）。

### 3.4 几何概型

$$P(A) = \frac{m(A)}{m(\Omega)}$$

其中 $m$ 为长度、面积或体积。

**条件**：样本空间有有限测度，事件的概率只取决于测度比。
