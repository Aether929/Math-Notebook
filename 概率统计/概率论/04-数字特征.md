# 数字特征

> 用少数几个数概括随机变量的"形状"。

## 1. 数学期望

### 1.1 定义

**离散型**：$E(X) = \sum_{k} x_k p_k$（绝对收敛时存在）

**连续型**：$E(X) = \int_{-\infty}^{+\infty} x f(x) \, dx$（绝对收敛时存在）

**随机变量函数的期望（LOTUS）**：

$$E(g(X)) = \int_{-\infty}^{+\infty} g(x) f(x) \, dx$$

> 不需要求 $g(X)$ 的分布，直接用 $X$ 的密度计算。

**定理 1.1（期望的存在性）**　$E(X)$ 存在 $\iff$ $E|X| < \infty$。

### 1.2 性质

| 性质 | 公式 |
|------|------|
| 线性 | $E(aX + bY) = aE(X) + bE(Y)$（不需要独立） |
| 单调性 | $X \leq Y$ a.s. $\Rightarrow E(X) \leq E(Y)$ |
| 常数 | $E(c) = c$ |
| 独立可乘 | $X, Y$ 独立 $\Rightarrow E(XY) = E(X)E(Y)$ |
| 绝对值 | $|E(X)| \leq E|X|$（Jensen 不等式特例） |

**推论 1.1**　$E(XY) = E(X)E(Y)$ 不意味着 $X, Y$ 独立。

**反例**：$X \sim U(-1, 1)$，$Y = X^2$。$E(XY) = E(X^3) = 0 = E(X)E(Y)$，但 $Y$ 完全由 $X$ 决定。

**定理 1.2（Jensen 不等式）**　$g$ 凸，$E|X| < \infty$，则 $g(E(X)) \leq E(g(X))$。

> **证明提示**：凸函数在 $E(X)$ 处有支撑线：$g(x) \geq g(E(X)) + g'(E(X))(x - E(X))$，取期望。

**推论 1.2**　$|E(X)|^r \leq E|X|^r$（$r \geq 1$）。

## 2. 方差

### 2.1 定义

$$D(X) = \text{Var}(X) = E[(X - E(X))^2] = E(X^2) - [E(X)]^2$$

**标准差**：$\sigma(X) = \sqrt{D(X)}$。

### 2.2 性质

| 性质 | 公式 |
|------|------|
| 非负 | $D(X) \geq 0$，$D(X) = 0 \iff X = E(X)$ a.s. |
| 常数 | $D(c) = 0$ |
| 齐次 | $D(aX + b) = a^2 D(X)$ |
| 独立可加 | $X, Y$ 独立 $\Rightarrow D(X + Y) = D(X) + D(Y)$ |
| 一般加法 | $D(X + Y) = D(X) + D(Y) + 2\text{Cov}(X, Y)$ |

**推论 2.1**　$D(X) = \min_c E[(X - c)^2]$，最小值在 $c = E(X)$ 处取得。

> **证明提示**：$E[(X-c)^2] = D(X) + (E(X) - c)^2 \geq D(X)$。

**推论 2.2**　$D(X) \leq E(X^2)$（因为 $D(X) = E(X^2) - [E(X)]^2 \leq E(X^2)$）。

### 2.3 Chebyshev 不等式

**定理 2.1（Chebyshev 不等式）**：

$$P(|X - E(X)| \geq \varepsilon) \leq \frac{D(X)}{\varepsilon^2}$$

等价形式：$P(|X - \mu| \geq k\sigma) \leq 1/k^2$。

> **意义**：方差控制了随机变量偏离均值的概率——大数定律的"初等版"。

> **证明提示**：$D(X) = E[(X - \mu)^2] \geq \varepsilon^2 P(|X - \mu| \geq \varepsilon)$。

**推论 2.3（Markov 不等式）**　$X \geq 0$，$P(X \geq a) \leq E(X)/a$（$a > 0$）。

**推论 2.4**　$D(X) = 0$ $\Rightarrow$ $P(X = E(X)) = 1$（$X$ 几乎必然是常数）。

## 3. 协方差与相关系数

### 3.1 协方差

$$\text{Cov}(X, Y) = E[(X - E(X))(Y - E(Y))] = E(XY) - E(X)E(Y)$$

**性质**：
- $\text{Cov}(X, X) = D(X)$
- $\text{Cov}(X, Y) = \text{Cov}(Y, X)$
- $\text{Cov}(aX + b, cY + d) = ac \cdot \text{Cov}(X, Y)$
- $D(X + Y) = D(X) + D(Y) + 2\text{Cov}(X, Y)$
- $D\left(\sum X_i\right) = \sum D(X_i) + 2\sum_{i<j} \text{Cov}(X_i, X_j)$
- $X, Y$ 独立 $\Rightarrow$ $\text{Cov}(X, Y) = 0$（反之不成立）

### 3.2 相关系数

$$\rho_{XY} = \frac{\text{Cov}(X, Y)}{\sqrt{D(X)} \sqrt{D(Y)}}$$

**定理 3.1（Cauchy-Schwarz 不等式）**　$|\text{Cov}(X, Y)| \leq \sqrt{D(X)} \sqrt{D(Y)}$，即 $|\rho_{XY}| \leq 1$。

> **证明提示**：$E[(X - \mu_X)t + (Y - \mu_Y)]^2 \geq 0$ 对所有 $t$ 成立，判别式 $\leq 0$。

**定理 3.2**　$|\rho_{XY}| = 1$ $\iff$ $Y = aX + b$ a.s.（线性相关）。

- $\rho = 1$：完全正线性相关（$a > 0$）
- $\rho = -1$：完全负线性相关（$a < 0$）
- $\rho = 0$：**不相关**

**推论 3.1**　不相关 $\not\Rightarrow$ 独立（但对正态分布等价）。

**定理 3.3（正态分布的特殊性）**　$(X, Y)$ 为二元正态 $\Rightarrow$ 不相关 $\iff$ 独立。

### 3.3 条件期望

**定义 3.1**　$E(X|Y = y) = \int x f_{X|Y}(x|y) \, dx$。

**定理 3.4（重期望公式）**　$E(X) = E[E(X|Y)]$，即 $E(X) = \int E(X|Y=y) f_Y(y) \, dy$。

**定理 3.5（条件方差公式）**　$D(X) = E[D(X|Y)] + D[E(X|Y)]$（**方差的分解公式**）。

> **直觉**：总方差 = 条件方差的期望 + 条件期望的方差。"组内变异 + 组间变异"。

## 4. 矩

### 4.1 定义

**$k$ 阶原点矩**：$\mu_k = E(X^k)$

**$k$ 阶中心矩**：$\nu_k = E[(X - E(X))^k]$

**偏度**：$\gamma_1 = \frac{\nu_3}{\nu_2^{3/2}}$（衡量分布的不对称性。$\gamma_1 > 0$ 右偏，$\gamma_1 < 0$ 左偏）

**峰度**：$\gamma_2 = \frac{\nu_4}{\nu_2^2} - 3$（衡量分布的"尖峭"程度，正态分布峰度为 $0$）

### 4.2 矩母函数

**定义 4.1**：

$$M_X(t) = E(e^{tX}) = \sum_{k=0}^{\infty} \frac{E(X^k)}{k!} t^k$$

**性质**：
- $M_X^{(k)}(0) = E(X^k)$（求导取零得各阶矩）
- $M_{X+Y}(t) = M_X(t) M_Y(t)$（独立时）
- 矩母函数唯一确定分布（若存在）
- $M_{aX+b}(t) = e^{bt} M_X(at)$

**定理 4.1**　矩母函数在 $0$ 的某邻域内存在 $\iff$ 所有阶矩存在。

### 4.3 特征函数

**定义 4.2**：

$$\varphi_X(t) = E(e^{itX}) = \int_{-\infty}^{+\infty} e^{itx} f(x) \, dx$$

**优点**：
- 特征函数**总是存在**（不要求矩存在）
- 唯一确定分布
- 独立和的特征函数 = 特征函数的乘积
- 是密度函数的 Fourier 变换

**定理 4.2（反转公式）**：

$$f(x) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} e^{-itx} \varphi_X(t) \, dt$$

**定理 4.3（Lévy 连续性定理）**　$X_n \xrightarrow{d} X$ $\iff$ $\varphi_{X_n}(t) \to \varphi_X(t)$（$\forall t$）。

## 5. 常见分布的数字特征汇总

| 分布 | 期望 | 方差 | 矩母函数 |
|------|------|------|----------|
| $B(1, p)$ | $p$ | $p(1-p)$ | $1 - p + pe^t$ |
| $B(n, p)$ | $np$ | $np(1-p)$ | $(1 - p + pe^t)^n$ |
| $P(\lambda)$ | $\lambda$ | $\lambda$ | $e^{\lambda(e^t - 1)}$ |
| $Ge(p)$ | $\frac{1}{p}$ | $\frac{1-p}{p^2}$ | $\frac{pe^t}{1 - (1-p)e^t}$ |
| $NB(r, p)$ | $\frac{r}{p}$ | $\frac{r(1-p)}{p^2}$ | $\left(\frac{pe^t}{1-(1-p)e^t}\right)^r$ |
| $U(a, b)$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ | $\frac{e^{bt} - e^{at}}{(b-a)t}$ |
| $Exp(\lambda)$ | $\frac{1}{\lambda}$ | $\frac{1}{\lambda^2}$ | $\frac{\lambda}{\lambda - t}$ |
| $N(\mu, \sigma^2)$ | $\mu$ | $\sigma^2$ | $e^{\mu t + \sigma^2 t^2 / 2}$ |
| $\chi^2(n)$ | $n$ | $2n$ | $(1 - 2t)^{-n/2}$ |
| $t(n)$ | $0$（$n>1$） | $\frac{n}{n-2}$（$n>2$） | — |
| $F(m, n)$ | $\frac{n}{n-2}$（$n>2$） | 复杂 | — |
