# 随机过程入门

> 随时间演化的随机现象——从 Markov 链到 Brown 运动。

## 1. 基本概念

### 1.1 定义

**定义 1.1**　随机过程 $\{X_t : t \in T\}$ 是一族随机变量，$T$ 为指标集（通常为时间）。

- **离散时间**：$T = \{0, 1, 2, \ldots\}$（随机序列）
- **连续时间**：$T = [0, +\infty)$ 或 $T = \mathbb{R}$
- **状态空间** $S$：$X_t$ 的取值范围

### 1.2 有限维分布族

$$\{F_{t_1, \ldots, t_n}(x_1, \ldots, x_n) = P(X_{t_1} \leq x_1, \ldots, X_{t_n} \leq x_n)\}$$

满足相容性条件（Kolmogorov 相容性定理保证存在性）。

**推论 1.1**　随机过程由其有限维分布族完全确定（在分布意义下）。

## 2. Markov 链

### 2.1 定义

**定义 2.1**　离散时间随机过程 $\{X_n\}$ 是 **Markov 链**，若：

$$P(X_{n+1} = j | X_n = i, X_{n-1} = i_{n-1}, \ldots) = P(X_{n+1} = j | X_n = i)$$

> **无记忆性**：未来只依赖于现在，与过去无关。

### 2.2 转移概率

**转移矩阵** $P = (p_{ij})$，$p_{ij} = P(X_{n+1} = j | X_n = i)$

**Chapman-Kolmogorov 方程**：

$$p_{ij}^{(m+n)} = \sum_k p_{ik}^{(m)} p_{kj}^{(n)}$$

即 $P^{(n)} = P^n$（$n$ 步转移矩阵 = 转移矩阵的 $n$ 次幂）。

**推论 2.1**　转移矩阵是随机矩阵：行和为 1。

### 2.3 状态分类

| 概念 | 定义 |
|------|------|
| 可达 | $j$ 可达 $i$：$\exists n, p_{ij}^{(n)} > 0$ |
| 互通 | $i$ 与 $j$ 互通：互可达 |
| 常返 | $f_{ii} = 1$（从 $i$ 出发必回 $i$） |
| 非常返 | $f_{ii} < 1$ |
| 正常返 | 常返且平均返回时间有限 |
| 遍历 | 正常返 + 非周期 |

**推论 2.2**　有限状态 Markov 链至少有一个常返态。

### 2.4 平稳分布

**定义 2.2**：$\boldsymbol{\pi} P = \boldsymbol{\pi}$，$\sum \pi_i = 1$

**定理 2.1**：不可约遍历 Markov 链存在唯一平稳分布 $\boldsymbol{\pi}$，且：

$$\lim_{n \to \infty} p_{ij}^{(n)} = \pi_j$$

**推论 2.3**　遍历 Markov 链的长期行为与初始状态无关。

## 3. Poisson 过程

### 3.1 定义

**定义 3.1**　计数过程 $\{N(t), t \geq 0\}$ 是参数为 $\lambda$ 的 **Poisson 过程**：

1. $N(0) = 0$
2. 独立增量：不相交时段的增量独立
3. 平稳增量：$N(t + s) - N(s) \sim P(\lambda t)$

**等价定义**：
- 到达间隔时间 $\{T_n\}$ i.i.d. $\sim Exp(\lambda)$
- $N(t) \sim P(\lambda t)$

### 3.2 性质

- $E(N(t)) = \lambda t$，$\text{Var}(N(t)) = \lambda t$
- 到达间隔 $T_n \sim Exp(\lambda)$
- 给定 $N(t) = n$，$n$ 个到达时刻的联合分布与 $[0, t]$ 上 $n$ 个独立均匀分布的顺序统计量相同

**推论 3.1**　Poisson 过程的叠加仍是 Poisson 过程。

### 3.3 复合 Poisson 过程

$$X(t) = \sum_{i=1}^{N(t)} Y_i$$

其中 $\{Y_i\}$ i.i.d.，与 $N(t)$ 独立。

$E(X(t)) = \lambda t E(Y_1)$，$\text{Var}(X(t)) = \lambda t E(Y_1^2)$。

## 4. Brown 运动

### 4.1 定义

**定义 4.1**　$\{B(t), t \geq 0\}$ 是标准 **Brown 运动**（Wiener 过程）：

1. $B(0) = 0$
2. 独立增量
3. $B(t) - B(s) \sim N(0, t - s)$（$t > s$）
4. 轨道连续

### 4.2 性质

- $E(B(t)) = 0$，$\text{Var}(B(t)) = t$
- $B(t) \sim N(0, t)$
- $\text{Cov}(B(s), B(t)) = \min(s, t)$
- 轨道处处连续但几乎处处不可导
- **自相似性**：$B(ct) \overset{d}{=} \sqrt{c} B(t)$

**推论 4.1**　Brown 运动是高斯过程。

### 4.3 随机游走与 Brown 运动

**Donsker 定理**：简单随机游走的缩放极限是 Brown 运动。

$$\frac{S_{\lfloor nt \rfloor}}{\sqrt{n}} \xrightarrow{d} B(t)$$

## 5. 鞅

### 5.1 定义

**定义 5.1**　$\{X_n, \mathcal{F}_n\}$ 是**鞅**，若：

1. $X_n$ 关于 $\mathcal{F}_n$ 可测
2. $E(|X_n|) < \infty$
3. $E(X_{n+1} | \mathcal{F}_n) = X_n$

> **直觉**：鞅是"公平博弈"的数学模型——未来的期望等于现在的值。

### 5.2 例子

- 独立随机变量之和（零均值）
- Brown 运动 $B(t)$
- 条件期望 $E(X | \mathcal{F}_n)$（$\mathcal{F}_n$ 递增）

### 5.3 鞅收敛定理

**定理 5.1**：若 $\{X_n\}$ 是下鞅且 $\sup E(X_n^+) < \infty$，则 $X_n$ 几乎处处收敛。

**停止定理（可选抽样定理）**：$\tau$ 为停时，$E(\tau) < \infty$，则 $E(X_\tau) = E(X_0)$。

> **意义**：在公平博弈中，无论采用什么停止策略，期望收益为零。
