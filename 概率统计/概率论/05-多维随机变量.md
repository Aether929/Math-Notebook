# 多维随机变量

> 从一维到多维——联合分布、边际分布与条件分布。

## 1. 联合分布

### 1.1 联合分布函数

**定义 1.1**：$(X, Y)$ 的联合分布函数：

$$F(x, y) = P(X \leq x, Y \leq y)$$

**性质**：
- 对每个变量单调不减
- 对每个变量右连续
- $\lim_{x, y \to -\infty} F = 0$，$\lim_{x, y \to +\infty} F = 1$
- $P(a < X \leq b, c < Y \leq d) = F(b, d) - F(a, d) - F(b, c) + F(a, c) \geq 0$

**推论 1.1**　最后一个性质是二维概率非负的要求。

### 1.2 边际分布

$$F_X(x) = F(x, +\infty), \quad F_Y(y) = F(+\infty, y)$$

> **注意**：联合分布唯一确定边际分布，反之不然。

**推论 1.2**　相同的边际分布可以有不同的联合分布——联合分布包含更多信息。

### 1.3 联合密度

若 $F(x, y) = \int_{-\infty}^{x} \int_{-\infty}^{y} f(s, t) \, ds \, dt$，则 $f$ 为联合密度。

**边际密度**：

$$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy, \quad f_Y(y) = \int_{-\infty}^{+\infty} f(x, y) \, dx$$

## 2. 条件分布

### 2.1 离散型

$$P(X = x_i | Y = y_j) = \frac{P(X = x_i, Y = y_j)}{P(Y = y_j)}$$

### 2.2 连续型

$$f_{X|Y}(x | y) = \frac{f(x, y)}{f_Y(y)}$$

**推论 2.1**　条件密度也是密度：$\int f_{X|Y}(x|y) \, dx = 1$。

---

## 3. 独立性

### 3.1 定义

**定义 3.1**　$X, Y$ **独立** $\iff$ $F(x, y) = F_X(x) F_Y(y)$（$\forall x, y$）

等价条件：
- $f(x, y) = f_X(x) f_Y(y)$ a.e.
- $P(X \in A, Y \in B) = P(X \in A) P(Y \in B)$

### 3.2 独立性的判断

**定理 3.1**：$X, Y$ 独立 $\iff$ 联合密度可以分解为 $g(x) h(y)$ 的形式（支撑集为矩形）。

**推论 3.1**　独立 $\Rightarrow$ 不相关，反之不然（除非是正态分布）。

## 4. 多维随机变量的函数

### 4.1 和的分布

**离散型（卷积）**：$Z = X + Y$

$$P(Z = z) = \sum_{k} P(X = k) P(Y = z - k)$$

**连续型**：

$$f_Z(z) = \int_{-\infty}^{+\infty} f(x, z - x) \, dx = \int_{-\infty}^{+\infty} f_X(x) f_Y(z - x) \, dx$$

**推论 4.1**　独立随机变量之和的密度是各自密度的卷积。

### 4.2 常见分布的可加性

| 分布 | 可加性 |
|------|--------|
| 二项分布 | $X \sim B(m, p), Y \sim B(n, p)$ $\Rightarrow$ $X + Y \sim B(m+n, p)$ |
| Poisson 分布 | $X \sim P(\lambda_1), Y \sim P(\lambda_2)$ $\Rightarrow$ $X + Y \sim P(\lambda_1 + \lambda_2)$ |
| 正态分布 | $X \sim N(\mu_1, \sigma_1^2), Y \sim N(\mu_2, \sigma_2^2)$ $\Rightarrow$ $X + Y \sim N(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2)$ |
| Gamma 分布 | $X \sim \Gamma(\alpha_1, \lambda), Y \sim \Gamma(\alpha_2, \lambda)$ $\Rightarrow$ $X + Y \sim \Gamma(\alpha_1 + \alpha_2, \lambda)$ |
| $\chi^2$ 分布 | $\chi^2(m) + \chi^2(n) \sim \chi^2(m+n)$ |

**推论 4.2**　可加性要求独立且参数匹配（如二项分布的 $p$ 相同）。

### 4.3 商的分布

$$f_{X/Y}(z) = \int_{-\infty}^{+\infty} |y| f(zy, y) \, dy$$

### 4.4 max 与 min 的分布

设 $X_1, \ldots, X_n$ 独立，分布函数分别为 $F_1, \ldots, F_n$：

$$F_{\max}(x) = \prod_{i=1}^{n} F_i(x), \quad F_{\min}(x) = 1 - \prod_{i=1}^{n} [1 - F_i(x)]$$

**推论 4.3**　$X_1, \ldots, X_n$ i.i.d. $\sim Exp(\lambda)$ 时，$\min(X_1, \ldots, X_n) \sim Exp(n\lambda)$。

## 5. 多维数字特征

### 5.1 协方差矩阵

**定义 5.1**：$\boldsymbol{\Sigma} = (\sigma_{ij})$，$\sigma_{ij} = \text{Cov}(X_i, X_j)$

**性质**：$\boldsymbol{\Sigma}$ 对称半正定。

**推论 5.1**　协方差矩阵的对角元是方差。

### 5.2 多维正态分布

$\mathbf{X} = (X_1, \ldots, X_n)^T \sim N(\boldsymbol{\mu}, \boldsymbol{\Sigma})$，密度：

$$f(\mathbf{x}) = \frac{1}{(2\pi)^{n/2} |\boldsymbol{\Sigma}|^{1/2}} \exp\left(-\frac{1}{2} (\mathbf{x} - \boldsymbol{\mu})^T \boldsymbol{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})\right)$$

**性质**：
- 边际分布仍为正态
- 独立 $\iff$ 不相关（$\boldsymbol{\Sigma}$ 为对角阵）
- 线性变换后仍为正态：$\mathbf{AX} + \mathbf{b} \sim N(\mathbf{A}\boldsymbol{\mu} + \mathbf{b}, \mathbf{A}\boldsymbol{\Sigma}\mathbf{A}^T)$

**推论 5.2**　多维正态分布中，不相关等价于独立——这是正态分布的特殊性质。

## 6. 条件期望

### 6.1 定义

$$E(X | Y = y) = \int_{-\infty}^{+\infty} x f_{X|Y}(x | y) \, dx$$

### 6.2 全期望公式

$$E(X) = E[E(X | Y)]$$

> **证明**：$E[E(X | Y)] = \int E(X | Y = y) f_Y(y) \, dy = \int\int x f_{X|Y}(x|y) f_Y(y) \, dx \, dy = \int x f_X(x) \, dx = E(X)$。

**推论 6.1**　全期望公式是"加权平均的加权平均等于总平均"。

### 6.3 条件方差

$$\text{Var}(X) = E[\text{Var}(X | Y)] + \text{Var}(E(X | Y))$$

> **意义**：全方差 = 条件方差的期望 + 条件期望的方差（"方差分解"）。

**推论 6.2**　$\text{Var}(X) \geq E[\text{Var}(X | Y)]$（条件减少了不确定性）。
