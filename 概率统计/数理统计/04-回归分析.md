# 回归分析

> 变量间关系的统计建模——从线性到广义线性模型。

## 1. 一元线性回归

### 1.1 模型

$$Y = \beta_0 + \beta_1 X + \varepsilon, \quad \varepsilon \sim N(0, \sigma^2)$$

**假设**：
- $X$ 为非随机变量（或条件推断）
- $\varepsilon_i$ 独立同分布，$\varepsilon_i \sim N(0, \sigma^2)$

### 1.2 最小二乘估计

**目标**：最小化残差平方和 $Q = \sum_{i=1}^{n} (y_i - \hat{\beta}_0 - \hat{\beta}_1 x_i)^2$

**正规方程**：

$$\hat{\beta}_1 = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2} = \frac{S_{xy}}{S_{xx}}$$

$$\hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x}$$

**推论 1.1**　回归直线过样本中心 $(\bar{x}, \bar{y})$。

### 1.3 估计量的性质

$$\hat{\beta}_1 \sim N\left(\beta_1, \frac{\sigma^2}{S_{xx}}\right), \quad \hat{\beta}_0 \sim N\left(\beta_0, \sigma^2\left(\frac{1}{n} + \frac{\bar{x}^2}{S_{xx}}\right)\right)$$

$$\hat{\sigma}^2 = \frac{Q}{n-2} = \frac{\sum (y_i - \hat{y}_i)^2}{n-2}, \quad \frac{(n-2)\hat{\sigma}^2}{\sigma^2} \sim \chi^2(n-2)$$

**推论 1.2**　$\hat{\beta}_1$ 的方差与 $S_{xx}$ 成反比——$X$ 的变异越大，斜率估计越精确。

### 1.4 显著性检验

**回归系数检验**：$H_0: \beta_1 = 0$

$$T = \frac{\hat{\beta}_1}{S / \sqrt{S_{xx}}} \sim t(n-2)$$

**相关系数检验**：$H_0: \rho = 0$

$$T = \frac{r\sqrt{n-2}}{\sqrt{1-r^2}} \sim t(n-2)$$

其中 $r = \frac{S_{xy}}{\sqrt{S_{xx} S_{yy}}}$ 为样本相关系数。

**推论 1.3**　$R^2 = r^2$（一元回归中决定系数等于相关系数的平方）。

### 1.5 预测

**点预测**：$\hat{y}_0 = \hat{\beta}_0 + \hat{\beta}_1 x_0$

**预测区间**（$Y_0$ 的区间）：

$$\hat{y}_0 \pm t_{\alpha/2}(n-2) \cdot S \sqrt{1 + \frac{1}{n} + \frac{(x_0 - \bar{x})^2}{S_{xx}}}$$

**置信区间**（$E(Y_0)$ 的区间）：

$$\hat{y}_0 \pm t_{\alpha/2}(n-2) \cdot S \sqrt{\frac{1}{n} + \frac{(x_0 - \bar{x})^2}{S_{xx}}}$$

**推论 1.4**　预测区间比置信区间更宽（多了 $\sqrt{1}$ 项，来自随机误差）。

## 2. 多元线性回归

### 2.1 模型

$$Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \cdots + \beta_p X_p + \varepsilon$$

**矩阵形式**：$\mathbf{Y} = \mathbf{X} \boldsymbol{\beta} + \boldsymbol{\varepsilon}$

### 2.2 最小二乘估计

$$\hat{\boldsymbol{\beta}} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{Y}$$

**性质**：
- $E(\hat{\boldsymbol{\beta}}) = \boldsymbol{\beta}$（无偏）
- $\text{Cov}(\hat{\boldsymbol{\beta}}) = \sigma^2 (\mathbf{X}^T \mathbf{X})^{-1}$
- $\hat{\boldsymbol{\beta}} \sim N(\boldsymbol{\beta}, \sigma^2 (\mathbf{X}^T \mathbf{X})^{-1})$

**推论 2.1**　Gauss-Markov 定理：$\hat{\boldsymbol{\beta}}$ 是最佳线性无偏估计（BLUE）。

### 2.3 模型检验

**整体显著性（$F$ 检验）**：$H_0: \beta_1 = \beta_2 = \cdots = \beta_p = 0$

$$F = \frac{SS_R / p}{SS_E / (n - p - 1)} \sim F(p, n - p - 1)$$

其中：
- $SS_T = \sum (y_i - \bar{y})^2$（总平方和）
- $SS_R = \sum (\hat{y}_i - \bar{y})^2$（回归平方和）
- $SS_E = \sum (y_i - \hat{y}_i)^2$（残差平方和）
- $SS_T = SS_R + SS_E$

**决定系数**：$R^2 = \frac{SS_R}{SS_T} = 1 - \frac{SS_E}{SS_T}$

**推论 2.2**　$0 \leq R^2 \leq 1$，$R^2$ 越大拟合越好。

### 2.4 变量选择

| 准则 | 公式 | 说明 |
|------|------|------|
| $R^2$ | 越大越好 | 加入变量总增大 |
| 调整 $R^2$ | $\bar{R}^2 = 1 - \frac{SS_E/(n-p-1)}{SS_T/(n-1)}$ | 考虑参数个数 |
| AIC | $n \ln(SS_E/n) + 2p$ | 信息准则 |
| BIC | $n \ln(SS_E/n) + p \ln n$ | 惩罚更重 |

**推论 2.3**　BIC 比 AIC 更倾向于选择简单模型（惩罚更重）。

## 3. 回归诊断

### 3.1 残差分析

**残差**：$e_i = y_i - \hat{y}_i$

**标准化残差**：$r_i = \frac{e_i}{S\sqrt{1 - h_{ii}}}$

其中 $h_{ii}$ 为帽子矩阵 $\mathbf{H} = \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T$ 的对角元。

**诊断图**：
- 残差 vs 拟合值：检查线性、等方差
- Q-Q 图：检查正态性
- 残差 vs 杠杆值：识别影响点

**推论 3.1**　$h_{ii}$ 度量第 $i$ 个观测的"杠杆"——对拟合的影响程度。

### 3.2 多重共线性

**方差膨胀因子**：$\text{VIF}_j = \frac{1}{1 - R_j^2}$

- VIF > 10：严重共线性
- VIF > 5：中等共线性

**解决方法**：删除变量、主成分回归、岭回归。

## 4. 广义线性模型

### 4.1 指数族

$$f(y; \theta, \phi) = \exp\left\{\frac{y\theta - b(\theta)}{a(\phi)} + c(y, \phi)\right\}$$

### 4.2 Logistic 回归

**模型**：$P(Y = 1 | X) = \frac{e^{\beta_0 + \beta_1 X}}{1 + e^{\beta_0 + \beta_1 X}}$

**对数几率**：$\ln \frac{P}{1-P} = \beta_0 + \beta_1 X$

**估计**：最大似然估计（无解析解，用 Newton-Raphson 迭代）。

**推论 4.1**　$\beta_1$ 的解释：$X$ 每增加一个单位，对数几率增加 $\beta_1$。

### 4.3 Poisson 回归

**模型**：$\ln E(Y | X) = \beta_0 + \beta_1 X$

适用于计数数据。
