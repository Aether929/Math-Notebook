# 抽样分布

> 从总体到样本——统计推断的分布基础。

## 1. 基本概念

### 1.1 总体与样本

**总体**：研究对象的全体（通常用随机变量 $X$ 表示）。

**样本** $X_1, X_2, \ldots, X_n$：从总体中抽取的 $n$ 个独立同分布的随机变量。

**样本值** $x_1, x_2, \ldots, x_n$：样本的观测值。

**推论 1.1**　i.i.d. 假设是简单随机抽样的数学模型。

### 1.2 统计量

**定义 1.1**：样本的函数 $T = T(X_1, \ldots, X_n)$，不含未知参数。

**常用统计量**：

| 统计量 | 定义 | 期望 | 方差 |
|--------|------|------|------|
| 样本均值 | $\bar{X} = \frac{1}{n}\sum X_i$ | $\mu$ | $\sigma^2/n$ |
| 样本方差 | $S^2 = \frac{1}{n-1}\sum (X_i - \bar{X})^2$ | $\sigma^2$ | — |
| 样本标准差 | $S = \sqrt{S^2}$ | — | — |
| 样本 $k$ 阶矩 | $A_k = \frac{1}{n}\sum X_i^k$ | $E(X^k)$ | — |
| 样本中位数 | $\tilde{X}$ | — | — |

> **注意**：样本方差用 $n-1$ 而非 $n$（无偏性，见参数估计）。

**推论 1.2**　$E(\bar{X}) = \mu$，即样本均值是总体均值的无偏估计。

## 2. 三大抽样分布

### 2.1 $\chi^2$ 分布

**定义 2.1**：$X_1, \ldots, X_n$ i.i.d. $\sim N(0, 1)$，则：

$$\chi^2 = \sum_{i=1}^{n} X_i^2 \sim \chi^2(n)$$

**性质**：
- $E(\chi^2) = n$，$D(\chi^2) = 2n$
- 可加性：$\chi^2(m) + \chi^2(n) \sim \chi^2(m + n)$
- 密度：$f(x) = \frac{1}{2^{n/2}\Gamma(n/2)} x^{n/2 - 1} e^{-x/2}$（$x > 0$）

**推论 2.1**　$\chi^2(n) = \Gamma(n/2, 1/2)$。

### 2.2 $t$ 分布

**定义 2.2**：$X \sim N(0, 1)$，$Y \sim \chi^2(n)$，$X, Y$ 独立，则：

$$T = \frac{X}{\sqrt{Y/n}} \sim t(n)$$

**性质**：
- 密度关于 $0$ 对称
- $E(T) = 0$（$n > 1$），$D(T) = \frac{n}{n-2}$（$n > 2$）
- $n$ 大时趋近 $N(0, 1)$

**推论 2.2**　$t(1)$ 是 Cauchy 分布（期望不存在）。

### 2.3 $F$ 分布

**定义 2.3**：$X \sim \chi^2(m)$，$Y \sim \chi^2(n)$，$X, Y$ 独立，则：

$$F = \frac{X/m}{Y/n} \sim F(m, n)$$

**性质**：
- $F > 0$
- $\frac{1}{F} \sim F(n, m)$
- $T \sim t(n) \Rightarrow T^2 \sim F(1, n)$

**推论 2.3**　$F$ 分布与 $t$ 分布的关系：$t^2 = F(1, n)$。

## 3. 正态总体的抽样分布定理

设 $X_1, \ldots, X_n$ i.i.d. $\sim N(\mu, \sigma^2)$：

### 3.1 样本均值的分布

$$\bar{X} \sim N\left(\mu, \frac{\sigma^2}{n}\right), \quad \frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim N(0, 1)$$

**推论 3.1**　样本均值的标准差 $= \sigma / \sqrt{n}$（标准误）。

### 3.2 样本方差的分布

$$\frac{(n-1)S^2}{\sigma^2} = \frac{\sum (X_i - \bar{X})^2}{\sigma^2} \sim \chi^2(n-1)$$

### 3.3 $\bar{X}$ 与 $S^2$ 独立

**定理 3.1**：$\bar{X}$ 与 $S^2$ 独立。

**证明提示**：利用正交变换将 $(X_1, \ldots, X_n)$ 变换为 $(\bar{X}, Y_2, \ldots, Y_n)$。

### 3.4 $t$ 统计量

$$\frac{\bar{X} - \mu}{S / \sqrt{n}} \sim t(n-1)$$

> **注意**：用 $S$（样本标准差）替代 $\sigma$ 后，从正态分布变为 $t$ 分布。

**推论 3.2**　当 $n$ 大时，$t(n-1) \approx N(0, 1)$。

## 4. 两个正态总体

设 $X_1, \ldots, X_m$ i.i.d. $\sim N(\mu_1, \sigma_1^2)$，$Y_1, \ldots, Y_n$ i.i.d. $\sim N(\mu_2, \sigma_2^2)$，两样本独立。

### 4.1 均值差的分布

$$\bar{X} - \bar{Y} \sim N\left(\mu_1 - \mu_2, \frac{\sigma_1^2}{m} + \frac{\sigma_2^2}{n}\right)$$

### 4.2 方差比的分布

$$\frac{S_1^2 / \sigma_1^2}{S_2^2 / \sigma_2^2} \sim F(m-1, n-1)$$

### 4.3 等方差情形

若 $\sigma_1^2 = \sigma_2^2 = \sigma^2$，令 $S_w^2 = \frac{(m-1)S_1^2 + (n-1)S_2^2}{m + n - 2}$，则：

$$\frac{(\bar{X} - \bar{Y}) - (\mu_1 - \mu_2)}{S_w \sqrt{\frac{1}{m} + \frac{1}{n}}} \sim t(m + n - 2)$$

**推论 4.1**　$S_w^2$ 是 $\sigma^2$ 的合并估计（pooled estimate）。

---

## 5. 经验分布函数

**定义 5.1**：

$$F_n(x) = \frac{1}{n} \sum_{i=1}^{n} \mathbf{1}_{\{X_i \leq x\}}$$

**定理 5.1（Glivenko-Cantelli）**：

$$\sup_x |F_n(x) - F(x)| \xrightarrow{\text{a.s.}} 0$$

> **意义**：经验分布函数一致收敛于真实分布函数。

**推论 5.1**　经验分布函数是分布函数的相合估计。
