# 参数估计

> 用样本推断总体——统计学的核心任务。

## 1. 点估计

### 1.1 定义

**定义 1.1**　设总体分布含未知参数 $\theta$，用样本 $X_1, \ldots, X_n$ 构造统计量 $\hat{\theta} = \hat{\theta}(X_1, \ldots, X_n)$ 来估计 $\theta$。

### 1.2 矩估计法（MM）

**思想**：用样本矩估计总体矩。

**步骤**：
1. 计算总体的前 $k$ 阶矩 $\mu_k = \mu_k(\theta_1, \ldots, \theta_k)$
2. 用样本矩 $A_k = \frac{1}{n}\sum X_i^k$ 替代
3. 解方程组得 $\hat{\theta}_1, \ldots, \hat{\theta}_k$

**例**：$X \sim N(\mu, \sigma^2)$
- $\mu_1 = \mu$，$\mu_2 = \sigma^2 + \mu^2$
- $\hat{\mu} = \bar{X}$，$\hat{\sigma}^2 = \frac{1}{n}\sum X_i^2 - \bar{X}^2 = \frac{1}{n}\sum (X_i - \bar{X})^2$

**定理 1.1（矩估计的一致性）**　矩估计是一致估计（由大数定律保证）。

**定理 1.2（矩估计的渐近正态性）**　在正则条件下，$\sqrt{n}(\hat{\theta}_{MM} - \theta) \xrightarrow{d} N(0, V)$。

### 1.3 最大似然估计（MLE）

**思想**：选择使观测数据出现概率最大的参数值。

**似然函数**：

$$L(\theta) = \prod_{i=1}^{n} f(x_i; \theta)$$

**对数似然**：$\ell(\theta) = \ln L(\theta) = \sum \ln f(x_i; \theta)$

**MLE**：$\hat{\theta}_{\text{MLE}} = \arg\max_\theta L(\theta)$

**求解**：解**似然方程** $\frac{\partial \ell}{\partial \theta} = 0$。

**定理 1.3（MLE 的不变性原理）**　若 $\hat{\theta}$ 是 MLE，则 $g(\hat{\theta})$ 是 $g(\theta)$ 的 MLE。

**定理 1.4（MLE 的渐近性质）**　在正则条件下：
1. $\hat{\theta}_{MLE}$ 是一致估计
2. $\sqrt{n}(\hat{\theta}_{MLE} - \theta) \xrightarrow{d} N(0, 1/I(\theta))$（渐近正态）
3. $\hat{\theta}_{MLE}$ 渐近有效（达到 Cramér-Rao 下界）

**定理 1.5（Cramér-Rao 下界）**　无偏估计的方差满足：

$$D(\hat{\theta}) \geq \frac{1}{nI(\theta)}$$

其中 $I(\theta) = E\left[\left(\frac{\partial \ln f(X; \theta)}{\partial \theta}\right)^2\right] = -E\left[\frac{\partial^2 \ln f(X; \theta)}{\partial \theta^2}\right]$ 为 **Fisher 信息量**。

**推论 1.1**　Fisher 信息量的可加性：$n$ 个独立样本的 Fisher 信息为 $nI(\theta)$。

### 1.4 常见分布的 MLE

| 分布 | 参数 | MLE | Fisher 信息量 |
|------|------|-----|--------------|
| $N(\mu, \sigma^2)$ | $\mu$ | $\bar{X}$ | $1/\sigma^2$ |
| $N(\mu, \sigma^2)$ | $\sigma^2$ | $\frac{1}{n}\sum(X_i - \bar{X})^2$ | $1/(2\sigma^4)$ |
| $P(\lambda)$ | $\lambda$ | $\bar{X}$ | $1/\lambda$ |
| $B(1, p)$ | $p$ | $\bar{X}$ | $1/[p(1-p)]$ |
| $Exp(\lambda)$ | $\lambda$ | $\frac{1}{\bar{X}}$ | $1/\lambda^2$ |

## 2. 估计量的评价标准

### 2.1 无偏性

**定义 2.1**　$E(\hat{\theta}) = \theta$，称 $\hat{\theta}$ 为 $\theta$ 的**无偏估计**。

**例**：
- $\bar{X}$ 是 $\mu$ 的无偏估计
- $S^2 = \frac{1}{n-1}\sum(X_i - \bar{X})^2$ 是 $\sigma^2$ 的无偏估计
- $\frac{1}{n}\sum(X_i - \bar{X})^2$ 是 $\sigma^2$ 的有偏估计（偏小，$E = \frac{n-1}{n}\sigma^2$）

**定理 2.1**　$\bar{X}$ 和 $S^2$ 独立（正态总体下）。

> **证明提示**：$\bar{X}$ 和 $(X_i - \bar{X})$ 独立（正态分布的性质），$S^2$ 只依赖于后者。

### 2.2 有效性

**定义 2.2**　在无偏估计中，方差越小越**有效**。

**有效估计**：达到 Cramér-Rao 下界的估计。

**定理 2.2**　有效估计存在 $\iff$ 得分函数可写成 $\frac{\partial \ln f}{\partial \theta} = a(\theta)(T(x) - b(\theta))$（指数族形式）。

**推论 2.1**　指数族分布的自然参数的有效估计存在。

### 2.3 一致性

**定义 2.3**　$\hat{\theta}_n \xrightarrow{P} \theta$，称 $\hat{\theta}$ 为 $\theta$ 的**一致估计**。

**定理 2.3**　MLE 在正则条件下是一致的且渐近正态的。

**定理 2.4（一致性的充分条件）**　若 $\hat{\theta}$ 无偏且 $D(\hat{\theta}) \to 0$，则 $\hat{\theta}$ 一致。

## 3. 区间估计

### 3.1 置信区间

**定义 3.1**　$(\hat{\theta}_L, \hat{\theta}_U)$ 是 $\theta$ 的 **$1 - \alpha$ 置信区间**，若：

$$P(\hat{\theta}_L \leq \theta \leq \hat{\theta}_U) = 1 - \alpha$$

> **频率学派解释**：重复抽样，约 $100(1-\alpha)\%$ 的区间会覆盖真值。

**定义 3.2**　**置信水平**：$1 - \alpha$。常用 $0.95$（$\alpha = 0.05$），$0.99$（$\alpha = 0.01$）。

**定理 3.1**　若 $T = T(X_1, \ldots, X_n, \theta)$ 的分布不依赖于 $\theta$（**枢轴量**），则可构造置信区间。

### 3.2 正态总体参数的置信区间

#### 已知 $\sigma^2$，估计 $\mu$

$$\bar{X} \pm z_{\alpha/2} \frac{\sigma}{\sqrt{n}}$$

枢轴量：$Z = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim N(0, 1)$。

#### 未知 $\sigma^2$，估计 $\mu$

$$\bar{X} \pm t_{\alpha/2}(n-1) \frac{S}{\sqrt{n}}$$

枢轴量：$T = \frac{\bar{X} - \mu}{S / \sqrt{n}} \sim t(n-1)$。

#### 估计 $\sigma^2$

$$\left(\frac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)}, \frac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right)$$

枢轴量：$\chi^2 = \frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$。

### 3.3 两个总体的置信区间

#### $\mu_1 - \mu_2$（$\sigma_1^2, \sigma_2^2$ 已知）

$$(\bar{X} - \bar{Y}) \pm z_{\alpha/2} \sqrt{\frac{\sigma_1^2}{m} + \frac{\sigma_2^2}{n}}$$

#### $\mu_1 - \mu_2$（$\sigma_1^2 = \sigma_2^2$ 未知）

$$(\bar{X} - \bar{Y}) \pm t_{\alpha/2}(m+n-2) S_w \sqrt{\frac{1}{m} + \frac{1}{n}}$$

其中 $S_w^2 = \frac{(m-1)S_1^2 + (n-1)S_2^2}{m+n-2}$（**合并方差**）。

#### $\sigma_1^2 / \sigma_2^2$

$$\left(\frac{S_1^2}{S_2^2} \cdot \frac{1}{F_{\alpha/2}(m-1, n-1)}, \frac{S_1^2}{S_2^2} \cdot F_{\alpha/2}(n-1, m-1)\right)$$

枢轴量：$\frac{S_1^2 / \sigma_1^2}{S_2^2 / \sigma_2^2} \sim F(m-1, n-1)$。

## 4. 贝叶斯估计

### 4.1 基本思想

将参数 $\theta$ 视为随机变量，有先验分布 $\pi(\theta)$。

**后验分布**（Bayes 公式）：

$$\pi(\theta | x) = \frac{f(x | \theta) \pi(\theta)}{\int f(x | \theta) \pi(\theta) \, d\theta} \propto f(x|\theta) \pi(\theta)$$

### 4.2 贝叶斯估计

**后验均值估计（MMSE）**：$\hat{\theta}_{\text{Bayes}} = E(\theta | X)$

**最大后验估计（MAP）**：$\hat{\theta}_{\text{MAP}} = \arg\max_\theta \pi(\theta | x)$

**定理 4.1**　后验均值估计使后验均方误差 $E[(\theta - \hat{\theta})^2 | X]$ 最小。

### 4.3 共轭先验

**定义 4.1**　若先验 $\pi(\theta)$ 与似然 $f(x|\theta)$ 属于同一分布族，则后验也属于该族。

| 似然 | 共轭先验 | 后验 |
|------|----------|------|
| 正态（已知方差） | 正态 $N(\mu_0, \tau^2)$ | 正态 |
| Poisson | Gamma$(\alpha, \beta)$ | Gamma |
| 二项 | Beta$(\alpha, \beta)$ | Beta |
| 指数 | Gamma | Gamma |
| 正态（未知方差） | 逆 Gamma | 逆 Gamma |

**推论 4.1**　Beta$(1,1)$ = 均匀分布，是二项分布的"无信息先验"。

### 4.4 贝叶斯 vs 频率学派

| 方面 | 频率学派 | 贝叶斯学派 |
|------|----------|------------|
| 参数 | 固定未知常数 | 随机变量 |
| 估计 | 点估计 + 置信区间 | 后验分布 |
| 信息 | 仅用样本 | 先验 + 样本 |
| 优势 | 客观 | 可融入先验知识 |
