## 学习路线

```
抽样分布 → 参数估计 → 假设检验
                ↓
            回归分析 → 方差分析
```

## 核心思想

| 统计推断 | 方法 | 核心工具 |
|----------|------|----------|
| 参数估计 | 用样本推断参数 | MLE、矩估计、置信区间 |
| 假设检验 | 用数据检验假设 | $p$ 值、功效函数 |
| 回归分析 | 建模变量间关系 | 最小二乘、$F$ 检验 |
| 方差分析 | 比较多组均值 | 平方和分解、$F$ 检验 |
