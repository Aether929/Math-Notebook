# 鞅论

> 公平博弈的数学理论——从收敛定理到金融应用。

## 1. 基本概念

### 1.1 定义

设 $(\Omega, \mathcal{F}, P)$ 为概率空间，$\{\mathcal{F}_n\}_{n \geq 0}$ 为递增 $\sigma$-代数列（信息流/滤子）。

**定义 1.1**　适应过程 $\{X_n\}$（$X_n$ 关于 $\mathcal{F}_n$ 可测）是**鞅**，若：
1. $E|X_n| < \infty$
2. $E(X_{n+1} \mid \mathcal{F}_n) = X_n$ a.s.

**下鞅**：$E(X_{n+1} \mid \mathcal{F}_n) \geq X_n$

**上鞅**：$E(X_{n+1} \mid \mathcal{F}_n) \leq X_n$

**推论 1.1**　$X_n$ 是上鞅 $\iff$ $-X_n$ 是下鞅。

### 1.2 基本例子

| 过程 | 说明 |
|------|------|
| $S_n = \sum_{i=1}^n X_i$，$E(X_i) = 0$ | 独立零均值和 |
| $M_n = E(X \mid \mathcal{F}_n)$ | Doob 鞅 |
| $B(t)$ | Brown 运动 |
| $B(t)^2 - t$ | Brown 运动的平方减时间 |
| $e^{\sigma B(t) - \sigma^2 t/2}$ | 指数鞅 |
| $\prod_{i=1}^n \frac{p_{X_i}}{q_{X_i}}$ | 似然比（$p$ 为真分布，$q$ 为假设分布） |

### 1.3 鞅的变换

**定理 1.1**：
- 鞅的和是鞅
- 鞅的极限（若存在）是鞅
- $f$ 凸函数，$X$ 鞅 $\Rightarrow$ $f(X)$ 下鞅（Jensen 不等式）

**推论 1.2**　$|X_n|$ 是下鞅（$X_n$ 为鞅时）。

## 2. Doob 鞅收敛定理

### 2.1 定理

**定理 2.1**　设 $\{X_n\}$ 是下鞅，$\sup_n E(X_n^+) < \infty$，则存在 $X_\infty$（$E|X_\infty| < \infty$）使得：

$$X_n \xrightarrow{\text{a.s.}} X_\infty$$

**推论**：
- 非负下鞅几乎必然收敛
- 有界鞅几乎必然收敛
- $L^1$ 有界鞅几乎必然收敛

### 2.2 收敛的正则性

**定理 2.2**：$L^1$ 有界鞅 $\{X_n\}$ 收敛于 $X_\infty$ $\iff$ $\{X_n\}$ 一致可积，此时 $X_n \xrightarrow{L^1} X_\infty$。

**推论 2.1**　一致可积保证了 $L^1$ 收敛（不仅是几乎处处收敛）。

## 3. 停时与可选抽样

### 3.1 停时

**定义 3.1**　$\tau: \Omega \to \{0, 1, \ldots\} \cup \{+\infty\}$ 是停时，若 $\{\tau = n\} \in \mathcal{F}_n$。

**停时 $\sigma$-代数**：$\mathcal{F}_\tau = \{A \in \mathcal{F} : A \cap \{\tau \leq n\} \in \mathcal{F}_n, \forall n\}$

### 3.2 停止过程

$X_n^\tau = X_{\min(n, \tau)}$

**定理 3.1**：$X$ 是鞅 $\Rightarrow$ $X^\tau$ 是鞅。

### 3.3 可选抽样定理（Doob）

**定理 3.2**　设 $\{X_n\}$ 为鞅，$\tau$ 为停时。以下条件之一保证 $E(X_\tau) = E(X_0)$：

1. $\tau$ 有界（$\tau \leq N$ a.s.）
2. $E(\tau) < \infty$ 且 $|X_{n+1} - X_n|$ 有界
3. $X_{\min(n, \tau)}$ 一致可积

> **意义**：公平博弈中，合理的停止策略不会改变期望收益。

### 3.4 Wald 等式

**推论 3.1**：$X_i$ i.i.d.，$E(X_i) = \mu$，$S_n = \sum X_i$，$\tau$ 停时，$E(\tau) < \infty$，则：

$$E(S_\tau) = \mu E(\tau)$$

## 4. Doob 不等式

### 4.1 极大不等式

**定理 4.1**　设 $\{X_n\}$ 为下鞅，$X_n^* = \max_{0 \leq k \leq n} X_k$：

$$\lambda P(X_n^* \geq \lambda) \leq E(X_n^+)$$

### 4.2 $L^p$ 极大不等式

**定理 4.2**　设 $\{X_n\}$ 为鞅，$1 < p < \infty$：

$$\|X_n^*\|_p \leq \frac{p}{p-1} \|X_n\|_p$$

**推论 4.1**　Doob 的 $L^p$ 不等式是极大函数估计的特例。

### 4.3 上穿不等式

**定理 4.3**：设 $\{X_n\}$ 为下鞅，$\beta_n(a, b)$ 为 $X_0, \ldots, X_n$ 上穿 $[a, b]$ 的次数，则：

$$E(\beta_n(a, b)) \leq \frac{E((X_n - a)^+)}{b - a}$$

> **用途**：证明收敛定理——上穿次数有限保证极限存在。

---

## 5. 鞅差序列

### 5.1 定义

**定义 5.1**：$D_n = X_n - X_{n-1}$（$X_n$ 为鞅），则 $\{D_n\}$ 为**鞅差序列**。

**性质**：
- $E(D_n \mid \mathcal{F}_{n-1}) = 0$
- 不相关：$E(D_m D_n) = 0$（$m \neq n$）

**推论 5.1**　鞅差序列是不相关的（但不一定独立）。

### 5.2 鞅中心极限定理

**定理 5.1**　设 $\{D_n\}$ 为鞅差序列，满足一定正则条件（Lindeberg 型条件），则：

$$\frac{1}{\sqrt{n}} \sum_{i=1}^n D_i \xrightarrow{d} N(0, \sigma^2)$$

> **意义**：鞅差序列的中心极限定理——比独立性条件更弱。

---

## 6. 连续时间鞅

### 6.1 定义

$\{X(t), \mathcal{F}_t\}$ 是连续时间鞅：
1. $X(t)$ 关于 $\mathcal{F}_t$ 适应
2. $E|X(t)| < \infty$
3. $E(X(t) \mid \mathcal{F}_s) = X(s)$（$s \leq t$）

### 6.2 例子

- $B(t)$
- $B(t)^2 - t$
- $e^{\sigma B(t) - \sigma^2 t / 2}$
- Itô 积分 $\int_0^t \sigma(s) \, dB(s)$

### 6.3 Doob 停止定理（连续时间）

设 $\{X(t)\}$ 右连续鞅，$\tau$ 停时，$E(\tau) < \infty$，$|X(t \wedge \tau)| \leq K$，则：

$$E(X(\tau)) = E(X(0))$$

### 6.4 鞅表示定理

**定理 6.1**：设 $M(t)$ 是关于 Brown 运动 $\{B(t)\}$ 的鞅，满足一定正则条件，则存在适应过程 $\phi(t)$ 使得：

$$M(t) = M(0) + \int_0^t \phi(s) \, dB(s)$$

> **意义**：Brown 运动滤子下的所有鞅都可以表示为 Itô 积分。

## 7. 鞅在金融中的应用

### 7.1 风险中性定价

**基本定理**：无套利 $\iff$ 存在等价鞅测度 $Q$，使得折现价格过程是鞅。

**欧式期权价格**：

$$C = e^{-rT} E^Q[\max(S(T) - K, 0)]$$

### 7.2 停时与美式期权

美式期权的最优执行策略是停时问题。

$$V = \sup_\tau e^{-r\tau} E^Q[S(\tau)]$$
