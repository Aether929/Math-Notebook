## 学习路线

```
基本概念
    ├── Poisson 过程 ──→ 连续时间 Markov 链 ──→ 排队论
    ├── Markov 链（离散）──→ 分支过程、随机游走
    ├── Brown 运动 ──→ 鞅论 ──→ 随机分析
    └── 平稳过程 ──→ 谱分析 ──→ 信号处理
```

## 核心思想

| 过程 | 关键特征 | 应用领域 |
|------|----------|----------|
| Poisson 过程 | 稀有事件、无记忆 | 排队论、可靠性 |
| Markov 链 | 无记忆性 | 物理、生物、Google PageRank |
| Brown 运动 | 独立增量、连续轨道 | 金融、扩散、控制 |
| 鞅 | 公平博弈 | 金融定价、统计检验 |
| 平稳过程 | 时间不变性 | 信号处理、时间序列 |
