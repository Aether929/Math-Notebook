# 随机过程基本概念

> 随时间演化的随机现象——随机过程的数学框架。

## 1. 定义与分类

### 1.1 定义

**定义 1.1**　设 $(\Omega, \mathcal{F}, P)$ 为概率空间，$T \subseteq \mathbb{R}$ 为指标集，$S$ 为状态空间。若对每个 $t \in T$，$X(t, \omega)$ 是随机变量，则称 $\{X(t, \omega) : t \in T\}$ 为**随机过程**。

简记为 $\{X_t\}_{t \in T}$ 或 $\{X(t)\}_{t \in T}$。

### 1.2 分类

| 分类依据 | 类型 | 例子 |
|----------|------|------|
| $T$ 离散 / 连续 | 离散时间 / 连续时间 | 随机游走 / Brown 运动 |
| $S$ 离散 / 连续 | 离散状态 / 连续状态 | Markov 链 / 扩散过程 |
| 统计特性 | 平稳 / 非平稳 | 平稳过程 / Brown 运动 |
| 记忆性 | Markov / 非 Markov | Markov 链 / 一般过程 |

### 1.3 例子

| 过程 | 时间 | 状态 | 特征 |
|------|------|------|------|
| 随机游走 | 离散 | $\mathbb{Z}$ | 独立增量 |
| Markov 链 | 离散 | 有限/可数 | Markov 性 |
| Poisson 过程 | 连续 | $\mathbb{N}_0$ | 计数过程 |
| Brown 运动 | 连续 | $\mathbb{R}$ | 独立增量、连续轨道 |

## 2. 有限维分布族

### 2.1 定义

对任意 $t_1 < t_2 < \cdots < t_n$，$(X_{t_1}, \ldots, X_{t_n})$ 的联合分布：

$$F_{t_1, \ldots, t_n}(x_1, \ldots, x_n) = P(X_{t_1} \leq x_1, \ldots, X_{t_n} \leq x_n)$$

全体有限维分布构成**有限维分布族**。

### 2.2 相容性条件

1. **置换不变性**：对 $(1, \ldots, n)$ 的任意置换 $\pi$：

$$F_{t_{\pi(1)}, \ldots, t_{\pi(n)}}(x_{\pi(1)}, \ldots, x_{\pi(n)}) = F_{t_1, \ldots, t_n}(x_1, \ldots, x_n)$$

2. **边际相容性**：

$$F_{t_1, \ldots, t_{n-1}}(x_1, \ldots, x_{n-1}) = \lim_{x_n \to +\infty} F_{t_1, \ldots, t_n}(x_1, \ldots, x_n)$$

### 2.3 Kolmogorov 存在定理

**定理 2.1**：给定满足相容性条件的有限维分布族，存在概率空间和随机过程以之为有限维分布族。

> **意义**：构造随机过程的理论基础——先指定有限维分布，再保证存在性。

**推论 2.1**　随机过程在分布意义下由有限维分布族完全确定。

## 3. 均值函数与相关函数

### 3.1 数字特征

**均值函数**：$m(t) = E(X_t)$

**方差函数**：$D(t) = \text{Var}(X_t)$

**自相关函数**：$R(s, t) = E(X_s X_t)$

**自协方差函数**：$C(s, t) = \text{Cov}(X_s, X_t) = R(s, t) - m(s) m(t)$

### 3.2 性质

- $R(s, t) = R(t, s)$（对称性）
- $C(s, t) = C(t, s)$
- $|C(s, t)| \leq \sqrt{D(s) D(t)}$（Cauchy-Schwarz）
- $R(s, s) = E(X_s^2) \geq 0$

**推论 3.1**　自协方差矩阵是半正定的。

## 4. 独立增量过程

### 4.1 定义

**定义 4.1**：$\{X_t\}$ 有**独立增量**，若对 $t_0 < t_1 < \cdots < t_n$，增量 $X_{t_1} - X_{t_0}, \ldots, X_{t_n} - X_{t_{n-1}}$ 相互独立。

### 4.2 平稳独立增量

若增量 $X_{t+s} - X_s$ 的分布只依赖于 $t$（不依赖于 $s$），则称**平稳独立增量**。

**例子**：
- Poisson 过程
- Brown 运动
- 复合 Poisson 过程

### 4.3 性质

设 $\{X_t\}$ 有平稳独立增量，$E(X_t^2) < \infty$：

- $m(t) = m(0) + t \cdot m'(0)$（均值线性）
- $C(s, t) = \text{Var}(X_{\min(s,t)})$（协方差只依赖于较小时间）

**推论 4.1**　平稳独立增量过程的协方差函数只依赖于 $\min(s, t)$。

## 5. 鞅、上鞅、下鞅

### 5.1 定义

设 $\{\mathcal{F}_n\}$ 为递增 $\sigma$-代数列（信息流），$X_n$ 关于 $\mathcal{F}_n$ 适应，$E|X_n| < \infty$：

| 类型 | 条件 | 直觉 |
|------|------|------|
| **鞅** | $E(X_{n+1} \mid \mathcal{F}_n) = X_n$ | 公平博弈 |
| **下鞅** | $E(X_{n+1} \mid \mathcal{F}_n) \geq X_n$ | 期望增长 |
| **上鞅** | $E(X_{n+1} \mid \mathcal{F}_n) \leq X_n$ | 期望下降 |

### 5.2 常见例子

**鞅**：
- 独立零均值随机变量之和 $S_n = \sum_{i=1}^n X_i$
- $M_n = E(X \mid \mathcal{F}_n)$（Doob 鞅）
- Brown 运动 $B(t)$

**下鞅**：
- $X_n^2$（$X_n$ 为鞅时）
- $e^{X_n}$（$X_n$ 为独立增量过程时，适当条件下）

**推论 5.1**　凸函数作用于鞅得到下鞅（Jensen 不等式）。

## 6. 停时

### 6.1 定义

**定义 6.1**　随机变量 $\tau: \Omega \to \{0, 1, 2, \ldots\} \cup \{+\infty\}$ 是关于 $\{\mathcal{F}_n\}$ 的**停时**，若：

$$\{\tau = n\} \in \mathcal{F}_n, \quad \forall n \geq 0$$

等价地：$\{\tau \leq n\} \in \mathcal{F}_n$。

> **直觉**：在时刻 $n$，你已经能判断"是否在这一刻停止"。

### 6.2 例子

- 常数 $\tau = n$（确定性停时）
- 首次到达时间 $\tau_a = \inf\{n : X_n = a\}$（如随机游走首次到达某点）
- 首次离开区域的时间

### 6.3 停时的性质

- 停时的和、最大值、最小值仍是停时
- $\tau_1, \tau_2$ 停时 $\Rightarrow$ $\tau_1 \wedge \tau_2 = \min(\tau_1, \tau_2)$ 停时

**推论 6.1**　停时的最小值仍是停时——这是"最早停止时间"的数学表述。

## 7. 随机过程的构造方法

### 7.1 Kolmogorov 构造

指定有限维分布族，验证相容性，由存在定理保证。

### 7.2 转移概率方法

对 Markov 过程，指定初始分布 + 转移核即可构造。

### 7.3 随机微分方程

通过 Itô 积分构造扩散过程：

$$dX_t = \mu(X_t, t) \, dt + \sigma(X_t, t) \, dB_t$$
