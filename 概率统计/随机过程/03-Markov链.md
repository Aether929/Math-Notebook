# Markov 链

> "无记忆性"的随机过程——从 Google PageRank 到金融模型。

## 1. 定义与基本概念

### 1.1 定义

**定义 1.1**　离散时间随机过程 $\{X_n, n = 0, 1, 2, \ldots\}$ 是 **Markov 链**，若状态空间 $S$ 可数，且：

$$P(X_{n+1} = j \mid X_n = i, X_{n-1} = i_{n-1}, \ldots, X_0 = i_0) = P(X_{n+1} = j \mid X_n = i)$$

> **直觉**：未来只依赖于现在，与过去无关（"无记忆性"）。

**转移概率**：$p_{ij}(n) = P(X_{n+1} = j \mid X_n = i)$

**时齐**：$p_{ij}(n) = p_{ij}$ 与 $n$ 无关。以下默认时齐。

### 1.2 转移矩阵

$$P = (p_{ij})_{i, j \in S}, \quad p_{ij} \geq 0, \quad \sum_j p_{ij} = 1$$

（$P$ 是**随机矩阵**：非负，每行和为 $1$）

**$n$ 步转移概率**：$p_{ij}^{(n)} = P(X_{m+n} = j \mid X_m = i)$

**定理 1.1（Chapman-Kolmogorov 方程）**：

$$p_{ij}^{(m+n)} = \sum_{k \in S} p_{ik}^{(m)} p_{kj}^{(n)}, \quad P^{(n)} = P^n$$

**推论 1.1**　$P^{(n)} = P^n$（$n$ 步转移矩阵 = 转移矩阵的 $n$ 次幂）。

**推论 1.2**　初始分布 $\boldsymbol{\mu}$，$n$ 步后分布 $\boldsymbol{\mu}^{(n)} = \boldsymbol{\mu} P^n$。

## 2. 状态分类

### 2.1 可达与互通

- $j$ **可达** $i$（$i \to j$）：$\exists n \geq 0, p_{ij}^{(n)} > 0$
- $i$ **与** $j$ **互通**（$i \leftrightarrow j$）：$i \to j$ 且 $j \to i$

**定理 2.1**　互通是等价关系，状态空间可分解为互通等价类。

### 2.2 常返与非常返

**定义 2.1**　从 $i$ 出发，首次返回 $i$ 的概率：

$$f_{ii} = P(\text{存在 } n \geq 1: X_n = i \mid X_0 = i) = \sum_{n=1}^{\infty} f_{ii}^{(n)}$$

其中 $f_{ii}^{(n)} = P(X_n = i, X_k \neq i, 1 \leq k < n \mid X_0 = i)$。

- $f_{ii} = 1$：$i$ **常返**
- $f_{ii} < 1$：$i$ **非常返**

**定理 2.2**　$i$ 常返 $\iff$ $\sum_{n=0}^{\infty} p_{ii}^{(n)} = \infty$。

> **证明提示**：$f_{ii} < 1$ 时 $p_{ii}^{(n)}$ 的级数几何收敛；$f_{ii} = 1$ 时级数发散。

**推论 2.1**　常返状态的子集是闭集（非常返状态不能"支撑"常返状态）。

**推论 2.2**　有限状态 Markov 链至少有一个常返状态。

### 2.3 正常返与零常返

**平均返回时间**：$m_i = E(\tau_i \mid X_0 = i) = \sum_{n=1}^{\infty} n f_{ii}^{(n)}$

- $m_i < \infty$：**正常返**
- $m_i = \infty$：**零常返**

### 2.4 周期性

**周期**：$d(i) = \gcd\{n \geq 1 : p_{ii}^{(n)} > 0\}$

- $d(i) = 1$：**非周期**
- $d(i) > 1$：**周期为** $d(i)$

**定理 2.3**　同一互通类的状态有相同周期。

### 2.5 遍历

**定义 2.2**　正常返 + 非周期 = **遍历**

**定理 2.4**　遍历 $\iff$ 存在唯一平稳分布 $\boldsymbol{\pi}$，且 $\lim_{n \to \infty} p_{ij}^{(n)} = \pi_j$。

## 3. 闭集与不可约

### 3.1 闭集

**定义 3.1**　$C \subseteq S$ 是**闭集**，若 $i \in C, j \notin C \Rightarrow p_{ij} = 0$。

即从 $C$ 中出发不会离开 $C$。

### 3.2 不可约

**定义 3.2**　Markov 链**不可约**，若除 $\emptyset$ 外没有其他闭集（所有状态互通）。

### 3.3 吸收态

**定义 3.3**　状态 $i$ 是**吸收态**，若 $p_{ii} = 1$。

**定理 3.1**　不可约有限 Markov 链必正常返。

---

## 4. 平稳分布

### 4.1 定义

**定义 4.1**　概率分布 $\boldsymbol{\pi} = (\pi_i)_{i \in S}$ 是**平稳分布**（不变分布），若：

$$\boldsymbol{\pi} P = \boldsymbol{\pi}, \quad \sum_i \pi_i = 1$$

即 $\pi_j = \sum_i \pi_i p_{ij}$。

### 4.2 存在性与唯一性

**定理 4.1**：
- 不可约 Markov 链：
  - 正常返 $\iff$ 存在平稳分布，且 $\pi_i = 1/m_i$
  - 零常返或非常返 $\Rightarrow$ 无平稳分布
- 不可约正常返非周期（遍历）：唯一平稳分布，且 $\lim_{n \to \infty} p_{ij}^{(n)} = \pi_j$

**定理 4.2（遍历收敛定理）**　遍历 Markov 链的收敛速度为指数级：

$$\|P^n - \boldsymbol{\pi}\|_{\text{TV}} \leq C \rho^n$$

其中 $\rho < 1$ 与 $P$ 的**谱隙**（spectral gap）有关。

### 4.3 求解方法

解方程组 $\boldsymbol{\pi} P = \boldsymbol{\pi}$，$\sum \pi_i = 1$。

**定理 4.3（细致平衡条件）**　若 $\pi_i p_{ij} = \pi_j p_{ji}$（$\forall i, j$），则 $\boldsymbol{\pi}$ 是平稳分布。

> 满足细致平衡的 Markov 链称为**可逆 Markov 链**。反之不然。

**推论 4.1**　对称转移矩阵（$p_{ij} = p_{ji}$）的平稳分布为均匀分布。

## 5. 极限定理

### 5.1 遍历定理

**定理 5.1（Markov 链的强大数定律）**　不可约正常返 Markov 链，对任意函数 $f$：

$$\lim_{n \to \infty} \frac{1}{n} \sum_{k=0}^{n-1} f(X_k) = \sum_{i \in S} \pi_i f(i) \quad \text{a.s.}$$

> **意义**：时间平均 = 空间平均（遍历性）。

**推论 5.1**　$\lim_{n \to \infty} \frac{1}{n} \sum_{k=0}^{n-1} \mathbf{1}_{X_k = i} = \pi_i$（访问频率趋于平稳分布）。

### 5.2 吸收概率

**定理 5.2**　设 $T$ 为吸收态集合，$h_i = P(\text{被 } T \text{ 吸收} \mid X_0 = i)$，则 $h$ 满足：

$$h_i = \sum_j p_{ij} h_j \quad (i \notin T), \quad h_i = 1 \quad (i \in T)$$

## 6. 分支过程

### 6.1 定义

**Galton-Watson 分支过程**：$X_n$ = 第 $n$ 代个体数。每个个体独立产生随机数量的后代（分布 $\{p_k\}$）。

$$X_{n+1} = \sum_{i=1}^{X_n} \xi_i$$

其中 $\xi_i$ i.i.d.，$P(\xi = k) = p_k$。

### 6.2 灭绝概率

**母函数**：$G(s) = \sum p_k s^k$

**均值**：$\mu = G'(1) = \sum k p_k$

**定理 6.1**　灭绝概率 $q = P(X_n = 0 \text{ 对某 } n)$ 是 $G(s) = s$ 的最小非负根。

- $\mu \leq 1$ 且 $p_0 > 0$：$q = 1$（几乎必然灭绝）
- $\mu > 1$：$q < 1$（有正概率永不灭绝）
- $\mu = 1$，$p_0 = 0$：$q = 0$（永不灭绝，但 $\mu = 1$ 时个体数不增长）

**推论 6.1**　$\mu > 1$ 时，$X_n / \mu^n$ 几乎必然收敛（条件于不灭绝时趋于指数增长）。

## 7. 随机游走

### 7.1 简单随机游走

$$S_n = \sum_{i=1}^{n} X_i, \quad P(X_i = 1) = p, \quad P(X_i = -1) = 1 - p = q$$

**性质**：
- $E(S_n) = n(2p - 1)$
- $p = 1/2$ 时为鞅
- 一维简单随机游走是**常返的**（Polya 定理）

### 7.2 高维随机游走

**定理 7.1（Polya 定理）**：
- 一维、二维简单随机游走：常返
- 三维及以上：非常返

> **直觉**：维度越高，随机游走"越容易迷路"，不回到原点。
