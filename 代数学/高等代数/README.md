```
多项式理论 → 行列式 → 线性方程组 → 矩阵

              欧氏空间与酉空间 ← 线性变换 ← 线性空间
```

## 核心定理

| 定理 | 内容 |
|------|------|
| 因式分解唯一性 | $F[x]$ 中多项式可唯一分解为不可约多项式之积 |
| Eisenstein 判别法 | 素数 $p$ 满足三条件 $\Rightarrow$ 不可约 |
| Hamilton-Cayley | $f(A) = 0$，矩阵满足自己的特征方程 |
| 实对称矩阵谱定理 | 实对称矩阵可正交对角化 |
| 维数公式 | $\dim(W_1 + W_2) = \dim W_1 + \dim W_2 - \dim(W_1 \cap W_2)$ |
