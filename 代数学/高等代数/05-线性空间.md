# 线性空间

> 抽象化的力量——从具体向量到一般线性空间。

## 1. 线性空间的定义

**定义 1.1**　设 $V$ 是非空集合，$F$ 是数域。定义两种运算：

- **加法**：$V \times V \to V$，$(\boldsymbol{\alpha}, \boldsymbol{\beta}) \mapsto \boldsymbol{\alpha} + \boldsymbol{\beta}$
- **数乘**：$F \times V \to V$，$(k, \boldsymbol{\alpha}) \mapsto k\boldsymbol{\alpha}$

若满足八条公理（加法交换群 + 数乘分配律 + 数乘结合律 + $1\boldsymbol{\alpha} = \boldsymbol{\alpha}$），则称 $V$ 为 $F$ 上的**线性空间**（向量空间）。

**常见例子**：
- $F^n$：$n$ 维列向量
- $F[x]_n$：次数 $< n$ 的多项式
- $F^{m \times n}$：$m \times n$ 矩阵
- $C[a,b]$：$[a,b]$ 上的连续函数

---

## 2. 线性相关与基

**定义 2.1**　$\boldsymbol{\alpha}_1, \ldots, \boldsymbol{\alpha}_s$ **线性相关**：存在不全为零的 $k_1, \ldots, k_s$ 使 $k_1 \boldsymbol{\alpha}_1 + \cdots + k_s \boldsymbol{\alpha}_s = \mathbf{0}$。

**定义 2.2**　$\boldsymbol{\alpha}_1, \ldots, \boldsymbol{\alpha}_s$ **线性无关**：$k_1 \boldsymbol{\alpha}_1 + \cdots + k_s \boldsymbol{\alpha}_s = \mathbf{0}$ $\Rightarrow$ $k_1 = \cdots = k_s = 0$。

**定义 2.3**　$\boldsymbol{\alpha}$ 可由 $\boldsymbol{\alpha}_1, \ldots, \boldsymbol{\alpha}_s$ **线性表示**：存在 $k_1, \ldots, k_s$ 使 $\boldsymbol{\alpha} = k_1 \boldsymbol{\alpha}_1 + \cdots + k_s \boldsymbol{\alpha}_s$。

**定义 2.4**　向量组 $\{\boldsymbol{\alpha}_i\}$ 与 $\{\boldsymbol{\beta}_j\}$ **等价**：可互相线性表示。

**定理 2.1**　等价的线性无关向量组含向量个数相同。

> **证明提示**：设 $|\{\boldsymbol{\alpha}_i\}| = s$，$|\{\boldsymbol{\beta}_j\}| = t$，$s > t$。将 $\boldsymbol{\alpha}_i$ 用 $\boldsymbol{\beta}_j$ 表示，代入线性关系后利用 $\boldsymbol{\beta}_j$ 的无关性推出矛盾。

**定义 2.5**　**基**：线性无关的生成组。**维数**：基中向量个数，记 $\dim V$。

**定理 2.2**　$V$ 的任何两组基含向量个数相同。

**定理 2.3**　$\dim V = n$ 时：
1. 任何 $n$ 个线性无关的向量构成基
2. 任何 $n$ 个生成向量构成基
3. 任何线性无关组可扩充为基

---

## 3. 坐标与过渡矩阵

**定义 3.1**　设基 $\boldsymbol{\varepsilon}_1, \ldots, \boldsymbol{\varepsilon}_n$，$\boldsymbol{\alpha} = x_1 \boldsymbol{\varepsilon}_1 + \cdots + x_n \boldsymbol{\varepsilon}_n$，则 $(x_1, \ldots, x_n)^T$ 为 $\boldsymbol{\alpha}$ 在此基下的**坐标**。

**定义 3.2**　从基 $\boldsymbol{\varepsilon}$ 到基 $\boldsymbol{\eta}$ 的**过渡矩阵** $T$：

$$(\boldsymbol{\eta}_1, \ldots, \boldsymbol{\eta}_n) = (\boldsymbol{\varepsilon}_1, \ldots, \boldsymbol{\varepsilon}_n) T$$

**定理 3.1（坐标变换公式）**　若 $\boldsymbol{\alpha}$ 在旧基下坐标为 $\mathbf{x}$，在新基下坐标为 $\mathbf{y}$，则

$$\mathbf{x} = T \mathbf{y}$$

**定理 3.2**　过渡矩阵 $T$ 可逆，且从 $\boldsymbol{\eta}$ 到 $\boldsymbol{\varepsilon}$ 的过渡矩阵为 $T^{-1}$。

---

## 4. 子空间

**定义 4.1**　$W \subseteq V$，若 $W$ 对加法和数乘封闭，则 $W$ 为 $V$ 的**子空间**。

**常见子空间**：
- $\ker A = \{\mathbf{x} : A\mathbf{x} = \mathbf{0}\}$（零空间/核）
- $\operatorname{Im} A = \{A\mathbf{x} : \mathbf{x} \in F^n\}$（列空间/像）
- $\operatorname{span}\{\boldsymbol{\alpha}_1, \ldots, \boldsymbol{\alpha}_s\}$（生成子空间）

**定理 4.1**　$W_1 \cap W_2$ 是子空间。

**定理 4.2**　$W_1 \cup W_2$ 一般不是子空间（除非一个包含另一个）。

**定理 4.3**　$W_1 + W_2 = \{\boldsymbol{\alpha}_1 + \boldsymbol{\alpha}_2 : \boldsymbol{\alpha}_i \in W_i\}$ 是子空间。

---

## 5. 维数公式

**定理 5.1（维数公式）**：

$$\dim(W_1 + W_2) = \dim W_1 + \dim W_2 - \dim(W_1 \cap W_2)$$

> **证明提示**：取 $W_1 \cap W_2$ 的基，分别扩充为 $W_1$ 和 $W_2$ 的基，证明合起来是 $W_1 + W_2$ 的基。

**推论 5.1**　$\dim(W_1 + W_2) \leq \dim W_1 + \dim W_2$，等号 $\iff$ $W_1 \cap W_2 = \{\mathbf{0}\}$。

---

## 6. 直和

**定义 6.1**　$W_1 + W_2$ 为**直和**（记 $W_1 \oplus W_2$），若 $W_1 \cap W_2 = \{\mathbf{0}\}$。

**等价条件**（以下等价）：
1. $W_1 \cap W_2 = \{\mathbf{0}\}$
2. $W_1 + W_2$ 中每个向量的分解唯一
3. 零向量的分解唯一（$\mathbf{0} = \mathbf{0} + \mathbf{0}$ 是唯一的）
4. $\dim(W_1 + W_2) = \dim W_1 + \dim W_2$

**定义 6.2**　$V$ 的**补子空间**：若 $V = W \oplus W'$，则 $W'$ 为 $W$ 的补。

**定理 6.1**　任何子空间都有补子空间。

> **证明提示**：取 $W$ 的基，扩充为 $V$ 的基，剩余部分生成的子空间即为补。

**推广**：$V = W_1 \oplus W_2 \oplus \cdots \oplus W_k$（直和），等价于 $\sum \dim W_i = \dim V$ 且各 $W_i$ 的基合起来线性无关。

---

## 7. 商空间

**定义 7.1**　$W$ 为 $V$ 的子空间，定义**陪集**：$\boldsymbol{\alpha} + W = \{\boldsymbol{\alpha} + \boldsymbol{w} : \boldsymbol{w} \in W\}$。

**定义 7.2**　**商空间** $V/W = \{\boldsymbol{\alpha} + W : \boldsymbol{\alpha} \in V\}$，加法和数乘定义为：

$$(\boldsymbol{\alpha} + W) + (\boldsymbol{\beta} + W) = (\boldsymbol{\alpha} + \boldsymbol{\beta}) + W$$
$$k(\boldsymbol{\alpha} + W) = k\boldsymbol{\alpha} + W$$

**定理 7.1**　$\dim(V/W) = \dim V - \dim W$。

---

## 8. 子空间的交与和

**定理 8.1**　设 $W_1, \ldots, W_k$ 为子空间，则

$$\dim(W_1 + \cdots + W_k) \leq \dim W_1 + \cdots + \dim W_k$$

等号成立当且仅当各 $W_i$ 的基合起来线性无关（即为直和）。

**定理 8.2（Grassmann 公式的推广）**　对三个子空间：

$$\dim(W_1 + W_2 + W_3) = \sum \dim W_i - \sum \dim(W_i \cap W_j) + \dim(W_1 \cap W_2 \cap W_3) + \delta$$

其中 $\delta \geq 0$，等号不一定成立（Grassmann 公式对三个子空间不精确）。
