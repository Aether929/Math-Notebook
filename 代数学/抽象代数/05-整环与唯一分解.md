# 整环与唯一分解

> 从整数的算术性质抽象出的代数结构层次。

## 1. 整环的层次

四种环的递进关系：

$$\text{域} \subsetneq \text{欧几里得环} \subsetneq \text{主理想整环 (PID)} \subsetneq \text{唯一分解整环 (UFD)} \subsetneq \text{整环}$$

| 性质 | 域 | 欧几里得环 | PID | UFD |
|------|:--:|:--:|:--:|:--:|
| 有单位元 | ✓ | ✓ | ✓ | ✓ |
| 无零因子 | ✓ | ✓ | ✓ | ✓ |
| 不可约 = 素元 | ✓ | ✓ | ✓ | ✓ |
| 唯一分解 | ✓ | ✓ | ✓ | ✓ |
| 理想都是主理想 | ✓ | ✓ | ✓ | — |
| 有欧几里得函数 | ✓ | ✓ | — | — |

## 2. 整除与相伴

**定义 2.1**　$a \mid b$：存在 $c$ 使 $b = ac$。

**定义 2.2**　$a \sim b$（相伴）：$a \mid b$ 且 $b \mid a$，即 $a = ub$（$u$ 为单位）。

**定义 2.3**　$p$ 是**不可约元**：$p = ab \Rightarrow$ $a$ 或 $b$ 是单位。

**定义 2.4**　$p$ 是**素元**：$p \mid ab \Rightarrow$ $p \mid a$ 或 $p \mid b$。

**命题 2.1**　素元 $\Rightarrow$ 不可约元（反之在一般整环中不一定成立）。

> **证明提示**：设 $p = ab$，$p \mid ab$，故 $p \mid a$ 或 $p \mid b$。若 $p \mid a$，则 $a = pc$，$p = pcb$，消去 $p$ 得 $cb = 1$，$b$ 是单位。

**命题 2.2**　在整环中，$a \mid b$ 且 $b \mid a$ $\iff$ $a = ub$（$u$ 为单位）。

> **证明提示**：$a = bc$，$b = ad$，则 $a = adc$，消去 $a$ 得 $dc = 1$。

## 3. 唯一分解整环 (UFD)

**定义 3.1**　整环 $R$ 是**唯一分解整环**：每个非零非单位元素可唯一（不计次序和相伴）分解为不可约元之积。

**定理 3.1**　UFD 中不可约元 = 素元。

> **证明提示**：设 $p$ 不可约，$p \mid ab$。将 $a, b$ 分解为不可约元，$p$ 在 $ab$ 的分解中出现，由唯一性，$p$ 必出现在 $a$ 或 $b$ 的分解中。

**定理 3.2**　UFD 中 $\gcd$ 存在（但不一定可表为线性组合）。

**定理 3.3**　整环 $R$ 是 UFD $\iff$

1. 每个非零非单位元素可分解为不可约元之积（存在性）
2. 不可约元是素元（唯一性）

**推论 3.1**　UFD 中 $a, b$ 的 $\gcd$ 存在且在相伴意义下唯一。

**推论 3.2**　UFD 中 $\operatorname{lcm}$ 也存在：$\operatorname{lcm}(a, b) = ab / \gcd(a, b)$（在相伴意义下）。

## 4. 主理想整环 (PID)

**定义 4.1**　整环 $R$ 是**主理想整环**：每个理想都是主理想。

**定理 4.1**　PID $\Rightarrow$ UFD。

> **证明提示**：(1) 存在性：若 $a$ 不能分解为不可约元之积，则 $a = a_1 b_1$，$a_1$ 或 $b_1$ 也不能分解。得无穷升链 $(a) \subsetneq (a_1) \subsetneq \cdots$，与 PID 矛盾。(2) 素元性：$(p) = (a)(b)$ 中 $p$ 不可约推出 $a$ 或 $b$ 是单位。

**定理 4.2**　PID 中不可约元 = 素元 = 极大元（生成的主理想是极大理想）。

> **证明提示**：$(p)$ 极大 $\Rightarrow$ $R/(p)$ 是域 $\Rightarrow$ $R/(p)$ 是整环 $\Rightarrow$ $(p)$ 素理想 $\Rightarrow$ $p$ 是素元。

**定理 4.3**　PID 中 Bézout 等式成立：$(a, b) = (d)$，存在 $u, v$ 使 $ua + vb = d$。

**推论 4.1**　PID 中 $\gcd$ 不仅存在，还可表为线性组合。

**推论 4.2**　$\mathbb{Z}$ 和 $F[x]$（$F$ 为域）都是 PID。

---

## 5. 欧几里得环

**定义 5.1**　整环 $R$ 是**欧几里得环**：存在函数 $\varphi: R \setminus \{0\} \to \mathbb{N}$ 使对任意 $a, b$（$b \neq 0$），存在 $q, r$ 满足

$$a = bq + r, \quad r = 0 \text{ 或 } \varphi(r) < \varphi(b)$$

**定理 5.1**　欧几里得环 $\Rightarrow$ PID。

> **证明提示**：设 $I$ 为理想，取 $\varphi$ 值最小的非零元 $b$，用带余除法证 $I = (b)$。

**例子**：
- $\mathbb{Z}$（$\varphi(n) = |n|$）
- $\mathbb{Z}[i]$（高斯整环，$\varphi(a+bi) = a^2+b^2$）
- $F[x]$（$\varphi(f) = \deg f$）

**推论 5.1**　$\mathbb{Z}[i]$ 中唯一分解成立——这是 Fermat 二平方和定理的代数基础。

## 6. 主理想整环上的模

**定理 6.1（有限生成 Abel 群基本定理）**　有限生成 Abel 群

$$G \cong \mathbb{Z}^r \oplus \mathbb{Z}_{d_1} \oplus \cdots \oplus \mathbb{Z}_{d_k}$$

其中 $d_1 \mid d_2 \mid \cdots \mid d_k$（不变因子），$r$ 为**秩**。

> **证明提示**：$G \cong \mathbb{Z}^n / M$，$M$ 为子模。用 Smith 标准形将 $M$ 的关系矩阵对角化。

**推论 6.1（初等因子分解）**：

$$G \cong \mathbb{Z}^r \oplus \mathbb{Z}_{p_1^{e_1}} \oplus \cdots \oplus \mathbb{Z}_{p_s^{e_s}}$$

**推论 6.2**　有限 Abel 群的阶确定了初等因子（同构意义下唯一）。

**推论 6.3**　$n$ 阶有限 Abel 群的同构类个数等于 $n$ 的**分拆数**（将 $n$ 的每个素因子幂分拆的方式数的乘积）。

## 7. 多项式环的 UFD 性质

**定理 7.1（Gauss 引理）**　$R$ 是 UFD $\Rightarrow$ $R[x]$ 也是 UFD。

> **证明提示**：(1) 本原多项式的乘积是本原多项式。(2) $R[x]$ 中不可约元要么是 $R$ 中的不可约元，要么是本原不可约多项式。(3) 利用 $R$ 的唯一分解和本原多项式的性质。

**推论 7.1**　$\mathbb{Z}[x]$ 是 UFD（但不是 PID）。

**推论 7.2**　$F[x_1, \ldots, x_n]$ 是 UFD（$F$ 为域）。

**推论 7.3**　UFD 中本原多项式在 $R[x]$ 中不可约 $\iff$ 在 $\operatorname{Frac}(R)[x]$ 中不可约。

## 8. Noether 环

**定义 8.1**　环 $R$ 是 **Noether 环**：理想升链条件——任何理想升链 $I_1 \subseteq I_2 \subseteq \cdots$ 最终稳定。

等价条件：
1. 升链条件
2. 每个理想都是有限生成的

**定理 8.1（Hilbert 基定理）**　$R$ 是 Noether 环 $\Rightarrow$ $R[x]$ 也是 Noether 环。

**推论 8.1**　$F[x_1, \ldots, x_n]$ 是 Noether 环（$F$ 为域）。

**推论 8.2**　Noether 环中每个理想可分解为有限个准素理想的交（Lasker–Noether 定理）。

**推论 8.3**　PID 是 Noether 环（主理想自动有限生成）。

## 9. 反例与边界

| 环 | UFD? | PID? | 说明 |
|----|:----:|:----:|------|
| $\mathbb{Z}$ | ✓ | ✓ | 标准例子 |
| $\mathbb{Z}[x]$ | ✓ | ✗ | $(2, x)$ 不是主理想 |
| $\mathbb{Z}[\sqrt{-5}]$ | ✗ | ✗ | $6 = 2 \cdot 3 = (1+\sqrt{-5})(1-\sqrt{-5})$，分解不唯一 |
| $F[x, y]$ | ✓ | ✗ | $(x, y)$ 不是主理想 |
| $\mathbb{Z}[x]/(x^2+1) \cong \mathbb{Z}[i]$ | ✓ | ✓ | 高斯整环 |
