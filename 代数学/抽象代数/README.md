## 核心定理

| 定理 | 内容 |
|------|------|
| Lagrange 定理 | $\|G\| = [G:H] \cdot \|H\|$ |
| Cayley 定理 | 任何群同构于置换群 |
| Sylow 定理 | $p$-子群存在、共轭、$n_p \equiv 1 \pmod{p}$ |
| 群同态基本定理 | $G/\ker \varphi \cong \operatorname{Im} \varphi$ |
| Galois 对应 | 中间域与 Galois 群子群反序一一对应 |
| Galois 可解性定理 | 方程可用根式求解 $\iff$ Galois 群可解 |
