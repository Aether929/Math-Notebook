## 学习路线

```
向量空间 → 线性变换与矩阵 → 特征值与特征向量 → Jordan 标准形
                                                      ↓
                         二次型 ← 正交化与正交投影 ← 内积空间
```

## 核心定理

| 定理 | 内容 |
|------|------|
| 秩—零化度定理 | $\dim \ker A + \dim \operatorname{Im} A = n$ |
| 对角化条件 | $A$ 可对角化 $\iff$ 几何重数 $=$ 代数重数 |
| Hamilton-Cayley | $f(A) = 0$ |
| Jordan 标准形定理 | 任何复矩阵相似于 Jordan 标准形 |
| 实对称矩阵谱定理 | 可正交对角化，特征值都是实数 |
| 惯性定理 | 正、负惯性指数是合同不变量 |
| Rayleigh 商 | $\lambda_{\min} \leq \frac{\mathbf{x}^T A \mathbf{x}}{\|\mathbf{x}\|^2} \leq \lambda_{\max}$ |
