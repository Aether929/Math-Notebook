# 初等函数

> 复数域上的基本函数——指数、对数、幂、三角函数。

## 1. 指数函数

### 1.1 定义

**定义 1.1**：$e^z = e^{x+iy} = e^x(\cos y + i \sin y)$

**性质**：
- $e^z$ 是整函数（全平面解析）
- $e^{z_1 + z_2} = e^{z_1} e^{z_2}$
- $|e^z| = e^x$，$\arg e^z = y$
- $e^z$ 以 $2\pi i$ 为周期

**推论 1.1**　复指数函数是周期函数——与实指数函数的根本区别。

**推论 1.2**　$e^z = 1 \iff z = 2k\pi i$（$k \in \mathbb{Z}$）。

### 1.2 映射性质

$w = e^z$ 将：
- 水平线 $y = c$ 映为射线 $\arg w = c$
- 垂直线 $x = c$ 映为圆 $|w| = e^c$
- 带域 $0 < y < 2\pi$ 映为去掉正实轴的复平面

**推论 1.3**　指数函数将带域映为角域——共形映射的基本构件。

---

## 2. 对数函数

### 2.1 定义

**定义 2.1**：$\log z = \ln|z| + i \arg z$（多值函数）

**主值**：$\text{Log}\, z = \ln|z| + i \text{Arg}\, z$，$\text{Arg}\, z \in (-\pi, \pi]$

**性质**：
- $\log(z_1 z_2) = \log z_1 + \log z_2$（模 $2\pi i$）
- $\log(e^z) = z + 2k\pi i$
- $e^{\log z} = z$

**推论 2.1**　对数函数的多值性来源于辐角的多值性——Riemann 面。

### 2.2 分支

**定义 2.2**：**分支**是 $\log z$ 的单值连续选择。

**分支切割**：去掉一条从原点出发的射线（如负实轴），在剩余区域可选单值分支。

**推论 2.2**　分支切割将多值函数变为单值——但改变了区域的拓扑。

### 2.3 导数

$$\frac{d}{dz} \log z = \frac{1}{z}$$

**推论 2.3**　$\log z$ 是 $1/z$ 的原函数——在去掉分支切割的区域内。

---

## 3. 一般幂函数

### 3.1 定义

**定义 3.1**：$z^\alpha = e^{\alpha \log z}$（多值函数，$\alpha \in \mathbb{C}$）

**主值**：$z^\alpha = e^{\alpha \text{Log}\, z}$

### 3.2 特殊情形

**整数幂**：$z^n$ 是单值函数。

**分数幂**：$z^{1/n}$ 有 $n$ 个分支——$n$ 次方根。

$$z^{1/n} = |z|^{1/n} e^{i(\arg z + 2k\pi)/n}, \quad k = 0, 1, \ldots, n-1$$

**推论 3.1**　$z^{1/n}$ 的 $n$ 个值在圆周上均匀分布。

### 3.3 导数

$$\frac{d}{dz} z^\alpha = \alpha z^{\alpha - 1}$$

## 4. 三角函数与双曲函数

### 4.1 定义

$$\cos z = \frac{e^{iz} + e^{-iz}}{2}, \quad \sin z = \frac{e^{iz} - e^{-iz}}{2i}$$

$$\cosh z = \frac{e^z + e^{-z}}{2}, \quad \sinh z = \frac{e^z - e^{-z}}{2}$$

### 4.2 关系

$$\cos(iz) = \cosh z, \quad \sin(iz) = i \sinh z$$
$$\cosh(iz) = \cos z, \quad \sinh(iz) = i \sin z$$

**推论 4.1**　三角函数与双曲函数通过虚数单位互化。

### 4.3 性质

- $\cos z$ 和 $\sin z$ 是整函数
- $\sin^2 z + \cos^2 z = 1$
- $\cos z$ 和 $\sin z$ 以 $2\pi$ 为周期
- $|\sin z|$ 和 $|\cos z|$ 无界——与实变函数不同

**推论 4.2**　复三角函数无界——$\sin(iy) = i \sinh y$ 指数增长。

### 4.4 零点

$$\sin z = 0 \iff z = k\pi, \quad k \in \mathbb{Z}$$
$$\cos z = 0 \iff z = \frac{\pi}{2} + k\pi, \quad k \in \mathbb{Z}$$

**推论 4.3**　复三角函数的零点与实变函数相同——没有新的零点。

---

## 5. 反三角函数

### 5.1 定义

$$\text{arcsin}\, z = -i \log(iz + \sqrt{1 - z^2})$$
$$\text{arccos}\, z = -i \log(z + \sqrt{z^2 - 1})$$
$$\text{arctan}\, z = \frac{1}{2i} \log\frac{1 + iz}{1 - iz}$$

**推论 5.1**　反三角函数通过对数定义——多值函数。

---

## 6. Riemann 面

### 6.1 概念

**定义 6.1**：**Riemann 面**是使多值函数变为单值的几何构造。

### 6.2 $\log z$ 的 Riemann 面

无穷多叶，沿正实轴切割，每叶对应辐角的一个 $2\pi$ 区间。

### 6.3 $z^{1/n}$ 的 Riemann 面

$n$ 叶，沿正实轴切割，绕原点一圈换一叶。

**推论 6.1**　Riemann 面将多值函数的"多值性"可视化为多叶结构。
