# 复数与复变函数

> 从实数到复数——解析函数的基础。

## 1. 复数

### 1.1 定义与运算

**定义 1.1**　**复数** $z = x + iy$，其中 $x = \text{Re}(z)$（实部），$y = \text{Im}(z)$（虚部），$i^2 = -1$。

**运算**：

$$z_1 + z_2 = (x_1 + x_2) + i(y_1 + y_2)$$
$$z_1 z_2 = (x_1 x_2 - y_1 y_2) + i(x_1 y_2 + x_2 y_1)$$

### 1.2 模与辐角

**模**：$|z| = \sqrt{x^2 + y^2}$

**辐角**：$\arg z = \arctan\frac{y}{x}$（多值，取主值 $\text{Arg}\, z \in (-\pi, \pi]$）

**极坐标形式**：$z = r e^{i\theta} = r(\cos\theta + i\sin\theta)$

**推论 1.1**　$|z_1 z_2| = |z_1| |z_2|$，$\arg(z_1 z_2) = \arg z_1 + \arg z_2$——乘法 = 模相乘、辐角相加。

### 1.3 基本不等式

**定理 1.1**（三角不等式）：$|z_1 + z_2| \leq |z_1| + |z_2|$，$||z_1| - |z_2|| \leq |z_1 - z_2|$。

**推论 1.2**　三角不等式在复平面上的几何意义——三角形两边之和大于第三边。

## 2. 复平面拓扑

### 2.1 基本概念

**邻域**：$N(z_0, \delta) = \{z : |z - z_0| < \delta\}$

**开集**：每点都有邻域包含在集合内

**闭集**：补集为开集

**连通**：不能分解为两个非空不相交开集的并

**单连通**：任意闭曲线可在区域内连续缩为一点

**推论 2.1**　单连通区域内"无洞"——Cauchy 定理成立的关键条件。

### 2.2 扩充复平面

**定义 2.1**：$\hat{\mathbb{C}} = \mathbb{C} \cup \{\infty\}$（Riemann 球面）。

**球极投影**：复平面与球面的一一对应。

**推论 2.2**　扩充复平面是紧致的——无穷远点"封闭"了复平面。

## 3. 复变函数

### 3.1 定义

**定义 3.1**：$w = f(z) = u(x, y) + iv(x, y)$ 是复变函数，$z = x + iy$。

**极限**：$\lim_{z \to z_0} f(z) = L$ $\iff$ $\forall \varepsilon > 0, \exists \delta > 0: 0 < |z - z_0| < \delta \Rightarrow |f(z) - L| < \varepsilon$。

**连续**：$\lim_{z \to z_0} f(z) = f(z_0)$。

**推论 3.1**　复变函数的极限要求从所有方向趋近——比实变函数更强。

### 3.2 导数

**定义 3.2**：$f'(z_0) = \lim_{\Delta z \to 0} \frac{f(z_0 + \Delta z) - f(z_0)}{\Delta z}$

要求极限与 $\Delta z \to 0$ 的方式无关——沿任意路径趋近得到相同结果。

---

## 4. 解析函数

### 4.1 定义

**定义 4.1**：$f(z)$ 在 $z_0$ **解析**（全纯），若在 $z_0$ 的某个邻域内处处可导。

在区域 $D$ 内解析 = 在 $D$ 内每点解析。

**推论 4.1**　解析比可导更强——要求在邻域内可导，不只是某一点。

### 4.2 Cauchy-Riemann 方程

**定理 4.1**：$f(z) = u + iv$ 在 $z_0$ 可导的必要条件：

$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$$

**定理 4.2**：若 $u, v$ 的偏导数连续且满足 C-R 方程，则 $f$ 解析。

**推论 4.2**　C-R 方程将复变函数的可导性转化为实变函数的偏微分方程。

**推论 4.3**　解析函数的实部和虚部都是调和函数（$\Delta u = 0$，$\Delta v = 0$）。

### 4.3 解析函数的性质

**定理 4.3**：
- 解析函数的和、积、商（分母不为零）仍解析
- 解析函数的复合仍解析
- 解析函数的导数仍解析（无穷次可导）

**推论 4.4**　解析函数自动无穷次可导——实变函数中不存在类似性质。

**推论 4.5**　解析函数的实部和虚部互为**共轭调和函数**。

## 5. 导数的几何意义

### 5.1 模与辐角

设 $f'(z_0) = R e^{i\alpha}$：

- **模** $R = |f'(z_0)|$：伸缩因子
- **辐角** $\alpha = \arg f'(z_0)$：旋转角

**推论 5.1**　解析函数的导数 = 无穷小旋转 + 伸缩——这是共形映射的基础。

### 5.2 共形性

**定义 5.2**：$f$ 在 $z_0$ **共形**（保角），若：
1. 保持角度大小
2. 保持方向（定向）

**定理 5.1**：$f'(z_0) \neq 0$ $\Rightarrow$ $f$ 在 $z_0$ 共形。

**推论 5.2**　非零导数保证共形——解析函数（导数非零处）是共形映射。

## 6. 调和函数

### 6.1 定义

**定义 6.1**：$u(x, y)$ 是**调和函数**，若 $\Delta u = u_{xx} + u_{yy} = 0$。

### 6.2 与解析函数的关系

**定理 6.1**：在单连通区域内，调和函数 $u$ 的共轭调和函数 $v$ 存在（相差常数），使得 $f = u + iv$ 解析。

**推论 6.1**　调和函数可以"提升"为解析函数——复分析方法可用于研究调和函数。

### 6.3 均值性质

**定理 6.2**：调和函数在圆心的值等于圆周上的平均值：

$$u(z_0) = \frac{1}{2\pi} \int_0^{2\pi} u(z_0 + r e^{i\theta}) \, d\theta$$

**推论 6.2**　调和函数没有内极值——极值原理。
