# $L^p$ 空间

> 函数构成的 Banach 空间——分析与几何的交汇。

## 1. 定义与范数

### 1.1 $L^p$ 空间

**定义 1.1**　设 $(X, \mathcal{A}, \mu)$ 为测度空间，$1 \leq p < \infty$：

$$L^p(X) = \left\{ f : X \to \mathbb{R} \text{ 可测}, \int_X |f|^p \, d\mu < \infty \right\}$$

**$L^\infty$ 空间**（本性有界函数）：

$$L^\infty(X) = \left\{ f : f \text{ 可测}, \exists M, |f(x)| \leq M \text{ a.e.} \right\}$$

### 1.2 范数

$$\|f\|_p = \left(\int_X |f|^p \, d\mu\right)^{1/p}, \quad \|f\|_\infty = \text{ess sup} |f| = \inf\{M : |f| \leq M \text{ a.e.}\}$$

> **注意**：$\|f\|_p = 0 \Leftrightarrow f = 0$ a.e.，所以 $L^p$ 中的元素实际上是等价类 $[f] = \{g : g = f \text{ a.e.}\}$。

## 2. 不等式

### 2.1 Hölder 不等式

**定理 2.1（Hölder 不等式）**　设 $1 < p, q < \infty$，$\frac{1}{p} + \frac{1}{q} = 1$，$f \in L^p, g \in L^q$，则 $fg \in L^1$ 且：

$$\int |fg| \leq \|f\|_p \cdot \|g\|_q$$

**特殊情况**：
- $p = q = 2$：**Cauchy-Schwarz 不等式** $\int |fg| \leq \|f\|_2 \|g\|_2$
- $p = 1, q = \infty$：$\int |fg| \leq \|f\|_1 \|g\|_\infty$

> **证明提示**：利用 Young 不等式 $ab \leq \frac{a^p}{p} + \frac{b^q}{q}$。

**推论 2.1**　Hölder 不等式中等号成立 $\iff$ $|f|^p$ 与 $|g|^q$ 成比例 a.e.

### 2.2 Minkowski 不等式

**定理 2.2（Minkowski 不等式）**　设 $1 \leq p \leq \infty$，$f, g \in L^p$，则：

$$\|f + g\|_p \leq \|f\|_p + \|g\|_p$$

> **意义**：Minkowski 不等式说明 $\|\cdot\|_p$ 满足三角不等式，因此 $L^p$ 是赋范空间。

**证明提示**：$p = 1$ 直接由绝对值不等式；$p > 1$ 用 Hölder 不等式。

### 2.3 Jensen 不等式

**定理 2.3（Jensen 不等式）**　设 $\varphi$ 为凸函数，$f \in L^1$，$m(E) = 1$：

$$\varphi\left(\frac{1}{m(E)} \int_E f \, dm\right) \leq \frac{1}{m(E)} \int_E \varphi(f) \, dm$$

---

## 3. $L^p$ 空间的性质

### 3.1 完备性

**定理 3.1（Riesz-Fischer 定理）**：$L^p$（$1 \leq p \leq \infty$）是完备的赋范空间（Banach 空间）。

> **证明思路**：取 Cauchy 列，选收敛子列，用 Fatou 引理证明极限在 $L^p$ 中。

### 3.2 稠密性

**定理 3.2**：
- 简单函数在 $L^p$（$1 \leq p < \infty$）中稠密
- 连续函数在 $L^p(\mathbb{R}^n)$（$1 \leq p < \infty$）中稠密
- $C_c^\infty(\mathbb{R}^n)$（光滑紧支函数）在 $L^p(\mathbb{R}^n)$ 中稠密

**推论 3.1**　$L^p$（$1 \leq p < \infty$）可分（存在可数稠密子集）。

### 3.3 可分性

**定理 3.3**：$L^p(\mathbb{R}^n)$（$1 \leq p < \infty$）是可分的（存在可数稠密子集）。

$L^\infty$ 不可分。

### 3.4 $L^p$ 之间的关系

设 $m(X) < \infty$：

$$p < q \Rightarrow L^q(X) \subseteq L^p(X), \quad \|f\|_p \leq m(X)^{1/p - 1/q} \|f\|_q$$

> **直觉**：在有限测度空间上，$p$ 越大，空间越小（高次可积要求更强）。

**推论 3.2**　在有限测度空间上，$L^\infty \subseteq L^q \subseteq L^p \subseteq L^1$（$1 \leq p \leq q \leq \infty$）。

---

## 4. $L^2$ 空间

### 4.1 内积

$L^2$ 上可定义内积：

$$\langle f, g \rangle = \int_X f(x) g(x) \, d\mu$$

这使 $L^2$ 成为 Hilbert 空间（完备的内积空间）。

### 4.2 正交性

- $f \perp g \iff \langle f, g \rangle = 0$
- **正交系**：$\{e_n\}$ 两两正交
- **标准正交系**：$\|e_n\|_2 = 1$

### 4.3 Fourier 级数

$\{e^{inx}\}_{n \in \mathbb{Z}}$ 是 $L^2[-\pi, \pi]$ 的标准正交基：

$$f = \sum_{n=-\infty}^{\infty} \hat{f}(n) e^{inx}, \quad \hat{f}(n) = \frac{1}{2\pi} \int_{-\pi}^{\pi} f(x) e^{-inx} \, dx$$

**Parseval 等式**：$\|f\|_2^2 = \sum |\hat{f}(n)|^2$

> **意义**：Fourier 变换是 $L^2$ 上的等距同构。

**推论 4.1**　$\{e^{inx}/\sqrt{2\pi}\}$ 是 $L^2[-\pi, \pi]$ 的标准正交基。

---

## 5. 对偶空间

### 5.1 $L^p$ 的对偶

**定理 5.1**　设 $1 \leq p < \infty$，$\frac{1}{p} + \frac{1}{q} = 1$，则：

$$(L^p)^* \cong L^q$$

即对任意 $\phi \in (L^p)^*$，存在唯一的 $g \in L^q$ 使得：

$$\phi(f) = \int fg \, d\mu, \quad \|\phi\| = \|g\|_q$$

**特殊情况**：
- $(L^1)^* \cong L^\infty$
- $(L^2)^* \cong L^2$（自对偶）
- $(L^\infty)^*$ 严格大于 $L^1$

> **意义**：$L^p$ 的对偶是 $L^q$（$1/p + 1/q = 1$），这是 Hölder 不等式的"对偶"体现。

---

## 6. 弱收敛

### 6.1 弱收敛的定义

**定义 6.1**　$f_n \rightharpoonup f$（弱收敛）：

$$\forall \phi \in (L^p)^*, \quad \phi(f_n) \to \phi(f)$$

等价地：$\forall g \in L^q$，$\int f_n g \to \int fg$。

### 6.2 性质

- 强收敛（范数收敛）$\Rightarrow$ 弱收敛
- 弱收敛 $\not\Rightarrow$ 强收敛
- $\|f\|_p \leq \liminf \|f_n\|_p$（范数下半连续）

### 6.3 $L^p$ 中弱紧性

**定理 6.1**　设 $1 < p < \infty$，$\{f_n\}$ 在 $L^p$ 中有界，则存在子列弱收敛。

> $L^1$ 中此结论不成立（需要一致可积性条件——Dunford-Pettis 定理）。

**推论 6.1**　$L^p$（$1 < p < \infty$）是自反的 Banach 空间。
