# 集合与点集

> 实变函数的基石——集合论与点集拓扑。

## 1. 集合运算

### 1.1 基本运算

设 $A, B$ 为集合：

| 运算 | 定义 |
|------|------|
| 并 | $A \cup B = \{x : x \in A \text{ 或 } x \in B\}$ |
| 交 | $A \cap B = \{x : x \in A \text{ 且 } x \in B\}$ |
| 差 | $A \setminus B = \{x : x \in A \text{ 且 } x \notin B\}$ |
| 补 | $A^c = X \setminus A$（$X$ 为全集） |
| 对称差 | $A \triangle B = (A \setminus B) \cup (B \setminus A)$ |

**性质**：
- $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$（分配律）
- $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$（分配律）

### 1.2 De Morgan 公式

$$\left(\bigcup_{\alpha} A_\alpha\right)^c = \bigcap_{\alpha} A_\alpha^c, \quad \left(\bigcap_{\alpha} A_\alpha\right)^c = \bigcup_{\alpha} A_\alpha^c$$

**推论 1.1**　De Morgan 公式对可数无穷个集合也成立。

### 1.3 集合列的极限

**上极限**：$\limsup_{n \to \infty} A_n = \bigcap_{n=1}^{\infty} \bigcup_{k=n}^{\infty} A_k$

> 属于无穷多个 $A_n$ 的元素全体。

**下极限**：$\liminf_{n \to \infty} A_n = \bigcup_{n=1}^{\infty} \bigcap_{k=n}^{\infty} A_k$

> 至多不属于有限个 $A_n$ 的元素全体。

**极限**：$\liminf A_n \subseteq \limsup A_n$，若两者相等则称 $\{A_n\}$ 收敛，记 $\lim A_n$。

**定理 1.1**　若 $A_n \subseteq A_{n+1}$（递增），则 $\lim A_n = \bigcup A_n$。若 $A_n \supseteq A_{n+1}$（递减），则 $\lim A_n = \bigcap A_n$。

## 2. 集合的基数

### 2.1 可数集与不可数集

**定义 2.1**　若存在 $A$ 到 $B$ 的双射，则 $A$ 与 $B$ **等势**，记 $A \sim B$。

**可数集**：与 $\mathbb{N}$ 等势的集合（有限或可列无限）。

**定理 2.1**：
- $\mathbb{Q}$ 可数
- $\mathbb{R}$ 不可数（Cantor 对角线论证）
- 可数集的可数并仍可数

**推论 2.1**　$\mathbb{R}$ 的基数记为 $\mathfrak{c} = 2^{\aleph_0}$。

**定理 2.2（Cantor 定理）**　任何集合的幂集的基数严格大于原集合的基数：$|2^A| > |A|$。

### 2.2 Cantor 集

**构造**：从 $[0, 1]$ 出发，每次去掉每个剩余区间的中间三分之一：

$$C = [0, 1] \setminus \left(\left(\frac{1}{3}, \frac{2}{3}\right) \cup \left(\frac{1}{9}, \frac{2}{9}\right) \cup \left(\frac{7}{9}, \frac{8}{9}\right) \cup \cdots\right)$$

**性质**：
- $C$ 不可数（与 $\{0, 2\}^\mathbb{N}$ 等势，基数为 $\mathfrak{c}$）
- $C$ 无内点（nowhere dense）
- $C$ 是闭集、完备集
- $C$ 的 Lebesgue 测度为 $0$

> **意义**：Cantor 集是实变函数中构造反例的重要工具——它是"大"（不可数）但"薄"（零测）的集合。

**推论 2.2**　零测集可以是不可数的。

## 3. $\mathbb{R}^n$ 中的点集

### 3.1 基本概念

| 概念 | 定义 |
|------|------|
| 内点 | $\exists \delta > 0, B(x, \delta) \subseteq E$ |
| 外点 | $x$ 是 $E^c$ 的内点 |
| 边界点 | $x$ 的任意邻域既含 $E$ 的点又含 $E^c$ 的点 |
| 聚点 | $\forall \delta > 0, (B(x, \delta) \setminus \{x\}) \cap E \neq \emptyset$ |
| 孤立点 | $x \in E$ 但不是 $E$ 的聚点 |

**定义 3.1**　$E$ 的**内部** $\operatorname{int} E$：全体内点的集合。$E$ 的**闭包** $\bar{E}$：$E$ 与其全体聚点的并。

**定理 3.1**　$\bar{E} = \bigcap \{F : F \supseteq E, F \text{ 闭}\}$（包含 $E$ 的最小闭集）。

### 3.2 开集与闭集

**开集**：$E$ 的每一点都是内点。

**闭集**：$E^c$ 是开集（等价于 $E$ 包含其所有聚点）。

**定理 3.2**：
- 任意多个开集的并是开集
- 有限多个开集的交是开集
- 任意多个闭集的交是闭集
- 有限多个闭集的并是闭集

> **注意**：无限多个开集的交未必开，无限多个闭集的并未必闭。

**定理 3.3（$\mathbb{R}^n$ 中开集的结构）**　$\mathbb{R}$ 中的非空开集是至多可数个互不相交的开区间的并。

### 3.3 紧集

**定义 3.2（开覆盖）**　若 $E \subseteq \bigcup_{\alpha} G_\alpha$，$G_\alpha$ 为开集，则称 $\{G_\alpha\}$ 为 $E$ 的开覆盖。

**紧集**：$E$ 的任意开覆盖都有有限子覆盖。

**定理 3.4（Heine-Borel）**：$\mathbb{R}^n$ 中 $E$ 紧 $\iff$ $E$ 有界闭。

> **直觉**：紧集是"有限"的推广——很多有限集才有的性质（最值、一致连续）对紧集也成立。

**定理 3.5（有限交性质）**　紧集的闭子集族若具有有限交性质（任意有限个的交非空），则全体的交非空。

### 3.4 完备集

**定义 3.3**：$E$ 是闭集且无孤立点（即 $E$ 等于其聚点全体）。

**定理 3.6（Cantor-Bendixson 定理）**：$\mathbb{R}^n$ 中的闭集可分解为可数集与完备集的并。

## 4. 可数与不可数的应用

### 4.1 Baire 纲定理

**定理 4.1（Baire 纲定理）**：$\mathbb{R}^n$ 中可数个无处稠密闭集的并不能覆盖 $\mathbb{R}^n$。

等价表述：$\mathbb{R}^n$ 中可数个稠密开集的交仍稠密。

> **意义**：$\mathbb{R}^n$ 是"第二纲"的——它不能被"薄"的集合覆盖。这是泛函分析中三大定理的基础。

### 4.2 第一纲集与第二纲集

- **第一纲集**（meager）：可数个无处稠密集的并
- **第二纲集**：不是第一纲集

> **直觉**：第一纲集是"小"集合（拓扑意义下），第二纲集是"大"集合。

**推论 4.1**　$\mathbb{R}^n$ 本身是第二纲集。

**推论 4.2**　$\mathbb{R}^n$ 中的开集是第二纲集。
