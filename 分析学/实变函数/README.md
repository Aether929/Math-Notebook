## 学习路线

```
集合与点集 → Lebesgue 测度 → 可测函数 → Lebesgue 积分
                                              ↓
                              Lp 空间 ← 微分与不定积分
```

## 与数学分析的关系

实变函数是数学分析的"升级版"：
- **积分**：Riemann 积分 → Lebesgue 积分（更灵活的极限交换）
- **可积性**：连续函数 → 可测函数（更大的函数类）
- **收敛**：一致收敛 → a.e. 收敛 / 依测度收敛（更弱的条件）
