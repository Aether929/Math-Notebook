# 多元函数微分学

> 从一元到多元——偏导数、全微分与隐函数定理。

## 1. 多元函数的极限与连续

### 1.1 多元函数的极限

**定义 1.1**　设 $f: D \subseteq \mathbb{R}^n \to \mathbb{R}$，$P_0$ 为 $D$ 的聚点：

$$\lim_{P \to P_0} f(P) = A \iff \forall \varepsilon > 0, \exists \delta > 0, 0 < \|P - P_0\| < \delta \Rightarrow |f(P) - A| < \varepsilon$$

> **与一元函数的区别**：$P \to P_0$ 可以沿任意路径，路径不同极限也必须相同。

**反例**：$f(x, y) = \frac{xy}{x^2 + y^2}$，沿 $y = kx$ 趋于原点得到不同极限，故极限不存在。

**定理 1.1（极限唯一性）**　若极限存在，则唯一。

**定理 1.2（极限的四则运算）**　若 $\lim f = A$，$\lim g = B$，则 $\lim(f \pm g) = A \pm B$，$\lim(fg) = AB$，$\lim(f/g) = A/B$（$B \neq 0$）。

### 1.2 重极限与累次极限

- **重极限**：$\lim_{(x, y) \to (0, 0)} f(x, y)$
- **累次极限**：$\lim_{x \to 0} \lim_{y \to 0} f(x, y)$ 与 $\lim_{y \to 0} \lim_{x \to 0} f(x, y)$

**关系**：
- 重极限存在 $\not\Rightarrow$ 累次极限存在
- 累次极限都存在且相等 $\not\Rightarrow$ 重极限存在
- 重极限存在且累次极限存在 $\Rightarrow$ 三者相等

### 1.3 连续性

**定义 1.2**　$f$ 在 $P_0$ 连续：$\lim_{P \to P_0} f(P) = f(P_0)$。

**定理 1.3（有界闭区域上连续函数的性质）**：
- **有界性**：$f$ 在有界闭区域 $D$ 上连续 $\Rightarrow$ $f$ 在 $D$ 上有界
- **最值定理**：$f$ 在有界闭区域 $D$ 上连续 $\Rightarrow$ $f$ 在 $D$ 上取得最大值和最小值
- **介值定理**：$f$ 在连通区域 $D$ 上连续 $\Rightarrow$ $f$ 取到任意中间值
- **一致连续性**：$f$ 在有界闭区域 $D$ 上连续 $\Rightarrow$ $f$ 在 $D$ 上一致连续

## 2. 偏导数与全微分

### 2.1 偏导数

**定义 2.1**　$f(x, y)$ 在 $(x_0, y_0)$ 处对 $x$ 的偏导数：

$$\frac{\partial f}{\partial x}(x_0, y_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x, y_0) - f(x_0, y_0)}{\Delta x}$$

> **几何意义**：固定 $y = y_0$，曲线 $z = f(x, y_0)$ 在 $x = x_0$ 处的切线斜率。

**高阶偏导数**：

$$f_{xx} = \frac{\partial^2 f}{\partial x^2}, \quad f_{xy} = \frac{\partial^2 f}{\partial x \partial y}, \quad f_{yx} = \frac{\partial^2 f}{\partial y \partial x}, \quad f_{yy} = \frac{\partial^2 f}{\partial y^2}$$

**定理 2.1（Schwarz 定理/混合偏导数与次序无关）**　若 $f_{xy}$ 和 $f_{yx}$ 都连续，则 $f_{xy} = f_{yx}$。

> **证明提示**：利用 Lagrange 中值定理两次，取双重极限。

**推论 2.1**　若 $f$ 有直到 $k$ 阶的连续偏导数，则 $k$ 阶混合偏导数与求导次序无关。

### 2.2 全微分

**定义 2.2**　若 $f(x, y)$ 在 $(x_0, y_0)$ 处的全增量可表示为：

$$\Delta f = f(x_0 + \Delta x, y_0 + \Delta y) - f(x_0, y_0) = A \Delta x + B \Delta y + o(\rho)$$

其中 $\rho = \sqrt{(\Delta x)^2 + (\Delta y)^2}$，则称 $f$ 在 $(x_0, y_0)$ 处**可微**，$df = A \, dx + B \, dy$ 为全微分。

**定理 2.2（可微的必要条件）**　$A = f_x(x_0, y_0)$，$B = f_y(x_0, y_0)$，即：

$$df = \frac{\partial f}{\partial x} dx + \frac{\partial f}{\partial y} dy$$

**定理 2.3（可微的充分条件）**　$f_x, f_y$ 在 $(x_0, y_0)$ 处连续 $\Rightarrow$ $f$ 在 $(x_0, y_0)$ 处可微。

**关系链**：

$$\text{偏导连续} \Rightarrow \text{可微} \Rightarrow \begin{cases} \text{偏导存在} \\ \text{连续} \end{cases}$$

> **注意**：偏导存在 $\not\Rightarrow$ 连续（反例：$f(x, y) = \frac{xy}{x^2 + y^2}$ 在原点偏导存在但不连续）。偏导存在 $\not\Rightarrow$ 可微。

**推论 2.2**　可微函数的偏导数在该点附近有界。

## 3. 复合函数求导（链式法则）

### 3.1 链式法则

设 $z = f(u, v)$，$u = \varphi(x, y)$，$v = \psi(x, y)$，则：

$$\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u} \frac{\partial u}{\partial x} + \frac{\partial z}{\partial v} \frac{\partial v}{\partial x}$$

$$\frac{\partial z}{\partial y} = \frac{\partial z}{\partial u} \frac{\partial u}{\partial y} + \frac{\partial z}{\partial v} \frac{\partial v}{\partial y}$$

**记忆**：画出变量依赖图，沿每条路径求偏导并相乘，再将所有路径求和。

**矩阵形式**：$D(f \circ g) = Df \cdot Dg$（Jacobi 矩阵的乘法）。

### 3.2 全微分形式不变性

无论 $u, v$ 是自变量还是中间变量，$df = f_u \, du + f_v \, dv$ 的形式不变。

## 4. 隐函数定理

### 4.1 一个方程的情形

**定理 4.1（隐函数存在定理）**　设 $F(x, y)$ 满足：
1. $F(x_0, y_0) = 0$
2. $F$ 在 $(x_0, y_0)$ 的邻域内有连续偏导数
3. $F_y(x_0, y_0) \neq 0$

则在 $(x_0, y_0)$ 附近存在唯一的连续可微函数 $y = f(x)$ 使得 $F(x, f(x)) = 0$，且：

$$\frac{dy}{dx} = -\frac{F_x}{F_y}$$

> **证明提示**：用反函数定理和压缩映射原理。

**推论 4.1**　$f'(x_0) = -\frac{F_x(x_0, y_0)}{F_y(x_0, y_0)}$。

### 4.2 方程组的情形

**定理 4.2**　设 $F(x, y, u, v) = 0, G(x, y, u, v) = 0$，Jacobi 行列式：

$$J = \frac{\partial(F, G)}{\partial(u, v)} = \begin{vmatrix} F_u & F_v \\ G_u & G_v \end{vmatrix} \neq 0$$

则在适当条件下可解出 $u = u(x, y), v = v(x, y)$。

**推论 4.2**　$\frac{\partial u}{\partial x} = -\frac{1}{J} \frac{\partial(F, G)}{\partial(x, v)}$（类似可求其他偏导）。

### 4.3 逆映射定理

**定理 4.3（逆映射定理）**　设 $\mathbf{F}: \mathbb{R}^n \to \mathbb{R}^n$ 在 $\mathbf{x}_0$ 附近有连续偏导数，且 $\det D\mathbf{F}(\mathbf{x}_0) \neq 0$，则 $\mathbf{F}$ 在 $\mathbf{x}_0$ 附近是局部微分同胚。

## 5. 偏导数的几何应用

### 5.1 空间曲线的切线与法平面

**参数方程** $\mathbf{r}(t) = (x(t), y(t), z(t))$ 在 $t_0$ 处：
- **切向量**：$\mathbf{r}'(t_0) = (x'(t_0), y'(t_0), z'(t_0))$
- **切线**：$\frac{x - x_0}{x'(t_0)} = \frac{y - y_0}{y'(t_0)} = \frac{z - z_0}{z'(t_0)}$
- **法平面**：$x'(t_0)(x - x_0) + y'(t_0)(y - y_0) + z'(t_0)(z - z_0) = 0$

### 5.2 曲面的切平面与法线

**隐式** $F(x, y, z) = 0$ 在 $(x_0, y_0, z_0)$ 处：
- **法向量**：$\nabla F = (F_x, F_y, F_z)$
- **切平面**：$F_x(x - x_0) + F_y(y - y_0) + F_z(z - z_0) = 0$
- **法线**：$\frac{x - x_0}{F_x} = \frac{y - y_0}{F_y} = \frac{z - z_0}{F_z}$

## 6. 极值与条件极值

### 6.1 无条件极值

**必要条件**：$f$ 在 $(x_0, y_0)$ 取极值，偏导存在 $\Rightarrow$ $f_x = f_y = 0$。

**充分条件**：令 $A = f_{xx}, B = f_{xy}, C = f_{yy}$，$\Delta = AC - B^2$：

| 条件 | 结论 |
|------|------|
| $\Delta > 0, A > 0$ | 极小值 |
| $\Delta > 0, A < 0$ | 极大值 |
| $\Delta < 0$ | 非极值（鞍点） |
| $\Delta = 0$ | 无法判定 |

> **证明提示**：用二阶 Taylor 展开，$\Delta > 0$ 时二次型正定或负定。

**定理 6.1（二阶条件的矩阵形式）**　令 $H = \begin{pmatrix} f_{xx} & f_{xy} \\ f_{xy} & f_{yy} \end{pmatrix}$（**Hessian 矩阵**），则 $H$ 正定 $\Rightarrow$ 极小，$H$ 负定 $\Rightarrow$ 极大。

### 6.2 条件极值与 Lagrange 乘数法

**问题**：在约束 $g(x, y, z) = 0$ 下求 $f(x, y, z)$ 的极值。

**Lagrange 函数**：

$$L(x, y, z, \lambda) = f(x, y, z) - \lambda g(x, y, z)$$

**必要条件**：

$$\nabla L = 0 \iff \begin{cases} f_x = \lambda g_x \\ f_y = \lambda g_y \\ f_z = \lambda g_z \\ g = 0 \end{cases}$$

> **几何意义**：在极值点，$\nabla f$ 与 $\nabla g$ 平行（等值面与约束面相切）。

**多个约束**：$g_1 = 0, g_2 = 0, \ldots$，令 $L = f - \lambda_1 g_1 - \lambda_2 g_2 - \cdots$。

### 6.3 最值问题

闭区域上连续函数的最值：
1. 求区域内驻点
2. 求边界上的条件极值
3. 比较所有候选点的函数值

## 7. 多元 Taylor 公式

设 $f$ 在 $(x_0, y_0)$ 附近有 $n+1$ 阶连续偏导数，令 $h = x - x_0, k = y - y_0$：

$$f(x, y) = \sum_{m=0}^{n} \frac{1}{m!} \left(h \frac{\partial}{\partial x} + k \frac{\partial}{\partial y}\right)^m f(x_0, y_0) + R_n$$

其中 $\left(h \frac{\partial}{\partial x} + k \frac{\partial}{\partial y}\right)^m$ 表示形式展开后作用于 $f$。

**二阶展开**（最常用）：

$$f(x, y) = f(x_0, y_0) + f_x h + f_y k + \frac{1}{2}(f_{xx} h^2 + 2f_{xy} hk + f_{yy} k^2) + o(h^2 + k^2)$$

**推论 7.1**　极值点处 $f_x = f_y = 0$，此时二阶项决定极值类型。
