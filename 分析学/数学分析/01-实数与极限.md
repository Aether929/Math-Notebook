# 实数与极限

> 分析学的基石——实数系的完备性是整个分析学的根基。

## 1. 实数系

### 1.1 实数的完备性

**定义（确界）**　设 $S \subseteq \mathbb{R}$ 非空：
- 若 $\exists M \in \mathbb{R}$ 使得 $\forall x \in S, x \leq M$，则称 $S$ **有上界**，$M$ 为 $S$ 的一个上界
- $S$ 的**上确界** $\sup S$ 是 $S$ 的最小上界：(1) $\sup S$ 是上界；(2) 任何小于 $\sup S$ 的数不是上界
- 类似定义**下确界** $\inf S$

**公理（确界原理）**　非空有上界的实数集必有上确界。

> **直觉**：实数轴上没有"缝隙"——有理数集 $\mathbb{Q}$ 不满足此性质（如 $\{x \in \mathbb{Q} : x^2 < 2\}$ 无有理上确界）。

**定理 1.1（确界的等价刻画）**　$\alpha = \sup S$ 当且仅当：
1. $\forall x \in S, x \leq \alpha$
2. $\forall \varepsilon > 0, \exists x_0 \in S, x_0 > \alpha - \varepsilon$

**推论 1.1**　$\inf S = -\sup(-S)$，其中 $-S = \{-x : x \in S\}$。

### 1.2 常用实数性质

| 性质 | 内容 |
|------|------|
| Archimedes 公理 | $\forall x \in \mathbb{R}, \exists n \in \mathbb{N}, n > x$ |
| 稠密性 | $\forall a < b, \exists q \in \mathbb{Q}, a < q < b$ |
| 闭区间套 | $\bigcap_{n=1}^{\infty} [a_n, b_n] \neq \emptyset$（当 $[a_{n+1}, b_{n+1}] \subseteq [a_n, b_n]$） |

**推论 1.2（有理数的稠密性）**　对任意 $a < b$，存在无穷多个有理数 $q$ 满足 $a < q < b$。

**推论 1.3（无理数的稠密性）**　对任意 $a < b$，存在无理数 $r$ 满足 $a < r < b$。

> **证明提示**：取 $q \in \mathbb{Q}$ 使 $a - \sqrt{2} < q < b - \sqrt{2}$，则 $r = q + \sqrt{2}$ 为无理数且 $a < r < b$。

## 2. 数列极限

### 2.1 定义

**定义（数列极限）**　数列 $\{a_n\}$ 收敛于 $a$，记 $\lim_{n \to \infty} a_n = a$：

$$\forall \varepsilon > 0, \exists N \in \mathbb{N}, \forall n > N: |a_n - a| < \varepsilon$$

**等价表述**：$a_n - a = o(1)$（当 $n \to \infty$）；$|a_n - a| \to 0$。

**定理 2.1（极限的唯一性）**　若 $\lim a_n = a$ 且 $\lim a_n = b$，则 $a = b$。

> **证明提示**：$\forall \varepsilon > 0$，$|a - b| \leq |a - a_n| + |a_n - b| < 2\varepsilon$。

**定理 2.2（收敛数列的有界性）**　收敛数列必有界。反之不成立（如 $a_n = (-1)^n$）。

**定理 2.3（保序性）**　若 $\lim a_n = a > 0$，则 $\exists N$，$n > N \Rightarrow a_n > a/2 > 0$。

**推论 2.1（保序性推广）**　若 $a_n \leq b_n$（最终），$\lim a_n = a$，$\lim b_n = b$，则 $a \leq b$。严格不等式不一定保持（如 $1/n > 0$ 但极限为 $0$）。

### 2.2 收敛准则

**定理 2.4（单调有界准则）**　单调有界数列必收敛。

> **证明提示**：设 $\{a_n\}$ 单调递增有上界，则 $\{a_n\}$ 有上确界 $a = \sup\{a_n\}$，利用确界定义可证 $a_n \to a$。

**推论 2.2**　单调递减有下界的数列收敛。

**推论 2.3**　$e = \lim_{n \to \infty} (1 + 1/n)^n$ 存在（序列单调递增有上界 $3$）。

**定理 2.5（Cauchy 准则）**　$\{a_n\}$ 收敛 $\iff$ $\{a_n\}$ 为 Cauchy 列：

$$\forall \varepsilon > 0, \exists N, \forall m, n > N: |a_m - a_n| < \varepsilon$$

> **证明提示**：必要性用三角不等式；充分性用 Cauchy 列有界 + Bolzano-Weierstrass 定理。

**推论 2.4**　Cauchy 列有界。

**推论 2.5**　Cauchy 列的子列收敛 $\Rightarrow$ 原 Cauchy 列收敛（于同一极限）。

### 2.3 极限运算法则

若 $\lim a_n = a, \lim b_n = b$，则：

$$\lim(a_n \pm b_n) = a \pm b, \quad \lim(a_n \cdot b_n) = a \cdot b, \quad \lim \frac{a_n}{b_n} = \frac{a}{b} \ (b \neq 0)$$

**定理 2.6（夹逼准则）**　$a_n \leq b_n \leq c_n$，$\lim a_n = \lim c_n = L$ $\Rightarrow$ $\lim b_n = L$。

**定理 2.7（Stolz-Cesàro 定理）**　设 $\{b_n\}$ 严格单调无界，则

$$\lim_{n \to \infty} \frac{a_n}{b_n} = \lim_{n \to \infty} \frac{a_{n+1} - a_n}{b_{n+1} - b_n}$$

（右边存在或为 $\pm \infty$ 时成立。）

> **证明提示**：数列版的 L'Hôpital 法则。利用 Cauchy 准则和 $\{b_n\}$ 的单调性。

**推论 2.6**　$\lim_{n \to \infty} \frac{a_1 + \cdots + a_n}{n} = L$（若 $\lim a_n = L$）（Cesàro 平均）。

### 2.4 重要极限与技巧

| 极限 | 值 | 备注 |
|------|----|------|
| $\lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n$ | $e$ | 自然对数的底 |
| $\lim_{n \to \infty} \frac{a^n}{n!}$ | $0$（任意 $a$） | 阶乘增长最快 |
| $\lim_{n \to \infty} \sqrt[n]{a}$ | $1$（$a > 0$） | $n$ 次根趋于 1 |
| $\lim_{n \to \infty} \sqrt[n]{n}$ | $1$ | 多项式增长慢于指数 |
| $\lim_{n \to \infty} n^{1/n}$ | $1$ | 取对数后用 L'Hôpital |

**命题 2.1**　若 $a_n > 0$，$\lim \frac{a_{n+1}}{a_n} = L$，则 $\lim \sqrt[n]{a_n} = L$。

> **证明提示**：取对数后用 Stolz-Cesàro 定理。这说明比值判别法比根值判别法"弱"。

## 3. 函数极限

### 3.1 定义

**定义**　$\lim_{x \to x_0} f(x) = A$：

$$\forall \varepsilon > 0, \exists \delta > 0, 0 < |x - x_0| < \delta \Rightarrow |f(x) - A| < \varepsilon$$

**单侧极限**：
- 右极限 $f(x_0^+) = \lim_{x \to x_0^+} f(x)$：$x_0 < x < x_0 + \delta$
- 左极限 $f(x_0^-) = \lim_{x \to x_0^-} f(x)$：$x_0 - \delta < x < x_0$

$$\lim_{x \to x_0} f(x) = A \iff f(x_0^+) = f(x_0^-) = A$$

**定理 3.1（函数极限的局部保号性）**　若 $\lim_{x \to x_0} f(x) = A > 0$，则 $\exists \delta > 0$，$0 < |x - x_0| < \delta \Rightarrow f(x) > A/2 > 0$。

**推论 3.1**　若 $f(x) \geq 0$（在 $x_0$ 附近），$\lim_{x \to x_0} f(x) = A$，则 $A \geq 0$。

**定理 3.2（Heine 归结原理）**　$\lim_{x \to x_0} f(x) = A$ $\iff$ 对任何 $x_n \to x_0$（$x_n \neq x_0$），$f(x_n) \to A$。

> **证明提示**：$\Rightarrow$：用极限定义。$\Leftarrow$：反证法，若不成立则可构造一个序列使 $f(x_n)$ 不趋于 $A$。

### 3.2 无穷极限与渐近线

- $\lim_{x \to x_0} f(x) = \infty$：$\forall M > 0, \exists \delta > 0, 0 < |x - x_0| < \delta \Rightarrow |f(x)| > M$
- **水平渐近线**：$\lim_{x \to +\infty} f(x) = a \Rightarrow y = a$
- **垂直渐近线**：$\lim_{x \to x_0} f(x) = \infty \Rightarrow x = x_0$
- **斜渐近线**：$\lim_{x \to \infty} [f(x) - (kx + b)] = 0$，其中 $k = \lim_{x \to \infty} f(x)/x$，$b = \lim_{x \to \infty} [f(x) - kx]$

### 3.3 连续性

**定义**　$f$ 在 $x_0$ 连续：$\lim_{x \to x_0} f(x) = f(x_0)$，即

$$\forall \varepsilon > 0, \exists \delta > 0, |x - x_0| < \delta \Rightarrow |f(x) - f(x_0)| < \varepsilon$$

> 注意：函数极限定义要求 $0 < |x - x_0|$（去心），连续性定义允许 $x = x_0$。

**定义（间断点分类）**：
- **第一类间断点**：$f(x_0^+)$ 和 $f(x_0^-)$ 都存在
  - 可去间断点：$f(x_0^+) = f(x_0^-) \neq f(x_0)$
  - 跳跃间断点：$f(x_0^+) \neq f(x_0^-)$
- **第二类间断点**：$f(x_0^+)$ 或 $f(x_0^-)$ 至少一个不存在（如振荡、无穷）

## 4. 实数完备性的等价命题

以下命题互相等价（在 $\mathbb{R}$ 中）：

| 命题 | 内容 |
|------|------|
| 确界原理 | 非空有上界的集合有上确界 |
| 单调有界准则 | 单调有界数列收敛 |
| Cauchy 收敛准则 | Cauchy 列收敛（$\mathbb{R}$ 完备） |
| Bolzano-Weierstrass | 有界数列有收敛子列 |
| 闭区间套定理 | $\bigcap [a_n, b_n] \neq \emptyset$（$a_n \leq a_{n+1} < b_{n+1} \leq b_n$） |
| Heine-Borel（有限覆盖） | $[a, b]$ 的开覆盖有有限子覆盖 |

**定理 4.1（Bolzano-Weierstrass 定理）**　有界数列必有收敛子列。

> **证明提示**：二分法。将 $[a, b]$ 二分，取含无穷多项的那一半，重复。得到的子列满足 Cauchy 条件。

**推论 4.1**　无界数列必有趋于 $\infty$ 的子列。

**定理 4.2（闭区间套定理）**　设 $[a_{n+1}, b_{n+1}] \subseteq [a_n, b_n]$，则 $\bigcap_{n=1}^{\infty} [a_n, b_n] \neq \emptyset$。若 $b_n - a_n \to 0$，则交为单点。

**定理 4.3（Heine-Borel 有限覆盖定理）**　$[a, b]$ 的任何开覆盖都有有限子覆盖。

> **证明提示**：反证法。二分 $[a, b]$，取不能被有限覆盖的那一半，重复。闭区间套的公共点可被某个开集覆盖，矛盾。

**推论 4.2**　$[a, b]$ 的任何开覆盖都有 Lebesgue 数：存在 $\delta > 0$，$[a, b]$ 中任何长度 $< \delta$ 的子区间被某个开集覆盖。

## 5. 上极限与下极限

**定义**：

$$\limsup_{n \to \infty} a_n = \lim_{n \to \infty} \sup_{k \geq n} a_k = \inf_{n \geq 1} \sup_{k \geq n} a_k$$

$$\liminf_{n \to \infty} a_n = \lim_{n \to \infty} \inf_{k \geq n} a_k = \sup_{n \geq 1} \inf_{k \geq n} a_k$$

**等价刻画**：$\limsup a_n$ 是 $\{a_n\}$ 所有收敛子列的极限的上确界。

**性质**：
- $\liminf a_n \leq \limsup a_n$
- $\lim a_n$ 存在 $\iff$ $\liminf a_n = \limsup a_n$
- $\limsup(a_n + b_n) \leq \limsup a_n + \limsup b_n$
- 若 $a_n \leq b_n$（最终），则 $\limsup a_n \leq \limsup b_n$，$\liminf a_n \leq \liminf b_n$

**定理 5.1（上极限的 $\varepsilon$-$N$ 刻画）**　$L = \limsup a_n$ 当且仅当：
1. $\forall \varepsilon > 0$，$\exists N$，$n > N \Rightarrow a_n < L + \varepsilon$（最终不超过）
2. $\forall \varepsilon > 0$，$a_n > L - \varepsilon$ 对无穷多个 $n$ 成立（经常超过）

**推论 5.1**　$\limsup a_n = L$ $\iff$ 子列 $a_{n_k} \to L$ 且任何收敛子列的极限 $\leq L$。

> **直觉**：上极限是数列尾部的"最高水位"，下极限是"最低水位"。
