# 不定积分

> 求导的逆运算——从微分到积分的桥梁。

## 1. 原函数与不定积分

### 1.1 基本概念

**定义 1.1**　若 $F'(x) = f(x)$，则称 $F(x)$ 为 $f(x)$ 的一个**原函数**。

**定义 1.2**　$f(x)$ 的全体原函数称为 $f(x)$ 的**不定积分**：

$$\int f(x) \, dx = F(x) + C$$

其中 $C$ 为任意常数。

**定理 1.1（原函数存在定理）**　若 $f$ 在区间 $I$ 上连续，则 $f$ 在 $I$ 上必有原函数。

> **证明提示**：$F(x) = \int_a^x f(t) \, dt$ 就是一个原函数（由微积分基本定理）。

**定理 1.2**　同一函数的任意两个原函数相差一个常数。

> **证明提示**：设 $F'(x) = G'(x) = f(x)$，则 $(F - G)' = 0$，由 Lagrange 中值定理得 $F - G = C$。

**推论 1.1**　若 $f$ 在区间 $I$ 上有原函数，则 $\int f(x) \, dx = F(x) + C$（$C$ 为任意常数）。

### 1.2 基本性质

$$\int [f(x) \pm g(x)] \, dx = \int f(x) \, dx \pm \int g(x) \, dx$$

$$\int k f(x) \, dx = k \int f(x) \, dx \quad (k \neq 0)$$

$$\frac{d}{dx} \int f(x) \, dx = f(x), \quad \int F'(x) \, dx = F(x) + C$$

**注意**：不定积分的结果是一个函数族（含任意常数 $C$），而非单一函数。

## 2. 基本积分公式

| 函数 | 积分 |
|------|------|
| $\int x^n \, dx$ | $\frac{x^{n+1}}{n+1} + C \quad (n \neq -1)$ |
| $\int \frac{1}{x} \, dx$ | $\ln\|x\| + C$ |
| $\int e^x \, dx$ | $e^x + C$ |
| $\int a^x \, dx$ | $\frac{a^x}{\ln a} + C$ |
| $\int \sin x \, dx$ | $-\cos x + C$ |
| $\int \cos x \, dx$ | $\sin x + C$ |
| $\int \tan x \, dx$ | $-\ln\|\cos x\| + C$ |
| $\int \cot x \, dx$ | $\ln\|\sin x\| + C$ |
| $\int \sec^2 x \, dx$ | $\tan x + C$ |
| $\int \csc^2 x \, dx$ | $-\cot x + C$ |
| $\int \sec x \tan x \, dx$ | $\sec x + C$ |
| $\int \csc x \cot x \, dx$ | $-\csc x + C$ |
| $\int \frac{1}{1 + x^2} \, dx$ | $\arctan x + C$ |
| $\int \frac{1}{\sqrt{1 - x^2}} \, dx$ | $\arcsin x + C$ |
| $\int \frac{1}{a^2 + x^2} \, dx$ | $\frac{1}{a} \arctan \frac{x}{a} + C$ |
| $\int \frac{1}{\sqrt{a^2 - x^2}} \, dx$ | $\arcsin \frac{x}{a} + C$ |
| $\int \frac{1}{x^2 - a^2} \, dx$ | $\frac{1}{2a} \ln\left\|\frac{x - a}{x + a}\right\| + C$ |
| $\int \frac{1}{\sqrt{x^2 \pm a^2}} \, dx$ | $\ln\left\|x + \sqrt{x^2 \pm a^2}\right\| + C$ |

## 3. 积分方法

### 3.1 换元积分法

**第一类换元（凑微分）**：

$$\int f(g(x)) g'(x) \, dx = \int f(u) \, du \Big|_{u = g(x)}$$

**常用凑微分**：
- $x \, dx = \frac{1}{2} d(x^2)$
- $\frac{1}{x} \, dx = d(\ln|x|)$
- $e^x \, dx = d(e^x)$
- $\cos x \, dx = d(\sin x)$，$\sin x \, dx = -d(\cos x)$
- $\frac{1}{\cos^2 x} \, dx = d(\tan x)$，$\frac{1}{\sin^2 x} \, dx = -d(\cot x)$

**第二类换元**：令 $x = \varphi(t)$，则：

$$\int f(x) \, dx = \int f(\varphi(t)) \varphi'(t) \, dt$$

**常用代换**：

| 被积函数特征 | 代换 |
|-------------|------|
| $\sqrt{a^2 - x^2}$ | $x = a \sin t$ |
| $\sqrt{a^2 + x^2}$ | $x = a \tan t$ |
| $\sqrt{x^2 - a^2}$ | $x = a \sec t$ |
| $\sqrt[n]{ax + b}$ | $t = \sqrt[n]{ax + b}$ |
| $\sqrt{\frac{ax + b}{cx + d}}$ | $t = \sqrt{\frac{ax + b}{cx + d}}$ |

**定理 3.1（换元的严格性）**　若 $g$ 在 $[\alpha, \beta]$ 上有连续导数，$g([\alpha, \beta]) \subseteq I$，$f$ 在 $I$ 上连续，则

$$\int f(x) \, dx = \int f(g(t)) g'(t) \, dt \Big|_{t = g^{-1}(x)}$$

### 3.2 分部积分法

$$\int u \, dv = uv - \int v \, du$$

**选择 $u$ 的优先级（LIATE 法则）**：

$$\text{对数} > \text{反三角} > \text{代数} > \text{三角} > \text{指数}$$

排在前面的优先选为 $u$。

**常用分部积分模式**：

$$\int x^n e^x \, dx, \quad \int x^n \sin x \, dx, \quad \int x^n \ln x \, dx, \quad \int e^x \sin x \, dx$$

> **技巧**：$\int e^x \sin x \, dx$ 需要两次分部积分后解方程得到结果。

**定理 3.2（递推公式）**　分部积分常用于建立递推关系，例如：

$$I_n = \int \sin^n x \, dx = -\frac{1}{n} \sin^{n-1} x \cos x + \frac{n-1}{n} I_{n-2}$$

## 4. 有理函数积分

### 4.1 部分分式分解

有理函数 $\frac{P(x)}{Q(x)}$（$\deg P < \deg Q$）可分解为部分分式之和。

**分解规则**：

| $Q(x)$ 的因式 | 对应的部分分式 |
|---------------|---------------|
| $(x - a)^k$ | $\frac{A_1}{x - a} + \frac{A_2}{(x - a)^2} + \cdots + \frac{A_k}{(x - a)^k}$ |
| $(x^2 + px + q)^k$ | $\frac{B_1 x + C_1}{x^2 + px + q} + \cdots + \frac{B_k x + C_k}{(x^2 + px + q)^k}$ |

> **步骤**：若 $\deg P \geq \deg Q$，先做多项式除法，再对余式做部分分式分解。

**定理 4.1**　任何有理函数的不定积分都可以用有理函数、对数函数和反正切函数表示。

### 4.2 三角函数有理式的积分

令 $t = \tan \frac{x}{2}$（万能代换）：

$$\sin x = \frac{2t}{1 + t^2}, \quad \cos x = \frac{1 - t^2}{1 + t^2}, \quad dx = \frac{2}{1 + t^2} \, dt$$

> **注意**：万能代换计算量大，优先考虑其他方法（如利用 $\sin^2 x + \cos^2 x = 1$ 化简）。

**特殊情形的简化**：
- $\int R(\sin x) \cos x \, dx$：令 $t = \sin x$
- $\int R(\cos x) \sin x \, dx$：令 $t = \cos x$
- $\int R(\tan x) \, dx$：令 $t = \tan x$

## 5. 某些无法用初等函数表示的积分

以下积分**不存在**初等函数形式的原函数（Liouville 定理）：

$$\int e^{-x^2} \, dx, \quad \int \frac{\sin x}{x} \, dx, \quad \int \frac{1}{\ln x} \, dx, \quad \int \frac{dx}{\sqrt{1 - k^2 \sin^2 x}}$$

> 这些积分在后续（概率论中的误差函数、物理中的 Fresnel 积分、椭圆积分等）有重要意义，需用级数或数值方法处理。

**定义 5.1**　**误差函数**：$\operatorname{erf}(x) = \frac{2}{\sqrt{\pi}} \int_0^x e^{-t^2} \, dt$。

**定义 5.2**　**椭圆积分**：$F(k, \varphi) = \int_0^\varphi \frac{d\theta}{\sqrt{1 - k^2 \sin^2 \theta}}$。

## 6. 积分表补充

$$\int \ln x \, dx = x \ln x - x + C$$

$$\int \arctan x \, dx = x \arctan x - \frac{1}{2} \ln(1 + x^2) + C$$

$$\int e^{ax} \sin bx \, dx = \frac{e^{ax}(a \sin bx - b \cos bx)}{a^2 + b^2} + C$$

$$\int e^{ax} \cos bx \, dx = \frac{e^{ax}(a \cos bx + b \sin bx)}{a^2 + b^2} + C$$

$$\int \sqrt{a^2 - x^2} \, dx = \frac{x}{2}\sqrt{a^2 - x^2} + \frac{a^2}{2} \arcsin \frac{x}{a} + C$$

$$\int \sqrt{x^2 + a^2} \, dx = \frac{x}{2}\sqrt{x^2 + a^2} + \frac{a^2}{2} \ln\left|x + \sqrt{x^2 + a^2}\right| + C$$
