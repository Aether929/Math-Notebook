
## 核心思想

泛函分析的三大要素：
- **代数**：线性空间、线性算子
- **拓扑**：范数、收敛、完备性
- **分析**：极限、微分、积分（在无穷维空间中）

三大定理的作用：
- **Hahn-Banach**：保证对偶空间足够"丰富"
- **开映射**：保证逆算子连续
- **闭图像**：简化连续性的验证
