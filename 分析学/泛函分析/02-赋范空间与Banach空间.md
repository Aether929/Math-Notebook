# 赋范空间与 Banach 空间

> 从有限维到无穷维——范数、完备性与线性算子。

## 1. 赋范空间

### 1.1 定义

**定义 1.1**　设 $X$ 为实（或复）线性空间，$\|\cdot\|: X \to \mathbb{R}$ 满足：

1. **正定性**：$\|x\| \geq 0$，$\|x\| = 0 \iff x = 0$
2. **齐次性**：$\|\alpha x\| = |\alpha| \|x\|$
3. **三角不等式**：$\|x + y\| \leq \|x\| + \|y\|$

则 $(X, \|\cdot\|)$ 为**赋范空间**。

**度量**：赋范空间自然诱导度量 $d(x, y) = \|x - y\|$。

### 1.2 常见赋范空间

| 空间 | 范数 |
|------|------|
| $\mathbb{R}^n$（$\ell^p$） | $\|x\|_p = \left(\sum |x_i|^p\right)^{1/p}$ |
| $\mathbb{R}^n$（$\ell^\infty$） | $\|x\|_\infty = \max_i |x_i|$ |
| $C[a, b]$ | $\|f\|_\infty = \max_{x \in [a, b]} |f(x)|$ |
| $L^p$ | $\|f\|_p = \left(\int |f|^p\right)^{1/p}$ |
| $\ell^p$（序列空间） | $\|x\|_p = \left(\sum |x_n|^p\right)^{1/p}$ |

### 1.3 等价范数

**定义 1.2**　$\|\cdot\|_a$ 与 $\|\cdot\|_b$ **等价**：$\exists c, C > 0$：

$$c \|x\|_a \leq \|x\|_b \leq C \|x\|_a$$

**定理 1.1**：有限维空间上所有范数等价。

> **意义**：有限维赋范空间的拓扑结构唯一，不依赖于范数的选择。

**推论 1.1**　等价范数诱导相同的收敛性、开集、闭集、紧集。

## 2. Banach 空间

### 2.1 定义

**定义 2.1**：完备的赋范空间称为 **Banach 空间**。

**常见 Banach 空间**：
- $\mathbb{R}^n$（任何范数）
- $C[a, b]$（上确界范数）
- $L^p$（$1 \leq p \leq \infty$）
- $\ell^p$（$1 \leq p \leq \infty$）

**非 Banach 空间的例子**：
- $C[a, b]$ 配 $L^1$ 范数（不完备）
- $C^1[a, b]$ 配上确界范数（不完备）

### 2.2 Banach 空间中的级数

**定理 2.1**：赋范空间 $X$ 完备 $\iff$ 绝对收敛的级数必收敛：

$$\sum \|x_n\| < \infty \Rightarrow \sum x_n \text{ 收敛}$$

> **证明提示**：必要性用 Cauchy 列性质；充分性用部分和为 Cauchy 列。

### 2.3 有限维 Banach 空间

**定理 2.2**：
- 有限维赋范空间必完备（因此是 Banach 空间）
- 有限维 Banach 空间的子空间必闭
- 赋范空间有限维 $\iff$ 单位球紧

> **意义**：无穷维空间中单位球不紧——这是有限维与无穷维的根本区别。

**推论 2.1**　无穷维 Banach 空间的闭单位球不是紧集。

## 3. 线性算子

### 3.1 定义

**定义 3.1**　设 $X, Y$ 为赋范空间，$T: D(T) \subseteq X \to Y$ 为线性映射。

**有界性**：$\exists M > 0$，$\|Tx\| \leq M \|x\|$（$\forall x \in D(T)$）。

### 3.2 有界性与连续性

**定理 3.1**：线性算子 $T$ 以下等价：
1. $T$ 有界
2. $T$ 连续
3. $T$ 在某一点连续
4. $T$ 将有界集映为有界集

> **关键**：线性算子的有界性、连续性、在原点连续完全等价。

### 3.3 算子范数

**定义 3.2**：

$$\|T\| = \sup_{\|x\| = 1} \|Tx\| = \sup_{x \neq 0} \frac{\|Tx\|}{\|x\|}$$

**性质**：
- $\|Tx\| \leq \|T\| \|x\|$
- $\|T\| = \inf\{M : \|Tx\| \leq M\|x\| \ \forall x\}$

## 4. 有界线性算子空间

### 4.1 $\mathcal{B}(X, Y)$

**定义 4.1**：从 $X$ 到 $Y$ 的所有有界线性算子构成的空间，记 $\mathcal{B}(X, Y)$ 或 $L(X, Y)$。

**定理 4.1**：若 $Y$ 是 Banach 空间，则 $\mathcal{B}(X, Y)$ 是 Banach 空间（不论 $X$ 是否完备）。

### 4.2 算子的复合

$$\|ST\| \leq \|S\| \|T\|$$

### 4.3 例子

| 算子 | 范数 |
|------|------|
| $T: \ell^p \to \ell^p$，$(Tx)_n = a_n x_n$ | $\|T\| = \sup |a_n|$ |
| 积分算子 $Tf(x) = \int_a^b K(x, y) f(y) \, dy$ | $\|T\| = \sup_x \int |K(x, y)| \, dy$（$C \to C$） |

## 5. 有限维空间的特殊性质

### 5.1 等价范数

**定理 5.1**：有限维线性空间上任意两个范数等价。

> **推论**：有限维赋范空间必完备，其上的线性算子必有界。

### 5.2 Riesz 引理

**引理 5.1（Riesz 引理）**：设 $X$ 为赋范空间，$Y \subsetneq X$ 是闭子空间，则：

$$\forall 0 < \theta < 1, \exists x \in X: \|x\| = 1, d(x, Y) \geq \theta$$

**推论 5.1**：赋范空间的闭单位球紧 $\iff$ 空间有限维。

> **意义**：无穷维空间中很多紧性论证失效，需要弱拓扑等工具。

---

## 6. 商空间

### 6.1 定义

设 $M$ 是 $X$ 的闭子空间，商空间 $X/M$ 的元素为等价类 $[x] = x + M$。

**商范数**：$\|[x]\| = d(x, M) = \inf_{m \in M} \|x - m\|$

### 6.2 性质

**定理 6.1**：
- $X$ 是 Banach 空间，$M$ 闭 $\Rightarrow$ $X/M$ 是 Banach 空间
- $\pi: X \to X/M$（商映射）是有界线性算子，$\|\pi\| = 1$
