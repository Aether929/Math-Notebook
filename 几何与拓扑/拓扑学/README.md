## 学习路线

```
【点集拓扑】
拓扑空间 → 连续映射与同胚 → 连通性 → 紧致性 → 分离公理 → 乘积与商空间

【代数拓扑 / 几何拓扑】
同伦与基本群 → 覆盖空间 → 单纯与奇异同调 → 曲面的分类
```

> **衔接**：点集拓扑给出语言与基础性质；代数拓扑用代数（群、环、模）为空间赋予可计算的不变量；几何拓扑研究低维流形的分类。第 06 章的 CW 复形与流形是两部分之间的桥梁。

## 与几何的关系

拓扑学是几何的"骨架"——只关心最基本的连续性结构。微分几何在此基础上添加了光滑结构和度量。

- **微分几何**：流形 + 光滑结构 + 度量；[04-整体微分几何](../微分几何/04-整体微分几何.md) 与同调通过 de Rham 定理相连
- **复分析**：单连通性、Cauchy 定理、Riemann 曲面与覆盖空间相通
- **代数**：同伦群与同调群是函子，Galois 对应类比域扩张
