# 乘积空间与商空间

> 从已知空间构造新空间——乘积、商、胶合。

## 1. 乘积拓扑

### 1.1 定义

**定义 1.1**　设 $\{(X_\alpha, \mathcal{T}_\alpha)\}_{\alpha \in A}$，$\prod X_\alpha$ 上的**乘积拓扑**由基生成：

$$\mathcal{B} = \left\{\prod_{\alpha \in A} U_\alpha : U_\alpha \in \mathcal{T}_\alpha, \ U_\alpha = X_\alpha \text{ 对除有限个外的 } \alpha\right\}$$

> **注意**：只有有限个分量可以不取全空间。

### 1.2 性质

**定理 1.1（Tychonoff）**：任意多个紧空间的乘积紧。

> 这是拓扑学最重要的定理之一，等价于选择公理。

**投影映射** $\pi_\alpha: \prod X_\beta \to X_\alpha$ 连续且开。

**推论 1.1**　投影映射是开映射——乘积中的开集投影到分量上仍是开集。

### 1.3 乘积拓扑的性质保持

| 性质 | 乘积空间 |
|------|----------|
| $T_0, T_1, T_2$ | 保持 |
| 正则、正规 | 保持 |
| 连通、道路连通 | 保持 |
| 紧 | 保持（Tychonoff） |
| 第一/第二可数 | 第一可数保持，第二可数（可数乘积保持） |

**推论 1.2**　紧 Hausdorff 空间的乘积仍是紧 Hausdorff 空间。

### 1.4 箱拓扑

**箱拓扑**：基为 $\prod U_\alpha$（无有限性限制）。

箱拓扑严格细于乘积拓扑（无穷乘积时）。Tychonoff 定理对箱拓扑不成立。

**推论 1.3**　乘积拓扑是使所有投影映射连续的最粗拓扑。

## 2. 商拓扑

### 2.1 定义

**定义 2.1**　设 $\sim$ 为 $X$ 上的等价关系，$X / \sim$ 为商集。**商拓扑**：

$$\mathcal{T}_{X/\sim} = \{U \subseteq X/\sim : \pi^{-1}(U) \in \mathcal{T}_X\}$$

其中 $\pi: X \to X/\sim$ 为商映射。

> **商拓扑是使 $\pi$ 连续的最细拓扑。**

### 2.2 商映射

**定义 2.2**：满射 $q: X \to Y$ 是**商映射**，若 $Y$ 的拓扑为商拓扑（$U$ 开 $\iff$ $q^{-1}(U)$ 开）。

**性质**：
- 商映射连续满射
- $f: Y \to Z$ 连续 $\iff$ $f \circ q$ 连续

**推论 2.1**　商映射的万有性质：任何与商映射"交换"的连续映射都唯一地通过商空间分解。

### 2.3 商空间的例子

| 构造 | 说明 |
|------|------|
| $[0, 1] / (0 \sim 1) \cong S^1$ | 区间两端粘合 |
| $[0, 1]^2 / \partial \sim$ | 正方形边界粘成球面 |
| $[0, 1]^2 / (x, 0) \sim (x, 1)$ | 圆柱面 |
| $[0, 1]^2 / \text{对边同向粘合}$ | 环面 |
| $[0, 1]^2 / \text{对边反向粘合}$ | Möbius 带 |
| $D^2 / \partial D^2 \sim \{p\}$ | $S^2$（圆盘边界缩为一点） |

**推论 2.2**　环面 $T^2 \cong S^1 \times S^1$。

## 3. 胶合拓扑

### 3.1 定义

**定义 3.1**　设 $X, Y$ 为拓扑空间，$A \subseteq X$，$f: A \to Y$ 连续。**胶合空间**：

$$Y \cup_f X = (X \sqcup Y) / (a \sim f(a), \forall a \in A)$$

### 3.2 例子

- **锥**：$CX = X \times [0, 1] / (X \times \{1\})$
- **悬挂**：$\Sigma X = X \times [-1, 1] / ((x, 1) \sim (x', 1), (x, -1) \sim (x', -1))$
- **Möbius 带**：$[0, 1] \times [0, 1]$ 粘合 $(0, y) \sim (1, 1-y)$

**推论 3.1**　$S^n$ 可以看作 $D^n$ 的边界粘为一点。

## 4. 粘合映射

### 4.1 CW 复形

**CW 复形**的构造：
1. 从离散点集（0-胞腔）开始
2. 逐维粘合 $n$-胞腔（$n$-维圆盘）到已有的 $(n-1)$-骨架

**例子**：
- $S^n$：一个 0-胞腔 + 一个 $n$-胞腔
- 环面：一个 0-胞腔 + 两个 1-胞腔 + 一个 2-胞腔
- 射影平面 $\mathbb{RP}^2$：一个 0-胞腔 + 一个 1-胞腔 + 一个 2-胞腔

**推论 4.1**　CW 复形的 Euler 示性数 $= \sum (-1)^k c_k$，其中 $c_k$ 是 $k$-胞腔的个数。

## 5. 拓扑流形

### 5.1 定义

**定义 5.1**　$n$-维**拓扑流形**：Hausdorff、第二可数、每一点有邻域同胚于 $\mathbb{R}^n$ 的开集。

### 5.2 常见流形

| 流形 | 维数 | 构造 |
|------|------|------|
| $S^n$ | $n$ | $\mathbb{R}^{n+1}$ 中单位球面 |
| $T^n$ | $n$ | $n$-维环面，$S^1 \times \cdots \times S^1$ |
| $\mathbb{RP}^n$ | $n$ | 实射影空间，$S^n / (x \sim -x)$ |
| $\mathbb{CP}^n$ | $2n$ | 复射影空间 |
| Klein 瓶 | 2 | Möbius 带的边界粘合 |

**推论 5.1**　紧致流形的 Euler 示性数是拓扑不变量。
