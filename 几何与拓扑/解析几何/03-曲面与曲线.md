# 曲面与曲线

> 从一维到二维——曲面是空间中的二维对象，曲线是一维的。

## 1. 曲面

### 1.1 一般方程

**隐式**：$F(x, y, z) = 0$

**显式**：$z = f(x, y)$

**参数式**：$\mathbf{r}(u, v) = (x(u, v), y(u, v), z(u, v))$

**推论 1.1**　显式方程 $z = f(x, y)$ 是隐式方程 $F(x, y, z) = z - f(x, y) = 0$ 的特殊情况。

### 1.2 旋转曲面

曲线 $\begin{cases} f(y, z) = 0 \\ x = 0 \end{cases}$ 绕 $z$ 轴旋转：

$$f(\pm\sqrt{x^2 + y^2}, z) = 0$$

**一般规则**：绕哪根轴旋转，该轴对应的变量不变，另一变量替换为 $\pm\sqrt{\text{两变量平方和}}$。

**例子**：
- 球面：$x^2 + y^2 + z^2 = R^2$
- 旋转抛物面：$z = x^2 + y^2$
- 旋转椭球面：$\frac{x^2 + y^2}{a^2} + \frac{z^2}{c^2} = 1$
- 圆锥面：$x^2 + y^2 = z^2 \tan^2\alpha$

**推论 1.2**　旋转曲面的法截线（过旋转轴的截面）都是全等的平面曲线。

### 1.3 柱面

准线沿方向 $\mathbf{v}$ 拉伸：

$$\text{准线 } \begin{cases} F(x, y) = 0 \\ z = 0 \end{cases} \text{ 沿 } z \text{ 轴} \Rightarrow F(x, y) = 0$$

**定义**：柱面是由一族平行直线（母线）构成的曲面。

**推论 1.3**　方程 $F(x, y) = 0$（不含 $z$）表示母线平行于 $z$ 轴的柱面。

## 2. 二次曲面

### 2.1 标准形式

| 名称 | 方程 |
|------|------|
| 椭球面 | $\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1$ |
| 单叶双曲面 | $\frac{x^2}{a^2} + \frac{y^2}{b^2} - \frac{z^2}{c^2} = 1$ |
| 双叶双曲面 | $\frac{x^2}{a^2} + \frac{y^2}{b^2} - \frac{z^2}{c^2} = -1$ |
| 椭圆抛物面 | $z = \frac{x^2}{a^2} + \frac{y^2}{b^2}$ |
| 双曲抛物面 | $z = \frac{x^2}{a^2} - \frac{y^2}{b^2}$ |
| 二次锥面 | $\frac{x^2}{a^2} + \frac{y^2}{b^2} - \frac{z^2}{c^2} = 0$ |

**推论 2.1**　椭球面 $a = b = c = R$ 时退化为球面。

**推论 2.2**　二次锥面是单叶双曲面和双叶双曲面的"极限"（令常数项趋于零）。

### 2.2 直纹面

**定义**：由一族直线构成的曲面。

**直纹二次曲面**：
- 单叶双曲面（两族直母线）
- 双曲抛物面（两族直母线）
- 二次锥面
- 柱面、锥面

**定理 2.1**　单叶双曲面和双曲抛物面上有两族直母线，同一族的直母线异面，不同族的直母线共面。

### 2.3 截痕法

用平行于坐标面的平面截曲面，分析截线形状。

**例**：单叶双曲面 $\frac{x^2}{a^2} + \frac{y^2}{b^2} - \frac{z^2}{c^2} = 1$
- $z = z_0$：椭圆（$z_0$ 任意）
- $y = 0$：双曲线
- $x = 0$：双曲线

**应用**：截痕法是识别二次曲面类型的主要方法。

## 3. 空间曲线

### 3.1 表示

**参数式**：$\mathbf{r}(t) = (x(t), y(t), z(t))$

**交面式**：$\begin{cases} F(x, y, z) = 0 \\ G(x, y, z) = 0 \end{cases}$

**推论 3.1**　交面式表示曲线为两曲面的交线。

### 3.2 切线与法平面

**切向量**：$\mathbf{r}'(t_0) = (x'(t_0), y'(t_0), z'(t_0))$

**切线**：$\frac{x - x_0}{x'} = \frac{y - y_0}{y'} = \frac{z - z_0}{z'}$

**法平面**：$x'(x - x_0) + y'(y - y_0) + z'(z - z_0) = 0$

**推论 3.2**　法平面是过切点且垂直于切向量的平面。

### 3.3 密切平面与从切平面

**副法向量**：$\mathbf{b} = \mathbf{r}' \times \mathbf{r}''$

**密切平面**：$\mathbf{b} \cdot (\mathbf{r} - \mathbf{r}_0) = 0$

**Frenet 标架**：$\{\mathbf{t}, \mathbf{n}, \mathbf{b}\}$，其中：
- $\mathbf{t}$：切向量（单位化）
- $\mathbf{n}$：主法向量
- $\mathbf{b}$：副法向量

**定理 3.1（Frenet-Serret 公式）**：

$$\begin{pmatrix} \mathbf{t}' \\ \mathbf{n}' \\ \mathbf{b}' \end{pmatrix} = \begin{pmatrix} 0 & \kappa & 0 \\ -\kappa & 0 & \tau \\ 0 & -\tau & 0 \end{pmatrix} \begin{pmatrix} \mathbf{t} \\ \mathbf{n} \\ \mathbf{b} \end{pmatrix}$$

其中 $\kappa$ 为曲率，$\tau$ 为挠率。

## 4. 常见曲线

| 曲线 | 参数方程 |
|------|----------|
| 圆 | $(R\cos t, R\sin t)$ |
| 椭圆 | $(a\cos t, b\sin t)$ |
| 螺旋线 | $(R\cos t, R\sin t, ht)$ |
| 摆线 | $(R(t - \sin t), R(1 - \cos t))$ |
| 心形线 | $(a(2\cos t - \cos 2t), a(2\sin t - \sin 2t))$ |

**推论 4.1**　圆螺旋线的曲率和挠率均为常数。

## 5. 曲面的切平面与法线

### 5.1 隐式方程

曲面 $F(x, y, z) = 0$ 在点 $P_0$ 处：
- **法向量**：$\mathbf{n} = \nabla F(P_0) = (F_x, F_y, F_z)$
- **切平面**：$F_x(x - x_0) + F_y(y - y_0) + F_z(z - z_0) = 0$
- **法线**：$\frac{x - x_0}{F_x} = \frac{y - y_0}{F_y} = \frac{z - z_0}{F_z}$

### 5.2 参数方程

曲面 $\mathbf{r}(u, v)$ 在点 $(u_0, v_0)$ 处：
- **法向量**：$\mathbf{n} = \mathbf{r}_u \times \mathbf{r}_v$
- **切平面**：$[\mathbf{r} - \mathbf{r}_0, \mathbf{r}_u, \mathbf{r}_v] = 0$
