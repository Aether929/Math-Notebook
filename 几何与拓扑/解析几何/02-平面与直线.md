# 平面与直线

> 空间中最基本的几何对象——平面是二维的，直线是一维的。

## 1. 平面方程

### 1.1 各种形式

| 形式 | 方程 |
|------|------|
| 点法式 | $A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$ |
| 一般式 | $Ax + By + Cz + D = 0$ |
| 截距式 | $\frac{x}{a} + \frac{y}{b} + \frac{z}{c} = 1$ |
| 三点式 | $\begin{vmatrix} x - x_1 & y - y_1 & z - z_1 \\ x_2 - x_1 & y_2 - y_1 & z_2 - z_1 \\ x_3 - x_1 & y_3 - y_1 & z_3 - z_1 \end{vmatrix} = 0$ |

法向量：$\mathbf{n} = (A, B, C)$

**推论 1.1**　一般式 $Ax + By + Cz + D = 0$ 中，$D = 0$ $\iff$ 平面过原点。

**推论 1.2**　截距式要求 $a, b, c$ 均非零，即平面不经过原点且不平行于任何坐标轴。

### 1.2 点到平面的距离

$$d = \frac{|Ax_0 + By_0 + Cz_0 + D|}{\sqrt{A^2 + B^2 + C^2}}$$

**证明提示**：设 $P_0 = (x_0, y_0, z_0)$，$P_1$ 为 $P_0$ 在平面上的投影，则 $d = |\overrightarrow{P_1 P_0} \cdot \frac{\mathbf{n}}{|\mathbf{n}|}|$。

**推论 1.3**　两平行平面 $Ax + By + Cz + D_1 = 0$ 和 $Ax + By + Cz + D_2 = 0$ 的距离：

$$d = \frac{|D_1 - D_2|}{\sqrt{A^2 + B^2 + C^2}}$$

### 1.3 两平面的夹角

$$\cos\theta = \frac{|\mathbf{n}_1 \cdot \mathbf{n}_2|}{|\mathbf{n}_1| |\mathbf{n}_2|}$$

**推论 1.4**　两平面垂直 $\iff$ $\mathbf{n}_1 \cdot \mathbf{n}_2 = 0$ $\iff$ $A_1 A_2 + B_1 B_2 + C_1 C_2 = 0$。

## 2. 直线方程

### 2.1 各种形式

| 形式 | 方程 |
|------|------|
| 参数式 | $x = x_0 + lt, \ y = y_0 + mt, \ z = z_0 + nt$ |
| 对称式 | $\frac{x - x_0}{l} = \frac{y - y_0}{m} = \frac{z - z_0}{n}$ |
| 两点式 | $\frac{x - x_1}{x_2 - x_1} = \frac{y - y_1}{y_2 - y_1} = \frac{z - z_1}{z_2 - z_1}$ |
| 交面式 | $\begin{cases} A_1 x + B_1 y + C_1 z + D_1 = 0 \\ A_2 x + B_2 y + C_2 z + D_2 = 0 \end{cases}$ |

方向向量：$\mathbf{v} = (l, m, n)$

**推论 2.1**　对称式中若某个分母为零（如 $l = 0$），则对应分子也为零（$x - x_0 = 0$），表示直线平行于 $yz$ 平面。

### 2.2 点到直线的距离

$$d = \frac{|\mathbf{v} \times \overrightarrow{P_0 P}|}{|\mathbf{v}|}$$

**等价形式**：$d = |\overrightarrow{P_0 P}| \sin\theta$，其中 $\theta$ 为 $\overrightarrow{P_0 P}$ 与方向向量的夹角。

### 2.3 两直线的夹角

$$\cos\theta = \frac{|\mathbf{v}_1 \cdot \mathbf{v}_2|}{|\mathbf{v}_1| |\mathbf{v}_2|}$$

### 2.4 异面直线的距离

$$d = \frac{|[\mathbf{v}_1 \mathbf{v}_2 \overrightarrow{P_1 P_2}]|}{|\mathbf{v}_1 \times \mathbf{v}_2|}$$

**几何意义**：异面直线的距离等于两直线上各取一点的连线在公垂线方向上的投影长度。

**推论 2.2**　两直线共面 $\iff$ $[\mathbf{v}_1 \mathbf{v}_2 \overrightarrow{P_1 P_2}] = 0$。

### 2.5 公垂线

异面直线的公垂线方向为 $\mathbf{v}_1 \times \mathbf{v}_2$。

**定理 2.1**　异面直线有且仅有一条公垂线。

## 3. 位置关系

### 3.1 平面与平面

| 关系 | 条件 |
|------|------|
| 平行 | $\mathbf{n}_1 \parallel \mathbf{n}_2$（$\mathbf{n}_1 \times \mathbf{n}_2 = \mathbf{0}$） |
| 重合 | 平行且共点 |
| 相交 | 不平行，交于一条直线 |

**推论 3.1**　两平面平行 $\iff$ $\frac{A_1}{A_2} = \frac{B_1}{B_2} = \frac{C_1}{C_2}$（比例系数相等）。

**推论 3.2**　两平面重合 $\iff$ $\frac{A_1}{A_2} = \frac{B_1}{B_2} = \frac{C_1}{C_2} = \frac{D_1}{D_2}$。

### 3.2 直线与平面

| 关系 | 条件 |
|------|------|
| 平行 | $\mathbf{v} \cdot \mathbf{n} = 0$ 且 $P_0 \notin \pi$ |
| 在平面上 | $\mathbf{v} \cdot \mathbf{n} = 0$ 且 $P_0 \in \pi$ |
| 相交 | $\mathbf{v} \cdot \mathbf{n} \neq 0$ |
| 垂直 | $\mathbf{v} \parallel \mathbf{n}$ |

**推论 3.3**　直线与平面的夹角 $\varphi$ 满足 $\sin\varphi = \frac{|\mathbf{v} \cdot \mathbf{n}|}{|\mathbf{v}| |\mathbf{n}|}$。

### 3.3 直线与直线

| 关系 | 条件 |
|------|------|
| 平行 | $\mathbf{v}_1 \parallel \mathbf{v}_2$ |
| 相交 | $\mathbf{v}_1, \mathbf{v}_2, \overrightarrow{P_1 P_2}$ 共面 |
| 异面 | $[\mathbf{v}_1 \mathbf{v}_2 \overrightarrow{P_1 P_2}] \neq 0$ |
| 垂直 | $\mathbf{v}_1 \cdot \mathbf{v}_2 = 0$ |

## 4. 平面束

### 4.1 定义

过直线 $\begin{cases} A_1 x + B_1 y + C_1 z + D_1 = 0 \\ A_2 x + B_2 y + C_2 z + D_2 = 0 \end{cases}$ 的所有平面构成**平面束**：

$$\lambda(A_1 x + B_1 y + C_1 z + D_1) + \mu(A_2 x + B_2 y + C_2 z + D_2) = 0$$

**推论 4.1**　平面束中不含平面 $A_2 x + B_2 y + C_2 z + D_2 = 0$ 本身（$\lambda = 0$ 时除外）。

### 4.2 应用

**求过直线的平面**：用平面束方程，再附加一个条件确定 $\lambda : \mu$。

**求直线与平面的交点**：将直线参数式代入平面方程求参数。
