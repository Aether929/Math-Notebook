# 二次曲面的分类

> 通过不变量系统地分类所有二次曲面。

## 1. 一般二次方程

$$F(x, y, z) = a_{11}x^2 + a_{22}y^2 + a_{33}z^2 + 2a_{12}xy + 2a_{13}xz + 2a_{23}yz + 2b_1 x + 2b_2 y + 2b_3 z + c = 0$$

**矩阵形式**：$\mathbf{x}^T A \mathbf{x} + 2\mathbf{b}^T \mathbf{x} + c = 0$

其中 $A = \begin{pmatrix} a_{11} & a_{12} & a_{13} \\ a_{12} & a_{22} & a_{23} \\ a_{13} & a_{23} & a_{33} \end{pmatrix}$

**推论 1.1**　$A$ 是实对称矩阵，因此一定可以正交对角化。

---

## 2. 不变量

通过坐标变换（旋转 + 平移），以下量不变：

| 不变量 | 定义 |
|--------|------|
| $I_1$ | $\text{tr}(A) = a_{11} + a_{22} + a_{33}$ |
| $I_2$ | $A$ 的二阶主子式之和 |
| $I_3$ | $\det(A)$ |
| $I_4$ | $\begin{vmatrix} A & \mathbf{b} \\ \mathbf{b}^T & c \end{vmatrix}$ |
| $K_2$ | $\begin{vmatrix} a_{11} & b_1 \\ b_1 & c \end{vmatrix} + \begin{vmatrix} a_{22} & b_2 \\ b_2 & c \end{vmatrix} + \begin{vmatrix} a_{33} & b_3 \\ b_3 & c \end{vmatrix}$ |

**定理 2.1**　两个二次曲面等价（可通过坐标变换互相转化） $\iff$ 它们有相同的不变量组。

**推论 2.1**　$I_1, I_2, I_3$ 是矩阵 $A$ 的特征值的初等对称多项式。

**推论 2.2**　$I_3 > 0$ $\iff$ $A$ 的三个特征值同号；$I_3 < 0$ $\iff$ 特征值两正一负或两负一正。

---

## 3. 分类表

| 条件 | 类型 |
|------|------|
| $I_3 \neq 0$（中心曲面） | |
| $I_3 > 0, I_4 / I_3 < 0$ | 椭球面 |
| $I_3 > 0, I_4 / I_3 > 0$ | 虚椭球面（无实点） |
| $I_3 < 0$ | 单叶双曲面（$I_4 \neq 0$）或二次锥面（$I_4 = 0$） |
| $I_3 = 0$（无中心或无穷多中心） | |
| $I_4 \neq 0$ | 抛物面（椭圆 / 双曲） |
| $I_4 = 0$ | 柱面、锥面或退化 |

### 3.1 详细分类

**椭球面型**（$I_3 > 0$）：
- $I_4 < 0$：椭球面
- $I_4 > 0$：虚椭球面
- $I_4 = 0$：点（退化）

**双曲面型**（$I_3 < 0$）：
- $I_4 \neq 0$：单叶双曲面
- $I_4 = 0$：二次锥面

**抛物面型**（$I_3 = 0, I_4 \neq 0$）：
- $I_2 > 0$：椭圆抛物面
- $I_2 < 0$：双曲抛物面

**柱面型**（$I_3 = 0, I_4 = 0$）：
- $I_2 > 0$：椭圆柱面（或虚椭圆柱面、一条直线）
- $I_2 < 0$：双曲柱面
- $I_2 = 0$：抛物柱面

**推论 3.1**　退化二次曲面（$I_3 = I_4 = 0$）的类型取决于 $K_2$ 的符号。

## 4. 化标准形

### 4.1 步骤

1. **旋转**：用正交变换消去交叉项 $xy, xz, yz$（对 $A$ 做对角化）
2. **平移**：消去一次项
3. **整理**：化为标准形式

### 4.2 旋转

**定理 4.1**　存在正交矩阵 $P$ 使得 $P^T A P = \text{diag}(\lambda_1, \lambda_2, \lambda_3)$，其中 $\lambda_i$ 为 $A$ 的特征值。

**步骤**：
1. 求 $A$ 的特征值 $\lambda_1, \lambda_2, \lambda_3$
2. 求对应的单位特征向量，构造正交矩阵 $P$
3. 做变换 $\mathbf{x} = P \mathbf{x}'$

### 4.3 平移

旋转后方程化为 $\lambda_1 x'^2 + \lambda_2 y'^2 + \lambda_3 z'^2 + 2b_1' x' + 2b_2' y' + 2b_3' z' + c = 0$。

对每个非零 $\lambda_i$，配方消去一次项。

### 4.4 例子

**例**：$x^2 + 4y^2 + z^2 - 2xy + 4xz - 8yz - 2x + 4y - 2z + 3 = 0$

1. 写出矩阵 $A$，求特征值
2. 用特征向量构造旋转矩阵
3. 旋转后化简

## 5. 二次曲面的几何性质

### 5.1 对称性

**定理 5.1**　二次曲面的对称中心（若存在）是方程组 $A\mathbf{x} + \mathbf{b} = \mathbf{0}$ 的解。

**推论 5.1**　$A$ 可逆 $\iff$ 二次曲面有唯一对称中心。

### 5.2 渐近方向

**定义**：方向 $(l, m, n)$ 若满足 $al^2 + bm^2 + cn^2 + 2fln + 2gmn + 2hlm = 0$，则为**渐近方向**。

**推论 5.2**　椭球面没有实渐近方向；双曲面有两族渐近方向。
