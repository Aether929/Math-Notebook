# 曲面上的向量场

> 内蕴几何——协变导数、平行移动与测地曲率。

## 1. 曲面上的协变导数

### 1.1 切空间

曲面 $S$ 在点 $p$ 的**切空间** $T_p S$：由 $\mathbf{r}_u, \mathbf{r}_v$ 张成的二维空间。

切向量：$\mathbf{v} = v_1 \mathbf{r}_u + v_2 \mathbf{r}_v$

**推论 1.1**　切空间是曲面在该点的最佳线性逼近。

### 1.2 协变导数

设 $\mathbf{V}(t)$ 是曲面上的切向量场，其**协变导数**（切向分量）：

$$\frac{D\mathbf{V}}{dt} = \left(\frac{d\mathbf{V}}{dt}\right)^{\text{切向}} = \frac{d\mathbf{V}}{dt} - \left(\frac{d\mathbf{V}}{dt} \cdot \mathbf{n}\right) \mathbf{n}$$

**几何意义**：协变导数是向量场在曲面上的"内在变化率"。

**推论 1.2**　协变导数只依赖于第一基本形式（内蕴量）。

### 1.3 Christoffel 符号

$$\mathbf{r}_{uu} = \Gamma^1_{11} \mathbf{r}_u + \Gamma^2_{11} \mathbf{r}_v + L \mathbf{n}$$

$$\mathbf{r}_{uv} = \Gamma^1_{12} \mathbf{r}_u + \Gamma^2_{12} \mathbf{r}_v + M \mathbf{n}$$

$$\mathbf{r}_{vv} = \Gamma^1_{22} \mathbf{r}_u + \Gamma^2_{22} \mathbf{r}_v + N \mathbf{n}$$

**推论 1.3**　Christoffel 符号可以由第一基本形式的系数 $E, F, G$ 及其偏导数表示。

## 2. 平行移动

### 2.1 定义

切向量 $\mathbf{V}$ 沿曲线**平行移动**，若 $\frac{D\mathbf{V}}{dt} = 0$。

### 2.2 平行移动方程

$$\begin{cases} \dot{V}^1 + \Gamma^1_{11} V^1 \dot{u} + \Gamma^1_{12}(V^1 \dot{v} + V^2 \dot{u}) + \Gamma^1_{22} V^2 \dot{v} = 0 \\ \dot{V}^2 + \Gamma^2_{11} V^1 \dot{u} + \Gamma^2_{12}(V^1 \dot{v} + V^2 \dot{u}) + \Gamma^2_{22} V^2 \dot{v} = 0 \end{cases}$$

**推论 2.1**　平行移动保持向量的长度和夹角（保度量性）。

### 2.3 平行移动与曲率

**关键现象**：沿闭曲线平行移动后，向量一般不会回到原来的方向。

> **例子**：球面上沿赤道平行移动，再沿经线移动，向量会旋转——旋转角度 = 曲率 × 面积。

**定理 2.1**　沿闭曲线平行移动的旋转角等于该曲线包围区域的总曲率：

$$\Delta\theta = \iint_D K \, dA$$

**推论 2.2**　平面上（$K = 0$）平行移动与路径无关；球面上（$K > 0$）与路径有关。

## 3. 测地线的进一步讨论

### 3.1 测地线作为"自平行"曲线

测地线的切向量沿自身平行移动：$\frac{D\mathbf{T}}{ds} = 0$

**推论 3.1**　测地线是曲面上的"直线"——切方向不变化的曲线。

### 3.2 测地曲率

$$\kappa_g = \frac{(\mathbf{r}' \times \mathbf{r}'') \cdot \mathbf{n}}{|\mathbf{r}'|^3}$$

测地线 $\iff$ $\kappa_g = 0$

**定理 3.1（Liouville 公式）**：对正交参数网（$F = 0$）：

$$\kappa_g = \frac{d\theta}{ds} + \frac{1}{2\sqrt{G}} \frac{\partial \ln E}{\partial v} \cos\theta - \frac{1}{2\sqrt{E}} \frac{\partial \ln G}{\partial u} \sin\theta$$

其中 $\theta$ 是曲线与 $u$-线的夹角。

### 3.3 Gauss-Bonnet 公式（局部）

设 $D$ 是曲面上的单连通区域，$\partial D$ 分段光滑：

$$\int_{\partial D} \kappa_g \, ds + \iint_D K \, dA = 2\pi - \sum_i \alpha_i$$

其中 $\alpha_i$ 是边界上的外角。

**推论 3.2**　平面上简单闭曲线的总曲率等于 $2\pi$。

**推论 3.3**　球面上三角形的内角和 $= \pi + \iint K \, dA$。

## 4. 内蕴几何

### 4.1 内蕴量

只依赖于第一基本形式的量：
- 弧长、面积、夹角
- 测地曲率
- Gauss 曲率
- Christoffel 符号

### 4.2 外蕴量

依赖于曲面在空间中嵌入的量：
- 法向量
- 主曲率、平均曲率
- 第二基本形式

### 4.3 Gauss 绝妙定理的意义

$K$ 是内蕴的 $\Rightarrow$ 曲面的弯曲是"内禀"的，不需要参照外部空间。

> **推论**：球面上的三角形内角和 $> \pi$，双曲面上的三角形内角和 $< \pi$。这些可以从曲面内部测量得到。

**推论 4.1**　等距映射保持 Gauss 曲率——这是 Gauss 绝妙定理的直接推论。

---

## 5. 测地坐标

### 5.1 法坐标

以 $p$ 为中心的**法坐标**：沿从 $p$ 出发的测地线参数化。

性质：$\Gamma^k_{ij}(p) = 0$（Christoffel 符号在中心为零）。

**推论 5.1**　法坐标下，测地线过原点时为直线。

### 5.2 测地极坐标

$$ds^2 = dr^2 + G(r, \theta) \, d\theta^2$$

其中 $G$ 满足 Jacobi 方程：$G_{rr} + KG = 0$，$G(0, \theta) = 0$，$G_r(0, \theta) = 1$。

- $K = 0$：$G = r$（平面）
- $K = 1$：$G = \sin r$（球面）
- $K = -1$：$G = \sinh r$（双曲面）

**推论 5.2**　常曲率空间的度量完全由曲率值决定。
