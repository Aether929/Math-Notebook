## 学习路线

```
曲线论 → 曲面论 → 曲面上的向量场 → 整体微分几何
                                      ↓
                               Riemann 几何 → 广义相对论
```

## 核心定理

| 定理 | 内容 |
|------|------|
| 曲线论基本定理 | 曲率 + 挠率 $\iff$ 曲线形状 |
| Gauss 绝妙定理 | Gauss 曲率是内蕴的 |
| Gauss-Bonnet 公式 | $\iint K \, dA = 2\pi\chi(M)$ |
| Poincaré-Hopf 定理 | 向量场零点指标和 $= \chi(M)$ |
