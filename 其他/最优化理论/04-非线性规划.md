# 非线性规划

> 非线性目标函数和约束——最一般的优化问题。

## 1. 基本概念

### 1.1 问题形式

**定义 1.1**　**非线性规划**（NLP）：

$$\min f(x) \quad \text{s.t.} \quad g_i(x) \leq 0, \, h_j(x) = 0$$

其中至少一个函数是非线性的。

**推论 1.1**　非线性规划是最一般的优化问题——线性规划、二次规划都是特例。

### 1.2 与凸优化的关系

- **凸优化**：目标函数和约束都是凸的——局部最优 = 全局最优
- **非凸优化**：可能存在多个局部极小点——全局优化更困难

---

## 2. 一般理论

### 2.1 最优性条件

**定理 2.1**（KKT 条件）：在约束规范下，局部极小点满足 KKT 条件。

**推论 2.1**　KKT 条件是非线性规划的核心——它是最优解的必要条件。

### 2.2 约束规范

**LICQ**：起作用约束的梯度线性独立。

**MFCQ**（Mangasarian-Fromovitz）：存在方向使不等式约束严格减小。

**推论 2.2**　约束规范保证乘子存在——是 KKT 条件成立的前提。

---

## 3. 算法

### 3.1 序列二次规划（SQP）

**算法 3.1**（SQP）：
1. 在当前点 $x_k$ 构造二次规划子问题
2. 求解 QP 得到方向 $d_k$
3. 线搜索确定步长 $\alpha_k$
4. 更新：$x_{k+1} = x_k + \alpha_k d_k$

**定理 3.1**：SQP 超线性收敛。

**推论 3.1**　SQP 是非线性规划最有效的方法之一——利用了问题的结构。

### 3.2 增广 Lagrange 方法

**定义 3.1**　**增广 Lagrange 函数**：

$$L_A(x, \lambda, \mu, \rho) = f(x) + \sum_i \lambda_i g_i(x) + \frac{\rho}{2} \sum_i g_i(x)^2$$

**算法 3.2**：交替更新 $x$ 和乘子 $\lambda$。

**推论 3.2**　增广 Lagrange 方法比罚函数法更稳定——乘子估计提供了更好的信息。

### 3.3 信赖域方法

**算法 3.3**（信赖域）：
1. 在当前点 $x_k$ 构造模型 $m_k(d)$
2. 求解信赖域子问题：$\min m_k(d)$，$\|d\| \leq \Delta_k$
3. 计算比值 $\rho_k = \frac{f(x_k) - f(x_k + d_k)}{m_k(0) - m_k(d_k)}$
4. 根据 $\rho_k$ 更新 $x_k$ 和信赖域半径 $\Delta_k$

**推论 3.3**　信赖域方法比线搜索更稳健——自动调整步长。

---

## 4. 全局优化

### 4.1 困难性

**定义 4.1**　**全局优化**：寻找全局极小点——比局部优化难得多。

**推论 4.1**　非凸问题的全局优化是 NP-hard 的——没有通用的多项式时间算法。

### 4.2 方法

- **分支定界**：系统搜索解空间
- **多起点局部优化**：从多个初始点运行局部优化
- **模拟退火**：随机搜索
- **遗传算法**：进化方法
