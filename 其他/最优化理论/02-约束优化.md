# 约束优化

> 带约束条件的优化——Lagrange 乘子法与 KKT 条件。

## 1. 基本概念

### 1.1 问题形式

**定义 1.1**　**约束优化问题**：

$$\min f(x) \quad \text{s.t.} \quad g_i(x) = 0, \, h_j(x) \leq 0$$

其中 $g_i$ 是等式约束，$h_j$ 是不等式约束。

### 1.2 可行域

**定义 1.2**　**可行域**：满足所有约束的点集。

$$\mathcal{F} = \{x : g_i(x) = 0, \, h_j(x) \leq 0\}$$

---

## 2. Lagrange 乘子法

### 2.1 Lagrange 函数

**定义 2.1**　**Lagrange 函数**：

$$L(x, \lambda, \mu) = f(x) + \sum_i \lambda_i g_i(x) + \sum_j \mu_j h_j(x)$$

### 2.2 必要条件

**定理 2.1**（一阶必要条件）：若 $x^*$ 是局部极小点且约束规范满足，则存在 $\lambda^*, \mu^*$ 使得：

$$\nabla_x L(x^*, \lambda^*, \mu^*) = 0$$
$$g_i(x^*) = 0, \quad h_j(x^*) \leq 0$$
$$\mu_j^* \geq 0, \quad \mu_j^* h_j(x^*) = 0$$

**推论 2.1**　Lagrange 乘子法将约束优化转化为无约束优化——通过引入乘子。

---

## 3. KKT 条件

### 3.1 Karush-Kuhn-Tucker 条件

**定义 3.1**　**KKT 条件**：

1. **驻点条件**：$\nabla f(x^*) + \sum_i \lambda_i^* \nabla g_i(x^*) + \sum_j \mu_j^* \nabla h_j(x^*) = 0$
2. **原始可行性**：$g_i(x^*) = 0$，$h_j(x^*) \leq 0$
3. **对偶可行性**：$\mu_j^* \geq 0$
4. **互补松弛**：$\mu_j^* h_j(x^*) = 0$

**定理 3.1**：在约束规范下，局部极小点满足 KKT 条件。

**推论 3.1**　KKT 条件是约束优化的核心——它是最优解的必要条件。

### 3.2 约束规范

**LICQ**（线性独立约束规范）：在 $x^*$ 处起作用的约束的梯度线性独立。

**Slater 条件**：存在严格可行点（对凸问题）。

---

## 4. 对偶理论

### 4.1 Lagrange 对偶

**定义 4.1**　**对偶函数**：

$$q(\lambda, \mu) = \min_x L(x, \lambda, \mu)$$

**对偶问题**：

$$\max q(\lambda, \mu) \quad \text{s.t.} \quad \mu \geq 0$$

### 4.2 强对偶

**定理 4.1**（弱对偶）：$q(\lambda, \mu) \leq f(x)$，$\forall x \in \mathcal{F}$。

**定理 4.2**（强对偶）：对凸问题且 Slater 条件满足，强对偶成立。

**推论 4.1**　强对偶将原问题和对偶问题联系起来——对偶间隙为零。

---

## 5. 惩罚方法

### 5.1 外罚函数法

**定义 5.1**　**外罚函数**：

$$P(x, \rho) = f(x) + \frac{\rho}{2} \sum_i g_i(x)^2 + \frac{\rho}{2} \sum_j [\max(0, h_j(x))]^2$$

**算法 5.1**：逐步增大 $\rho$，求解无约束问题。

### 5.2 内罚函数法（障碍法）

**定义 5.2**　**内罚函数**：

$$B(x, \mu) = f(x) - \mu \sum_j \log(-h_j(x))$$

**推论 5.1**　障碍法保持可行性——适合内点法。
