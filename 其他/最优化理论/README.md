## 核心思想

最优化理论研究如何找到"最好"的解：
- **无约束优化**：梯度下降、Newton 法、拟 Newton 法
- **约束优化**：Lagrange 乘子法、KKT 条件、对偶理论
- **凸优化**：局部最优 = 全局最优，多项式时间算法
- **非凸优化**：NP-hard，需要启发式方法
- **组合优化**：离散问题，近似算法和启发式

## 与其他分支的关系

- **线性代数**：矩阵运算、特征值问题
- **微积分**：梯度、Hessian、Taylor 展开
- **概率论**：随机优化、贝叶斯优化
- **运筹学**：线性规划、整数规划、网络优化
