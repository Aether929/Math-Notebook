# 凸优化

> 凸函数在凸集上的优化——最优化理论中最优美的部分。

## 1. 基本概念

### 1.1 凸集

**定义 1.1**　集合 $C$ 是**凸集**，若对任意 $x, y \in C$ 和 $\theta \in [0, 1]$：

$$\theta x + (1 - \theta) y \in C$$

**例子**：
- 超平面：$\{x : a^T x = b\}$
- 半空间：$\{x : a^T x \leq b\}$
- 球：$\{x : \|x - x_0\| \leq r\}$

### 1.2 凸函数

**定义 1.2**　函数 $f$ 是**凸函数**，若对任意 $x, y$ 和 $\theta \in [0, 1]$：

$$f(\theta x + (1 - \theta) y) \leq \theta f(x) + (1 - \theta) f(y)$$

**定理 1.1**：$f$ 是凸函数 $\iff$ $\nabla^2 f(x) \succeq 0$（半正定）。

**推论 1.1**　凸函数的局部极小点就是全局极小点——这是凸优化的核心优势。

## 2. 凸优化问题

### 2.1 标准形式

**定义 2.1**　**凸优化问题**：

$$\min f(x) \quad \text{s.t.} \quad g_i(x) \leq 0, \, A x = b$$

其中 $f$ 和 $g_i$ 是凸函数。

**推论 2.1**　凸优化问题的可行域是凸集——局部最优就是全局最优。

### 2.2 特殊类型

| 类型 | 目标函数 | 约束 |
|------|----------|------|
| 线性规划 | 线性 | 线性 |
| 二次规划 | 二次 | 线性 |
| 二次约束二次规划 | 二次 | 二次 |
| 半定规划 | 线性 | 矩阵不等式 |

## 3. 对偶理论

### 3.1 Lagrange 对偶

**定义 3.1**　**Lagrange 对偶函数**：

$$q(\lambda, \nu) = \inf_x L(x, \lambda, \nu)$$

**对偶问题**：$\max q(\lambda, \nu)$，$\lambda \geq 0$

### 3.2 强对偶

**定理 3.1**（Slater 定理）：对凸问题，若存在严格可行点，则强对偶成立。

**推论 3.1**　Slater 条件是凸问题强对偶的充分条件——比一般问题的约束规范弱。

### 3.3 互补松弛

**定理 3.2**：强对偶成立时，最优解满足互补松弛条件：

$$\lambda_i^* g_i(x^*) = 0$$

## 4. 算法

### 4.1 内点法

**算法 4.1**（障碍法）：
1. 选择初始点 $x_0$，$\mu_0 > 0$
2. 求解 $\min f(x) - \mu \sum \log(-g_i(x))$
3. 减小 $\mu$：$\mu_{k+1} = t \mu_k$
4. 若收敛，停止；否则回到步骤 2

**定理 4.1**：内点法在多项式时间内收敛到 $\epsilon$-最优解。

**推论 4.1**　内点法是凸优化的标准算法——比单纯形法更高效。

### 4.2 次梯度方法

**定义 4.1**　**次梯度**：$g$ 是 $f$ 在 $x$ 处的次梯度，若：

$$f(y) \geq f(x) + g^T (y - x), \quad \forall y$$

**算法 4.2**（次梯度法）：$x_{k+1} = x_k - \alpha_k g_k$
