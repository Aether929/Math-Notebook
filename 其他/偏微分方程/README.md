## 学习路线

```
基本概念与分类 → 波动方程（双曲型）
              → 热传导方程（抛物型）
              → 位势方程（椭圆型）
                    ↓
              二阶线性方程理论（统一框架）
```

## 与其他分支的联系

- **常微分方程**：分离变量法化 PDE 为 ODE
- **泛函分析**：弱解理论需要 Sobolev 空间
- **数值分析**：有限差分/有限元求解 PDE
