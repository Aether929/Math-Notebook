# 基本概念与分类

> 多变量的变化规律——偏微分方程的数学框架。

## 1. 基本概念

### 1.1 定义

**定义 1.1**　**偏微分方程**（PDE）是含有未知函数及其偏导数的等式：

$$F(x_1, \ldots, x_n, u, u_{x_1}, \ldots, u_{x_n}, u_{x_1 x_1}, \ldots) = 0$$

**阶**：方程中出现的最高阶偏导数的阶数。

**解**：满足方程的函数 $u(x_1, \ldots, x_n)$。

**通解**：含有任意函数的解（与 ODE 的任意常数不同）。

### 1.2 重要例子

| 方程 | 形式 | 物理背景 |
|------|------|----------|
| Laplace 方程 | $\Delta u = 0$ | 稳态温度、静电场 |
| 热传导方程 | $u_t = a^2 \Delta u$ | 热传导、扩散 |
| 波动方程 | $u_{tt} = a^2 \Delta u$ | 声波、电磁波 |
| Schrödinger 方程 | $i\hbar u_t = -\frac{\hbar^2}{2m} \Delta u + Vu$ | 量子力学 |

**推论 1.1**　偏微分方程是描述连续介质物理的基本工具。

## 2. 二阶线性方程的分类

### 2.1 一般形式

两个自变量的二阶线性方程：

$$a u_{xx} + 2b u_{xy} + c u_{yy} + d u_x + e u_y + f u = g$$

### 2.2 分类判据

**判别式**：$\Delta = b^2 - ac$。

| 类型 | 条件 | 标准形 | 典型方程 |
|------|------|--------|----------|
| **椭圆型** | $\Delta < 0$ | $u_{\xi\xi} + u_{\eta\eta} = \cdots$ | Laplace |
| **双曲型** | $\Delta > 0$ | $u_{\xi\eta} = \cdots$ 或 $u_{\xi\xi} - u_{\eta\eta} = \cdots$ | 波动 |
| **抛物型** | $\Delta = 0$ | $u_{\eta\eta} = \cdots$ | 热传导 |

**定理 2.1**：通过自变量的非退化线性变换，方程可化为标准形。

**推论 2.1**　分类决定了方程的基本性质——不同类型需要不同的求解方法和边界条件。

### 2.3 物理意义

- **椭圆型**：平衡/稳态问题（无时间变量）
- **双曲型**：传播问题（波动、信号）
- **抛物型**：扩散问题（热传导、粘性）

**推论 2.2**　方程类型反映了物理过程的本质——平衡、传播还是扩散。

## 3. 定解条件

### 3.1 初始条件

对含时间的方程，需要**初始条件**（Cauchy 条件）：

- 波动方程：$u(x, 0) = \varphi(x)$, $u_t(x, 0) = \psi(x)$（需要两个初始条件）
- 热传导方程：$u(x, 0) = \varphi(x)$（需要一个初始条件）

**推论 3.1**　初始条件的个数等于方程中时间导数的最高阶数。

### 3.2 边界条件

| 类型 | 形式 | 物理意义 |
|------|------|----------|
| **第一类**（Dirichlet） | $u \vert_{\partial \Omega} = g$ | 给定边界值 |
| **第二类**（Neumann） | $\frac{\partial u}{\partial n} \vert_{\partial \Omega} = g$ | 给定边界法向导数 |
| **第三类**（Robin） | $\left(\frac{\partial u}{\partial n} + \sigma u\right) \vert_{\partial \Omega} = g$ | 混合条件 |

**推论 3.2**　边界条件的选择取决于物理问题——固定边界用 Dirichlet，自由边界用 Neumann。

### 3.3 定解问题

**定义 3.1**：方程 + 初始条件 + 边界条件 = **定解问题**。

**适定性**（Hadamard）：解存在、唯一、连续依赖于数据。

**推论 3.3**　不适定问题需要特殊处理——如正则化方法。

## 4. 叠加原理

### 4.1 线性方程

**定理 4.1**（叠加原理）：设 $L$ 是线性微分算子，$L u_1 = f_1$，$L u_2 = f_2$，则：

$$L(c_1 u_1 + c_2 u_2) = c_1 f_1 + c_2 f_2$$

**推论 4.1**　线性方程的解可以叠加——这是 Fourier 方法和 Green 函数方法的基础。

### 4.2 齐次与非齐次

- **齐次方程**：$Lu = 0$，解的线性组合仍是解
- **非齐次方程**：$Lu = f$，通解 = 齐次通解 + 非齐次特解

**推论 4.2**　非齐次问题可分解为：先解齐次问题，再找特解。

---

## 5. Cauchy-Kovalevskaya 定理

### 5.1 定理

**定理 5.1**（Cauchy-Kovalevskaya）：设方程关于某自变量可解出最高阶导数，且初始数据和方程系数都是解析函数，则 Cauchy 问题存在唯一的解析解。

**推论 5.1**　解析条件下解的存在唯一性有保证——但实际问题中数据往往不够光滑。

### 5.2 局限性

**Hadamard 反例**：Laplace 方程的 Cauchy 问题可以不适定——解不连续依赖于初始数据。

**推论 5.2**　Cauchy-Kovalevskaya 定理不保证适定性——只保证解析解的存在唯一。

## 6. 特征理论

### 6.1 特征

**定义 6.1**：二阶方程的**特征曲面**是使得方程的最高阶导数项在曲面上退化的曲面。

对 $a u_{xx} + 2b u_{xy} + c u_{yy} = \cdots$，特征方程为：

$$a \, dy^2 - 2b \, dx \, dy + c \, dx^2 = 0$$

### 6.2 分类与特征

- **双曲型**：两族实特征线
- **抛物型**：一族实特征线
- **椭圆型**：无实特征线

**定理 6.1**：特征线是信息传播的路径——扰动沿特征线传播。

**推论 6.3**　双曲型方程的解沿特征线传播——因果性与有限传播速度。

**推论 6.4**　椭圆型方程无特征线——扰动瞬间影响全区域（无限传播速度）。

## 7. 应用

### 7.1 物理学
- 电磁学：Maxwell 方程组
- 流体力学：Navier-Stokes 方程
- 广义相对论：Einstein 场方程

### 7.2 工程学
- 结构力学：弹性方程
- 热工学：传热方程
- 声学：声波方程

### 7.3 金融学
- Black-Scholes 方程
- 期权定价
