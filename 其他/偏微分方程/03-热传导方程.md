# 热传导方程

> 扩散与平衡——从热传导到 Brown 运动。

## 1. 方程与定解问题

### 1.1 方程

**一维热传导方程**：

$$u_t = a^2 u_{xx}$$

**高维热传导方程**：

$$u_t = a^2 \Delta u$$

**物理背景**：热传导、扩散过程、金融中的 Black-Scholes 方程。

### 1.2 定解问题

**初值问题**：

$$u_t = a^2 u_{xx}, \quad -\infty < x < +\infty, \, t > 0$$
$$u(x, 0) = \varphi(x)$$

**混合问题**：

$$u_t = a^2 u_{xx}, \quad 0 < x < l, \, t > 0$$
$$u(x, 0) = \varphi(x)$$
$$u(0, t) = u(l, t) = 0$$

**推论 1.1**　热传导方程只需一个初始条件——一阶时间导数。

---

## 2. 基本解

### 2.1 基本解

**定义 2.1**：**基本解**是满足以下方程的函数（$t > 0$）：

$$\Gamma_t = a^2 \Gamma_{xx}$$

初值条件为 $\Gamma(x, 0) = \delta(x)$（Dirac 函数）。

**定理 2.1**：

$$\Gamma(x, t) = \frac{1}{2a\sqrt{\pi t}} \exp\left(-\frac{x^2}{4a^2 t}\right)$$

这是均值为 0、方差为 $2a^2 t$ 的正态分布密度函数。

**推论 2.1**　基本解是 Gaussian 函数——扩散过程的自然结果。

**推论 2.2**　基本解在 $t \to 0^+$ 时趋于 $\delta(x)$——初始时刻的集中热量。

### 2.2 初值问题的解

**定理 2.2**：初值问题的解为卷积：

$$u(x, t) = \int_{-\infty}^{+\infty} \Gamma(x - \xi, t) \varphi(\xi) \, d\xi = \frac{1}{2a\sqrt{\pi t}} \int_{-\infty}^{+\infty} \varphi(\xi) \exp\left(-\frac{(x - \xi)^2}{4a^2 t}\right) \, d\xi$$

**推论 2.3**　解是初始数据的 Gaussian 加权平均——扩散使温度趋于均匀。

**推论 2.4**　$u(x, t)$ 对 $x$ 无穷次可微（$t > 0$）——热传导方程的**正则化效应**。

---

## 3. 分离变量法

### 3.1 混合问题

**边界条件**：$u(0, t) = u(l, t) = 0$。

**特征值**：$\lambda_n = \left(\frac{n\pi}{l}\right)^2$，$n = 1, 2, 3, \ldots$

**特征函数**：$X_n(x) = \sin\frac{n\pi x}{l}$

**解**：

$$u(x, t) = \sum_{n=1}^{\infty} B_n e^{-a^2 \lambda_n t} \sin\frac{n\pi x}{l}$$

其中 $B_n = \frac{2}{l} \int_0^l \varphi(x) \sin\frac{n\pi x}{l} \, dx$。

**推论 3.1**　每个 Fourier 模态按 $e^{-a^2 \lambda_n t}$ 指数衰减——高阶模态衰减更快。

**推论 3.2**　$u(x, t) \to 0$（$t \to +\infty$）——温度趋于零（边界温度为零时）。

### 3.2 不同边界条件

| 边界条件 | 特征函数 | 特征值 |
|----------|----------|--------|
| $u(0) = u(l) = 0$ | $\sin\frac{n\pi x}{l}$ | $(n\pi/l)^2$ |
| $u'(0) = u'(l) = 0$ | $\cos\frac{n\pi x}{l}$ | $(n\pi/l)^2$ |
| $u(0) = u(l)$, $u'(0) = u'(l)$ | $1, \cos\frac{n\pi x}{l}, \sin\frac{n\pi x}{l}$ | $(n\pi/l)^2$ |

**推论 3.3**　边界条件决定了特征函数的类型——Fourier 正弦、余弦或完整级数。

## 4. 极值原理

### 4.1 定理

**定理 4.1**（极值原理）：设 $u$ 在矩形区域 $R = [0, l] \times [0, T]$ 上连续，在 $R$ 内部满足 $u_t = a^2 u_{xx}$，则 $u$ 在 $R$ 的抛物边界（底边和两侧边）上取到最大值和最小值。

**抛物边界**：$\partial_p R = \{x = 0, 0 \leq t \leq T\} \cup \{x = l, 0 \leq t \leq T\} \cup \{0 \leq x \leq l, t = 0\}$。

**推论 4.1**　热传导方程的最大值在初始或边界处取到——内部不会产生新的极值。

### 4.2 唯一性

**定理 4.2**：热传导方程的混合问题的解唯一。

**证明提示**：设 $u_1, u_2$ 是两个解，$w = u_1 - u_2$ 满足齐次方程和零边界条件，由极值原理得 $w \equiv 0$。

**推论 4.2**　极值原理是证明唯一性和稳定性的统一工具。

### 4.3 稳定性

**定理 4.3**：解连续依赖于初始数据和边界数据。

$$\|u_1 - u_2\|_{L^\infty} \leq \|\varphi_1 - \varphi_2\|_{L^\infty} + T \|g_1 - g_2\|_{L^\infty}$$

**推论 4.3**　热传导方程是适定的——小扰动导致小变化。

## 5. Fourier 方法的应用

### 5.1 热传导的物理直觉

- **热量守恒**：$\frac{d}{dt} \int u \, dx = a^2 [u_x]_{\text{边界}}$
- **Fourier 定律**：热流 $q = -k u_x$（热量从高温流向低温）
- **熵增**：热传导使温度均匀化——不可逆过程

### 5.2 无限长杆的热传导

初值问题的解表明：
- 任意初始温度分布最终趋于均匀
- 热量以无穷速度传播（与波动方程不同）
- 解的正则性瞬间提高（$C^\infty$）

**推论 5.1**　热传导方程是抛物型——扩散性质导致无限传播速度。

---

## 6. 非齐次方程

### 6.1 Duhamel 原理

**定理 6.1**：非齐次热传导方程 $u_t = a^2 u_{xx} + f(x, t)$ 的解：

$$u(x, t) = \int_0^t w(x, t - \tau; \tau) \, d\tau$$

其中 $w$ 满足齐次方程，初始条件 $w(x, 0; \tau) = f(x, \tau)$。

**推论 6.1**　Duhamel 原理将持续作用的源分解为瞬时脉冲的叠加。

---

## 7. 最大值原理的推广

### 7.1 强极值原理

**定理 7.1**（强极值原理）：设 $u$ 在有界区域 $\Omega$ 内满足 $u_t = a^2 \Delta u$，且在 $\bar{\Omega} \times [0, T]$ 上取到最大值 $M$。若最大值在 $(\mathbf{x}_0, t_0)$（$\mathbf{x}_0 \in \Omega$, $t_0 > 0$）处取到，则 $u \equiv M$。

**推论 7.1**　非常数解不能在内部取到最大值——强极值原理比弱极值原理更强。

### 7.2 Harnack 不等式

**定理 7.2**：设 $u \geq 0$ 满足热传导方程，则对 $\Omega' \Subset \Omega$：

$$\sup_{\Omega'} u(\cdot, t_1) \leq C \inf_{\Omega'} u(\cdot, t_2), \quad 0 < t_1 < t_2$$

**推论 7.2**　Harnack 不等式控制了解在不同时间的相关性。
