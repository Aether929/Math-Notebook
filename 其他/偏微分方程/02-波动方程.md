# 波动方程

> 振动与传播——从弦振动到电磁波。

## 1. 方程与定解问题

### 1.1 方程

**一维波动方程**：

$$u_{tt} = a^2 u_{xx}$$

**物理背景**：弦振动、杆的纵振动、传输线方程。

**高维波动方程**：

$$u_{tt} = a^2 \Delta u = a^2 (u_{x_1 x_1} + u_{x_2 x_2} + u_{x_3 x_3})$$

### 1.2 定解问题

**初值问题**（Cauchy 问题）：

$$u_{tt} = a^2 u_{xx}, \quad -\infty < x < +\infty, \, t > 0$$
$$u(x, 0) = \varphi(x), \quad u_t(x, 0) = \psi(x)$$

**混合问题**（有界弦）：

$$u_{tt} = a^2 u_{xx}, \quad 0 < x < l, \, t > 0$$
$$u(x, 0) = \varphi(x), \quad u_t(x, 0) = \psi(x)$$
$$u(0, t) = u(l, t) = 0$$

**推论 1.1**　波动方程需要两个初始条件——位移和速度。

## 2. d'Alembert 公式

### 2.1 公式

**定理 2.1**：一维波动方程初值问题的解：

$$u(x, t) = \frac{1}{2}[\varphi(x - at) + \varphi(x + at)] + \frac{1}{2a} \int_{x-at}^{x+at} \psi(s) \, ds$$

### 2.2 推导

**方法**：引入特征坐标 $\xi = x - at$, $\eta = x + at$，方程化为 $u_{\xi\eta} = 0$。

通解：$u = f(\xi) + g(\eta) = f(x - at) + g(x + at)$。

**推论 2.1**　波动方程的解是右行波和左行波的叠加——波的传播。

**推论 2.2**　$u = f(x - at)$ 表示以速度 $a$ 向右传播的波形。

### 2.3 依赖区域与影响区域

**定义 2.1**：点 $(x_0, t_0)$ 的**依赖区域**是 $[x_0 - at_0, x_0 + at_0]$。

**定义 2.2**：区间 $[x_1, x_2]$ 的**影响区域**是 $\{(x, t): x_1 - at \leq x \leq x_2 + at, t > 0\}$。

**推论 2.3**　依赖区域 = 影响解的初始数据范围——因果性的体现。

**推论 2.4**　有限传播速度：扰动以速度 $a$ 传播——与 Laplace 方程的根本区别。

## 3. 分离变量法

### 3.1 方法

设 $u(x, t) = X(x) T(t)$，代入方程得：

$$\frac{T''}{a^2 T} = \frac{X''}{X} = -\lambda$$

得到两个常微分方程：

$$X'' + \lambda X = 0, \quad T'' + a^2 \lambda T = 0$$

### 3.2 混合问题的解

**边界条件**：$u(0, t) = u(l, t) = 0$。

**特征值**：$\lambda_n = \left(\frac{n\pi}{l}\right)^2$，$n = 1, 2, 3, \ldots$

**特征函数**：$X_n(x) = \sin\frac{n\pi x}{l}$

**解**：

$$u(x, t) = \sum_{n=1}^{\infty} \left(A_n \cos\frac{n\pi at}{l} + B_n \sin\frac{n\pi at}{l}\right) \sin\frac{n\pi x}{l}$$

其中 $A_n, B_n$ 由初始条件确定（Fourier 正弦级数）。

**推论 3.1**　分离变量法将 PDE 化为 ODE——降维思想。

**推论 3.2**　解是驻波的叠加——每个驻波有固定的频率和波形。

## 4. 能量方法

### 4.1 能量积分

**定义 4.1**：波动方程的**能量**：

$$E(t) = \frac{1}{2} \int (u_t^2 + a^2 u_x^2) \, dx$$

### 4.2 能量守恒

**定理 4.1**：对初值问题（无穷弦）或齐次边界条件的混合问题：

$$\frac{dE}{dt} = 0$$

即 $E(t) = E(0)$（能量守恒）。

**推论 4.1**　波动方程是保守系统——无耗散。

### 4.3 唯一性

**定理 4.2**：波动方程的混合问题的解唯一。

**证明提示**：设 $u_1, u_2$ 是两个解，$w = u_1 - u_2$ 满足齐次方程和零初始条件，由能量守恒得 $E_w(t) = 0$，故 $w \equiv 0$。

**推论 4.2**　能量方法是证明唯一性的有力工具——零能量意味着零解。

## 5. 高维波动方程

### 5.1 球对称解

三维波动方程在球对称情形下化为一维问题：

$$u_{tt} = a^2 \left(u_{rr} + \frac{2}{r} u_r\right)$$

令 $v = ru$，得 $v_{tt} = a^2 v_{rr}$——一维波动方程。

### 5.2 Kirchhoff 公式

**定理 5.1**：三维波动方程初值问题的解（Kirchhoff 公式）：

$$u(\mathbf{x}, t) = \frac{1}{4\pi a^2 t} \iint_{|\boldsymbol{\xi} - \mathbf{x}| = at} \psi(\boldsymbol{\xi}) \, dS + \frac{\partial}{\partial t}\left[\frac{1}{4\pi a^2 t} \iint_{|\boldsymbol{\xi} - \mathbf{x}| = at} \varphi(\boldsymbol{\xi}) \, dS\right]$$

**推论 5.1**　三维波动方程的解只依赖于球面上的初始数据——Huygens 原理。

### 5.3 Huygens 原理

**定义 5.1**：**Huygens 原理**：波前的每一点都是新的子波源，子波的包络形成新的波前。

- 奇数维（$n \geq 3$）：Huygens 原理成立（清晰的波前）
- 偶数维：Huygens 原理不成立（波后有"拖尾"）

**推论 5.2**　三维空间中声音有清晰的到达时刻，二维空间中声音有回响。

## 6. 非齐次方程

### 6.1 Duhamel 原理

**定理 6.1**：非齐次波动方程 $u_{tt} = a^2 u_{xx} + f(x, t)$ 的解：

$$u(x, t) = \int_0^t w(x, t; \tau) \, d\tau$$

其中 $w(x, t; \tau)$ 是以下问题的解：

$$w_{tt} = a^2 w_{xx}, \quad t > \tau$$
$$w(x, \tau; \tau) = 0, \quad w_t(x, \tau; \tau) = f(x, \tau)$$

**推论 6.1**　Duhamel 原理将非齐次问题转化为齐次问题——叠加持续作用的源。
