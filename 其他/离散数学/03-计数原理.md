# 计数原理

> 有多少种方法？——排列、组合与生成函数。

## 1. 基本计数原理

### 1.1 加法原理与乘法原理

**定理 1.1**（加法原理）：完成一件事有 $k$ 类方法，第 $i$ 类有 $n_i$ 种，则总方法数为 $n_1 + n_2 + \cdots + n_k$。

**定理 1.2**（乘法原理）：完成一件事需 $k$ 个步骤，第 $i$ 步有 $n_i$ 种选择，则总方法数为 $n_1 \cdot n_2 \cdots n_k$。

**推论 1.1**　加法原理适用于"或"（互斥选择），乘法原理适用于"且"（顺序步骤）。

### 1.2 补集原理

**定理 1.3**：$|A| = |U| - |A^c|$。

**推论 1.2**　直接计数困难时，计数补集再相减——**容斥原理**的特例。

## 2. 排列与组合

### 2.1 排列

**定义 2.1**：从 $n$ 个不同元素中取 $r$ 个**排列**（考虑顺序）：

$$P(n, r) = n(n-1)(n-2) \cdots (n-r+1) = \frac{n!}{(n-r)!}$$

**特例**：$P(n, n) = n!$（全排列）。

**推论 2.1**　$P(n, r) = n \cdot P(n-1, r-1)$——递推关系。

### 2.2 组合

**定义 2.2**：从 $n$ 个不同元素中取 $r$ 个**组合**（不考虑顺序）：

$$\binom{n}{r} = \frac{P(n, r)}{r!} = \frac{n!}{r!(n-r)!}$$

**定理 2.1**（对称性）：$\binom{n}{r} = \binom{n}{n-r}$。

**推论 2.2**　选择 $r$ 个元素 = 排除 $n - r$ 个元素。

### 2.3 组合数的性质

**定理 2.2**（Pascal 恒等式）：

$$\binom{n}{r} = \binom{n-1}{r-1} + \binom{n-1}{r}$$

**证明提示**：固定某个元素——包含它或不包含它。

**定理 2.3**（二项式定理）：

$$(x + y)^n = \sum_{k=0}^{n} \binom{n}{k} x^k y^{n-k}$$

**推论 2.3**　令 $x = y = 1$：$\sum_{k=0}^{n} \binom{n}{k} = 2^n$。

**推论 2.4**　令 $x = -1, y = 1$：$\sum_{k=0}^{n} (-1)^k \binom{n}{k} = 0$。

**定理 2.4**（Vandermonde 恒等式）：

$$\binom{m+n}{r} = \sum_{k=0}^{r} \binom{m}{k} \binom{n}{r-k}$$

**推论 2.5**　$\binom{n}{r}^2 = \sum_{k=0}^{r} \binom{n}{k} \binom{n}{r-k}$——组合数的卷积。

## 3. 多重集排列与组合

### 3.1 多重集排列

**定理 3.1**：$n$ 个元素中有 $n_1$ 个相同、$n_2$ 个相同、…、$n_k$ 个相同（$n_1 + \cdots + n_k = n$），则排列数为：

$$\frac{n!}{n_1! \, n_2! \cdots n_k!}$$

此即**多项式系数** $\binom{n}{n_1, n_2, \ldots, n_k}$。

**推论 3.1**　多项式系数是二项式系数的推广。

### 3.2 多重集组合

**定理 3.2**（插板法）：从 $k$ 类元素（每类无限）中取 $r$ 个的组合数：

$$\binom{r + k - 1}{k - 1} = \binom{r + k - 1}{r}$$

**证明提示**：将 $r$ 个球和 $k - 1$ 个隔板排列。

**推论 3.2**　方程 $x_1 + x_2 + \cdots + x_k = r$（$x_i \geq 0$）的整数解个数为 $\binom{r+k-1}{k-1}$。

## 4. 容斥原理

### 4.1 基本形式

**定理 4.1**（容斥原理）：

$$\left|\bigcup_{i=1}^{n} A_i\right| = \sum_{i} |A_i| - \sum_{i<j} |A_i \cap A_j| + \sum_{i<j<k} |A_i \cap A_j \cap A_k| - \cdots + (-1)^{n+1} |A_1 \cap \cdots \cap A_n|$$

**推论 4.1**　不在任何 $A_i$ 中的元素个数：

$$\left|\bigcap_{i=1}^{n} A_i^c\right| = |U| - \sum_i |A_i| + \sum_{i<j} |A_i \cap A_j| - \cdots$$

### 4.2 错排问题

**定义 4.2**：$n$ 个元素的**错排**是使得每个元素都不在原来位置上的排列。

**定理 4.2**：错排数 $D_n = n! \sum_{k=0}^{n} \frac{(-1)^k}{k!}$。

**证明提示**：设 $A_i$ = 第 $i$ 个元素在原位，用容斥原理求 $\left|\bigcap A_i^c\right|$。

**推论 4.2**　$D_n \approx n! / e$——错排概率趋近于 $1/e \approx 0.368$。

**推论 4.3**　$D_n = n D_{n-1} + (-1)^n$——递推关系。

## 5. 生成函数

### 5.1 普通生成函数

**定义 5.1**：序列 $\{a_n\}$ 的**普通生成函数**（OGF）：

$$A(x) = \sum_{n=0}^{\infty} a_n x^n$$

**常见生成函数**：

| 序列 $a_n$ | 生成函数 $A(x)$ |
|------------|----------------|
| $1$ | $\frac{1}{1-x}$ |
| $n$ | $\frac{x}{(1-x)^2}$ |
| $n^2$ | $\frac{x(1+x)}{(1-x)^3}$ |
| $\binom{n}{k}$（固定 $k$） | $\frac{x^k}{(1-x)^{k+1}}$ |
| $2^n$ | $\frac{1}{1-2x}$ |
| $C_n$（Catalan） | $\frac{1 - \sqrt{1-4x}}{2x}$ |

### 5.2 运算

**定理 5.1**：
- **移位**：$\{a_{n+1}\} \leftrightarrow \frac{A(x) - a_0}{x}$
- **卷积**：$\left\{\sum_{k=0}^{n} a_k b_{n-k}\right\} \leftrightarrow A(x) B(x)$
- **部分和**：$\left\{\sum_{k=0}^{n} a_k\right\} \leftrightarrow \frac{A(x)}{1-x}$

**推论 5.1**　卷积对应生成函数的乘法——这是生成函数强大的原因。

### 5.3 指数生成函数

**定义 5.2**：序列 $\{a_n\}$ 的**指数生成函数**（EGF）：

$$\hat{A}(x) = \sum_{n=0}^{\infty} \frac{a_n}{n!} x^n$$

**定理 5.2**：EGF 的乘法对应**二项卷积**：

$$\left\{\sum_{k=0}^{n} \binom{n}{k} a_k b_{n-k}\right\} \leftrightarrow \hat{A}(x) \hat{B}(x)$$

**推论 5.2**　排列计数用 EGF 更自然（$n!$ 在分母中）。

## 6. Catalan 数与经典序列

### 6.1 Catalan 数

**定义 6.1**：第 $n$ 个 Catalan 数 $C_n = \frac{1}{n+1} \binom{2n}{n}$。

**等价计数模型**（以下数量都等于 $C_n$）：
- $n$ 对括号的合法匹配数
- $n$ 个节点的不同二叉树数
- 从 $(0,0)$ 到 $(n,n)$ 不越过对角线的格路数
- 凸 $n+2$ 边形的三角剖分数
- $2n$ 个人排队买票（每人 5 元或 10 元，初始无零钱）的合法方式数

**定理 6.1**：$C_0 = 1$，$C_{n+1} = \sum_{k=0}^{n} C_k C_{n-k}$。

**推论 6.1**　Catalan 数的递推结构 = 分治结构——左子树 + 右子树。

### 6.2 Stirling 数

**第一类 Stirling 数** $\left[{n \atop k}\right]$：$n$ 个元素分成 $k$ 个轮换的方法数。

**第二类 Stirling 数** $\left\{{n \atop k}\right\}$：$n$ 个元素分成 $k$ 个非空子集的方法数。

**定理 6.2**：

$$x^n = \sum_{k=0}^{n} \left\{{n \atop k}\right\} x(x-1)(x-2) \cdots (x-k+1)$$

**推论 6.2**　Stirling 数是普通幂与下降幂之间的转换系数。

## 7. 应用

### 7.1 概率论
- 组合计数用于古典概型
- 生成函数用于分布的卷积

### 7.2 算法设计
- 动态规划的状态转移 = 递推关系
- 生成函数用于求解递推

### 7.3 组合优化
- 排列组合用于穷举搜索
- 容斥原理用于约束计数
