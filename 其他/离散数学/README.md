## 学习路线

```
集合论基础 → 图论基础 → 计数原理 → 递推关系
                                    ↓
                            数理逻辑 → 布尔代数与格
```

## 与其他分支的联系

- **代数学**：格与布尔代数是代数结构的特例
- **概率论**：组合计数是古典概型的基础
- **计算机科学**：图论、逻辑、布尔代数是核心工具
