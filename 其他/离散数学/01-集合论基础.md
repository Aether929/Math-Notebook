# 集合论基础

> 数学的语言——集合、关系、函数的严格框架。

## 1. 集合的基本概念

### 1.1 集合与元素

**定义 1.1**　**集合**是确定的、互异的对象的全体。对象称为集合的**元素**。

记号：$a \in A$（$a$ 属于 $A$），$a \notin A$（$a$ 不属于 $A$）。

**集合的表示**：
- **列举法**：$A = \{a_1, a_2, \ldots\}$
- **描述法**：$A = \{x : P(x)\}$（满足性质 $P$ 的全体 $x$）

### 1.2 集合间的关系

| 关系 | 定义 | 记号 |
|------|------|------|
| 子集 | $\forall x (x \in A \Rightarrow x \in B)$ | $A \subseteq B$ |
| 真子集 | $A \subseteq B$ 且 $A \neq B$ | $A \subsetneq B$ |
| 相等 | $A \subseteq B$ 且 $B \subseteq A$ | $A = B$ |

**定理 1.1**（外延公理）：$A = B \iff A \subseteq B \land B \subseteq A$。

**推论 1.1**　证明集合相等的标准方法：双向包含。

### 1.3 特殊集合

- **空集** $\varnothing$：不含任何元素的集合
- **全集** $U$：讨论范围内的全体元素
- **幂集** $\mathcal{P}(A)$：$A$ 的所有子集构成的集合

**定理 1.2**：$|A| = n \Rightarrow |\mathcal{P}(A)| = 2^n$。

**证明提示**：每个子集对应一个长度为 $n$ 的 0-1 串（每个元素选或不选）。

**推论 1.2**　$|\mathcal{P}(A)| > |A|$——Cantor 定理的有限版本。

## 2. 集合运算

### 2.1 基本运算

| 运算 | 定义 | 记号 |
|------|------|------|
| 并 | $\{x : x \in A \lor x \in B\}$ | $A \cup B$ |
| 交 | $\{x : x \in A \land x \in B\}$ | $A \cap B$ |
| 差 | $\{x : x \in A \land x \notin B\}$ | $A \setminus B$ |
| 补 | $\{x : x \in U \land x \notin A\}$ | $A^c$ 或 $\overline{A}$ |
| 对称差 | $(A \setminus B) \cup (B \setminus A)$ | $A \triangle B$ |

### 2.2 运算律

**定理 2.1**（De Morgan 律）：

$$(A \cup B)^c = A^c \cap B^c, \quad (A \cap B)^c = A^c \cup B^c$$

推广到任意族：

$$\left(\bigcup_{i \in I} A_i\right)^c = \bigcap_{i \in I} A_i^c, \quad \left(\bigcap_{i \in I} A_i\right)^c = \bigcup_{i \in I} A_i^c$$

**定理 2.2**（分配律）：

$$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$$
$$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$$

**推论 2.1**　集合运算构成一个布尔代数（见 [06-布尔代数与格](06-布尔代数与格.md)）。

### 2.3 Cartesian 积

**定义 2.1**：$A \times B = \{(a, b) : a \in A, b \in B\}$。

**定理 2.3**：$|A \times B| = |A| \cdot |B|$。

**推论 2.2**　$|A^n| = |A|^n$——$n$ 元组的个数。

## 3. 关系

### 3.1 二元关系

**定义 3.1**：$A$ 到 $B$ 的**二元关系**是 $A \times B$ 的子集。$A$ 到自身的关系简称 $A$ 上的关系。

记号：$a R b$ 表示 $(a, b) \in R$。

### 3.2 等价关系

**定义 3.2**：$A$ 上的关系 $R$ 是**等价关系**，若满足：
1. **自反性**：$a R a$
2. **对称性**：$a R b \Rightarrow b R a$
3. **传递性**：$a R b \land b R c \Rightarrow a R c$

**等价类**：$[a] = \{x \in A : x R a\}$

**商集**：$A / R = \{[a] : a \in A\}$（全体等价类的集合）

**定理 3.1**：等价关系将集合划分为互不相交的等价类（**划分**）。

反之，任意划分确定一个等价关系。

**推论 3.1**　等价关系与划分一一对应——这是"商"操作的集合论基础。

### 3.3 序关系

**定义 3.3**：$A$ 上的关系 $\leq$ 是**偏序**，若满足：
1. **自反性**：$a \leq a$
2. **反对称性**：$a \leq b \land b \leq a \Rightarrow a = b$
3. **传递性**：$a \leq b \land b \leq c \Rightarrow a \leq c$

**全序**：偏序 + 任意两个元素可比（$\forall a, b: a \leq b \lor b \leq a$）。

**良序**：全序 + 每个非空子集有最小元。

**推论 3.2**　$\mathbb{N}$ 是良序集，$\mathbb{Z}$ 和 $\mathbb{R}$ 不是。

## 4. 函数

### 4.1 定义

**定义 4.1**：$f: A \to B$ 是**函数**（映射），若 $\forall a \in A, \exists! b \in B$ 使得 $(a, b) \in f$。

记号：$f(a) = b$ 或 $a \mapsto b$。

### 4.2 函数的类型

| 类型 | 条件 |
|------|------|
| **单射**（一对一） | $f(a_1) = f(a_2) \Rightarrow a_1 = a_2$ |
| **满射**（到上） | $\forall b \in B, \exists a \in A: f(a) = b$ |
| **双射**（一一对应） | 单射 + 满射 |

**定理 4.1**：$f: A \to B$ 是双射 $\iff$ 存在逆函数 $f^{-1}: B \to A$。

**推论 4.1**　双射建立了两个集合间元素的完美配对。

### 4.3 复合与逆

**复合**：$(g \circ f)(a) = g(f(a))$。

**定理 4.2**：
- $f, g$ 单射 $\Rightarrow$ $g \circ f$ 单射
- $f, g$ 满射 $\Rightarrow$ $g \circ f$ 满射
- $f, g$ 双射 $\Rightarrow$ $g \circ f$ 双射，且 $(g \circ f)^{-1} = f^{-1} \circ g^{-1}$

**推论 4.2**　复合运算满足结合律，双射全体关于复合构成群。

## 5. 基数

### 5.1 等势

**定义 5.1**：集合 $A$ 与 $B$ **等势**（$|A| = |B|$），若存在双射 $f: A \to B$。

**例子**：
- $|\mathbb{N}| = |\mathbb{Z}| = |\mathbb{Q}| = \aleph_0$（可数无穷）
- $|\mathbb{R}| = 2^{\aleph_0} = \mathfrak{c}$（连续统）

### 5.2 Cantor 定理

**定理 5.1**（Cantor）：$|A| < |\mathcal{P}(A)|$。

**证明提示**：对角线论证——假设满射 $f: A \to \mathcal{P}(A)$，取 $B = \{a \in A : a \notin f(a)\}$，导出矛盾。

**推论 5.1**　不存在最大的基数——无穷有无穷多个层次。

### 5.3 可数与不可数

**定义 5.2**：$A$ **可数**，若 $|A| \leq \aleph_0$（有限或与 $\mathbb{N}$ 等势）。

**定理 5.2**：
- $\mathbb{Q}$ 可数
- $\mathbb{R}$ 不可数
- 可数个可数集的并仍可数

**推论 5.2**　无理数比有理数"多得多"——$|\mathbb{R} \setminus \mathbb{Q}| = \mathfrak{c}$。

## 6. 应用

### 6.1 在代数中

- 群、环、域的定义依赖集合与运算
- 商群 = 等价类的集合（见 [代数学/抽象代数/](../../代数学/抽象代数/)）

### 6.2 在分析中

- $\sigma$-代数 = 对可数并、交封闭的集合族
- 测度论建立在集合论基础之上

### 6.3 在计算机科学中

- 关系数据库 = 关系的实现
- 等价关系用于聚类、分类
