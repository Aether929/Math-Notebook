# 常微分方程数值解

> 从分析解到数值解——Euler、Runge-Kutta 与多步法。

## 1. 初值问题

### 1.1 问题

$$y' = f(t, y), \quad y(t_0) = y_0$$

**目标**：在 $t_0, t_1, t_2, \ldots$ 处计算 $y$ 的近似值 $y_0, y_1, y_2, \ldots$

**步长**：$h = t_{n+1} - t_n$（可变或固定）。

### 1.2 基本思想

用差商近似导数：

$$y'(t_n) \approx \frac{y(t_{n+1}) - y(t_n)}{h}$$

代入方程得递推公式。

---

## 2. Euler 方法

### 2.1 显式 Euler

$$y_{n+1} = y_n + h f(t_n, y_n)$$

**局部截断误差**：$O(h^2)$

**全局截断误差**：$O(h)$（一阶方法）

**推论 2.1**　显式 Euler 最简单但精度最低——一阶方法。

### 2.2 隐式 Euler

$$y_{n+1} = y_n + h f(t_{n+1}, y_{n+1})$$

**特点**：需要解方程求 $y_{n+1}$——但对刚性问题更稳定。

**推论 2.2**　隐式方法每步需要解非线性方程——计算量大但稳定性好。

### 2.3 梯形方法

$$y_{n+1} = y_n + \frac{h}{2}[f(t_n, y_n) + f(t_{n+1}, y_{n+1})]$$

**局部截断误差**：$O(h^3)$

**全局截断误差**：$O(h^2)$（二阶方法）

**推论 2.3**　梯形方法是隐式的——用预测-校正法可化为显式。

---

## 3. Runge-Kutta 方法

### 3.1 基本思想

用多个中间点的 $f$ 值组合，提高精度阶。

### 3.2 经典四阶 Runge-Kutta (RK4)

$$k_1 = f(t_n, y_n)$$
$$k_2 = f(t_n + h/2, y_n + hk_1/2)$$
$$k_3 = f(t_n + h/2, y_n + hk_2/2)$$
$$k_4 = f(t_n + h, y_n + hk_3)$$

$$y_{n+1} = y_n + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)$$

**局部截断误差**：$O(h^5)$

**全局截断误差**：$O(h^4)$（四阶方法）

**推论 3.1**　RK4 用 4 次函数求值获得四阶精度——效率很高。

### 3.3 自适应步长

**嵌入 Runge-Kutta 对**：同时计算两个不同阶的近似，用差估计误差。

**Dormand-Prince (RK45)**：嵌入四阶和五阶方法，自适应控制步长。

**推论 3.2**　自适应步长在解变化快时用小步长，变化慢时用大步长——效率与精度的平衡。

---

## 4. 线性多步法

### 4.1 一般形式

$$\sum_{j=0}^{k} \alpha_j y_{n+j} = h \sum_{j=0}^{k} \beta_j f_{n+j}$$

其中 $f_n = f(t_n, y_n)$。

### 4.2 Adams 方法

**Adams-Bashforth**（显式）：

- 二步：$y_{n+2} = y_{n+1} + \frac{h}{2}(3f_{n+1} - f_n)$
- 三步：$y_{n+3} = y_{n+2} + \frac{h}{12}(23f_{n+2} - 16f_{n+1} + 5f_n)$

**Adams-Moulton**（隐式）：

- 二步：$y_{n+2} = y_{n+1} + \frac{h}{12}(5f_{n+2} + 8f_{n+1} - f_n)$

**推论 4.1**　多步法利用历史信息——每步只需一次新函数求值。

### 4.3 预测-校正

**思想**：用显式方法预测，用隐式方法校正。

**Adams-Bashforth-Moulton (ABM)**：
1. 预测：$\tilde{y}_{n+1}$（Adams-Bashforth）
2. 校正：$y_{n+1}$（Adams-Moulton，用 $\tilde{f}_{n+1} = f(t_{n+1}, \tilde{y}_{n+1})$）

**推论 4.2**　预测-校正结合了显式的简单和隐式的稳定。

---

## 5. 稳定性分析

### 5.1 测试方程

$$y' = \lambda y, \quad \text{Re}(\lambda) < 0$$

精确解：$y(t) = y_0 e^{\lambda t} \to 0$。

### 5.2 绝对稳定性

**定义 5.1**：数值方法对测试方程是**绝对稳定的**，若 $y_n \to 0$。

**稳定区域**：$z = h\lambda$ 的集合使得方法绝对稳定。

| 方法 | 稳定区域 |
|------|----------|
| 显式 Euler | $\|1 + h\lambda\| < 1$（圆盘） |
| 隐式 Euler | $\|1 - h\lambda\| > 1$（左半平面外） |
| RK4 | 复平面上的区域 |

**推论 5.1**　隐式方法的稳定区域通常比显式方法大——适合刚性问题。

### 5.3 刚性问题

**定义 5.2**：**刚性问题**的特征：解的不同分量衰减速率相差悬殊。

**刚性比**：$\max |\text{Re}(\lambda_i)| / \min |\text{Re}(\lambda_i)|$。

**推论 5.2**　刚性问题需要隐式方法——显式方法的步长受快速衰减分量限制。

---

## 6. 收敛性

### 6.1 相容性

**定义 6.1**：方法是**相容的**，若局部截断误差 $\to 0$（$h \to 0$）。

等价于：对常微分方程 $y' = 1$，方法精确成立。

### 6.2 收敛性定理

**定理 6.1**（Dahlquist）：多步法收敛 $\iff$ 相容 + 零稳定。

**零稳定**：初始误差不随步数增长。

**推论 6.1**　相容性 + 稳定性 = 收敛性——数值方法的基本定理。

### 6.3 阶与精度

**定理 6.2**：$p$ 阶方法的全局误差 $\|y(t_n) - y_n\| = O(h^p)$。

**推论 6.2**　提高精度的方法：减小步长（$h$）或提高方法阶数（$p$）。

---

## 7. 二阶方程的特殊方法

### 7.1 辛方法

**问题**：$y'' = f(t, y)$（力学系统）。

**Störmer-Verlet 方法**：

$$y_{n+1} = 2y_n - y_{n-1} + h^2 f(t_n, y_n)$$

**性质**：辛结构保持——长期能量守恒。

**推论 7.1**　辛方法适合力学系统——长时间模拟能量不漂移。

### 7.2 指数方法

**问题**：$y' = Ay + g(t)$（线性部分 + 非线性部分）。

**指数 Euler**：$y_{n+1} = e^{hA} y_n + \int_0^h e^{(h-s)A} g(t_n + s) \, ds$

**推论 7.2**　指数方法对线性部分精确——适合半线性问题。
