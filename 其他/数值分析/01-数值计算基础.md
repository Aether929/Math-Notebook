# 数值计算基础

> 从精确到近似——误差、稳定性与收敛性。

## 1. 误差理论

### 1.1 误差的来源

| 类型 | 来源 | 说明 |
|------|------|------|
| **模型误差** | 数学模型与实际的差异 | 简化假设导致 |
| **观测误差** | 测量数据的不精确 | 仪器精度限制 |
| **截断误差** | 无穷过程用有限过程近似 | Taylor 展开截断 |
| **舍入误差** | 有限精度算术 | 浮点数表示 |

**推论 1.1**　数值计算必须考虑误差——近似是不可避免的。

### 1.2 绝对误差与相对误差

**定义 1.1**：
- **绝对误差**：$\varepsilon(x) = |x - \tilde{x}|$
- **相对误差**：$\varepsilon_r(x) = \frac{|x - \tilde{x}|}{|x|}$（$x \neq 0$）
- **有效数字**：相对误差 $\leq 5 \times 10^{-k}$ 称有 $k$ 位有效数字

**推论 1.2**　相对误差比绝对误差更能反映近似质量——与量纲无关。

### 1.3 运算误差

**定理 1.1**（误差传播）：

$$\varepsilon(x \pm y) \leq \varepsilon(x) + \varepsilon(y)$$
$$\varepsilon(xy) \leq |y| \varepsilon(x) + |x| \varepsilon(y)$$
$$\varepsilon_r(xy) \leq \varepsilon_r(x) + \varepsilon_r(y)$$
$$\varepsilon_r(x/y) \leq \varepsilon_r(x) + \varepsilon_r(y) \quad (|y| \text{不太小})$$

**推论 1.3**　乘除法的相对误差近似相加——误差传播的基本规律。

## 2. 浮点数

### 2.1 IEEE 754 标准

**定义 2.1**：浮点数表示 $x = \pm m \times \beta^e$，其中：
- $m$：尾数（mantissa），$1 \leq m < \beta$
- $\beta$：基数（base），通常为 2
- $e$：指数（exponent）

**单精度**：32 位（1 + 8 + 23），约 7 位有效数字。

**双精度**：64 位（1 + 11 + 52），约 16 位有效数字。

### 2.2 机器精度

**定义 2.2**：**机器精度** $\varepsilon_{\text{mach}}$ 是满足 $\text{fl}(1 + \varepsilon) > 1$ 的最小正数。

- 单精度：$\varepsilon_{\text{mach}} \approx 1.19 \times 10^{-7}$
- 双精度：$\varepsilon_{\text{mach}} \approx 2.22 \times 10^{-16}$

**推论 2.1**　机器精度是浮点运算误差的基本单位。

### 2.3 舍入误差

**定理 2.1**：对基本运算 $\circ \in \{+, -, \times, /\}$：

$$\text{fl}(x \circ y) = (x \circ y)(1 + \delta), \quad |\delta| \leq \varepsilon_{\text{mach}}$$

**推论 2.2**　每次浮点运算引入最多 $\varepsilon_{\text{mach}}$ 的相对误差。

## 3. 数值稳定性

### 3.1 病态与良态

**定义 3.1**：问题的**条件数**衡量输入扰动对输出的影响：

$$\text{cond}(f, x) = \lim_{\varepsilon \to 0} \sup_{|\delta x| \leq \varepsilon} \frac{|f(x + \delta x) - f(x)|}{|f(x)|} / \frac{|\delta x|}{|x|}$$

**病态问题**：条件数大——小扰动导致大变化。

**良态问题**：条件数小——输入扰动被控制。

**推论 3.1**　条件数是问题本身的属性——与算法无关。

### 3.2 前向误差与后向误差

**定义 3.2**：
- **前向误差**：$|\tilde{y} - y|$（近似解与精确解的差异）
- **后向误差**：最小的 $|\delta x|$ 使得 $f(x + \delta x) = \tilde{y}$

**定理 3.1**：前向误差 $\leq$ 条件数 $\times$ 后向误差。

**推论 3.2**　后向误差分析更实用——只需验证算法对"邻近输入"的精确性。

### 3.3 数值稳定性

**定义 3.3**：算法是**数值稳定的**，若它对所有良态问题都给出小的前向误差。

**等价刻画**：算法产生的后向误差远小于输入的不确定性。

**推论 3.3**　稳定性是算法的属性——好的算法不会放大数据中的误差。

## 4. 条件数的例子

### 4.1 线性方程组

$A \mathbf{x} = \mathbf{b}$ 的条件数：

$$\text{cond}(A) = \|A\| \cdot \|A^{-1}\|$$

**定理 4.1**：

$$\frac{\|\delta \mathbf{x}\|}{\|\mathbf{x}\|} \leq \text{cond}(A) \frac{\|\delta \mathbf{b}\|}{\|\mathbf{b}\|}$$

**推论 4.1**　条件数大的矩阵（病态矩阵）使线性方程组的求解不稳定。

### 4.2 常见病态问题

| 问题 | 条件数大时的表现 |
|------|-----------------|
| Hilbert 矩阵 | 随阶数指数增长 |
| 多项式求根 | 根对系数敏感 |
| 数值积分 | 被积函数振荡 |
| 微分方程数值解 | 刚性问题 |

**推论 4.2**　病态问题需要特殊算法或正则化——不能简单提高精度。

## 5. 算法设计原则

### 5.1 避免相近数相减

**问题**：$a \approx b$ 时，$a - b$ 的相对误差可能很大。

**解决**：用等价变换避免大数相消。

**例**：$\sqrt{x + \varepsilon} - \sqrt{x} = \frac{\varepsilon}{\sqrt{x + \varepsilon} + \sqrt{x}}$。

**推论 5.1**　大数相消是数值计算中最常见的精度损失来源。

### 5.2 避免除以小数

**问题**：除以小数放大大误差。

**解决**：重新组织计算，避免小分母。

### 5.3 用稳定算法

**例子**：
- 求方差：用 $s^2 = \frac{1}{n-1}\left[\sum x_i^2 - \frac{(\sum x_i)^2}{n}\right]$ 可能大数相消，改用递推公式。

**推论 5.2**　数学上等价的公式，数值上可能差异巨大。

### 5.4 控制累加误差

**Kahan 求和**：用补偿变量跟踪舍入误差，使 $n$ 项求和的误差从 $O(n\varepsilon)$ 降为 $O(\varepsilon)$。

## 6. 迭代法基础

### 6.1 不动点迭代

**定义 6.1**：$x_{n+1} = g(x_n)$ 的不动点满足 $x^* = g(x^*)$。

**定理 6.1**（压缩映射）：若 $|g'(x^*)| < 1$，则迭代局部收敛。

**收敛阶**：
- $|g'(x^*)| \neq 0$：线性收敛，速率 $|g'(x^*)|$
- $g'(x^*) = 0$：超线性/二次收敛

**推论 6.1**　收敛速度取决于不动点处的导数——越小越快。

### 6.2 停止准则

| 准则 | 公式 | 说明 |
|------|------|------|
| 残差 | $\|f(x_n)\| < \varepsilon$ | 检验方程满足程度 |
| 步长 | $\|x_{n+1} - x_n\| < \varepsilon$ | 检验迭代稳定性 |
| 相对步长 | $\|x_{n+1} - x_n\|/\|x_n\| < \varepsilon$ | 量纲无关 |

**推论 6.2**　停止准则应结合问题背景选择——没有万能准则。
