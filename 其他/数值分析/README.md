```
数值计算基础 → 插值与逼近 → 数值积分

            常微分方程数值解 → 线性方程组数值解
```

## 与其他分支的联系

- **常微分方程**：ODE 的数值解法
- **偏微分方程**：有限差分/有限元方法
- **线性代数**：矩阵分解与迭代法
- **概率论**：Monte Carlo 方法
