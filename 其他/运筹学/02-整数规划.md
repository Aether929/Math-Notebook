# 整数规划

> 变量取整数——离散决策的优化问题。

## 1. 基本概念

### 1.1 问题形式

**定义 1.1**　**整数规划**（IP）：

$$\min \mathbf{c}^T \mathbf{x} \quad \text{s.t.} \quad A\mathbf{x} = \mathbf{b}, \, \mathbf{x} \geq \mathbf{0}, \, \mathbf{x} \in \mathbb{Z}^n$$

**特殊情况**：
- **纯整数规划**：所有变量都是整数
- **混合整数规划**（MIP）：部分变量整数，部分连续
- **0-1 规划**：变量只取 0 或 1

**推论 1.1**　整数规划比线性规划难得多——它是 NP-hard 的。

### 1.2 应用场景

- 设施选址：建或不建（0-1 变量）
- 排班问题：工人分配到班次
- 背包问题：物品选或不选
- 旅行商问题：访问城市的顺序

---

## 2. 求解方法

### 2.1 分支定界法

**算法 2.1**（分支定界）：
1. 求解 LP 松弛（去掉整数约束）
2. 若解是整数，完成
3. 否则，选择一个非整数变量 $x_i$，分支为 $x_i \leq \lfloor x_i^* \rfloor$ 和 $x_i \geq \lceil x_i^* \rceil$
4. 对每个分支递归求解
5. 用上界和下界剪枝

**定理 2.1**：分支定界法在有限步内找到最优解。

**推论 2.1**　分支定界法是最常用的 IP 求解方法——实际中通常很高效。

### 2.2 割平面法

**Gomory 割**：添加线性约束，切掉非整数解但保留所有整数解。

$$\sum_i (a_i - \lfloor a_i \rfloor) x_i \geq b - \lfloor b \rfloor$$

**推论 2.2**　割平面法与分支定界结合（分支切割）是现代 IP 求解器的核心。

### 2.3 启发式方法

- **贪心算法**：逐步做出局部最优选择
- **局部搜索**：在当前解附近搜索更好解
- **遗传算法**：模拟生物进化
- **模拟退火**：模拟金属冷却过程

## 3. 0-1 规划

### 3.1 问题形式

**定义 3.1**　**0-1 规划**：

$$\min \mathbf{c}^T \mathbf{x} \quad \text{s.t.} \quad A\mathbf{x} \leq \mathbf{b}, \, \mathbf{x} \in \{0, 1\}^n$$

**推论 3.1**　0-1 规划可以建模"是否"决策——是整数规划中最常见的类型。

### 3.2 经典问题

**背包问题**：

$$\max \sum_{i=1}^n v_i x_i \quad \text{s.t.} \quad \sum_{i=1}^n w_i x_i \leq W, \, x_i \in \{0, 1\}$$

**旅行商问题**（TSP）：访问所有城市恰好一次并回到起点，求最短路径。

**集合覆盖**：选择最少的集合覆盖所有元素。

---

## 4. 线性松弛

### 4.1 松弛与界

**定义 4.1**　**LP 松弛**：去掉整数约束，得到线性规划。

**定理 4.1**：LP 松弛的最优值是 IP 最优值的下界（最小化问题）。

**推论 4.1**　松弛的质量决定了分支定界的效率——松弛越紧，搜索越快。

### 4.2 对偶界

**定理 4.2**（对偶界）：对偶问题的可行解提供 IP 最优值的上界。
