# 动态规划

> 将复杂问题分解为子问题——多阶段决策的优化方法。

## 1. 基本概念

### 1.1 最优性原理

**定义 1.1**　**动态规划**（DP）：将问题分解为相互重叠的子问题，通过求解子问题得到原问题的解。

**定理 1.1**（最优性原理）：最优策略的子策略也是最优的。

**推论 1.1**　最优性原理是动态规划的理论基础——它保证了"局部最优导致全局最优"。

### 1.2 问题特征

使用动态规划需要满足：
1. **最优子结构**：问题的最优解包含子问题的最优解
2. **重叠子问题**：子问题被重复计算
3. **无后效性**：当前状态只与之前状态有关，与路径无关

## 2. 基本方程

### 2.1 Bellman 方程

**定义 2.1**　**Bellman 方程**：

$$V(s) = \max_a \{r(s, a) + \gamma V(s')\}$$

其中 $V(s)$ 是状态 $s$ 的价值函数，$r(s, a)$ 是即时奖励，$\gamma$ 是折扣因子。

**推论 2.1**　Bellman 方程将多阶段决策问题转化为递推关系——这是动态规划的核心。

### 2.2 前向与后向

**后向递推**（逆序）：
$$V_t(s_t) = \max_{a_t} \{r_t(s_t, a_t) + V_{t+1}(s_{t+1})\}$$

**前向递推**（顺序）：
$$V_t(s_t) = \max_{a_{t-1}} \{V_{t-1}(s_{t-1}) + r_{t-1}(s_{t-1}, a_{t-1})\}$$

## 3. 经典问题

### 3.1 背包问题

**0-1 背包**：

$$f(i, w) = \max \{f(i-1, w), \, f(i-1, w - w_i) + v_i\}$$

**推论 3.1**　背包问题是动态规划的典型应用——从指数时间降到多项式时间。

### 3.2 最短路问题

$$d(u, v) = \min_{w} \{d(u, w) + d(w, v)\}$$

**Floyd-Warshall 算法**：$O(|V|^3)$ 所有点对最短路。

### 3.3 序列比对

**编辑距离**：

$$d(i, j) = \min \begin{cases} d(i-1, j) + 1 \\ d(i, j-1) + 1 \\ d(i-1, j-1) + [s_i \neq t_j] \end{cases}$$

---

## 4. 随机动态规划

### 4.1 马尔可夫决策过程

**定义 4.1**　**马尔可夫决策过程**（MDP）：

$$V(s) = \max_a \left\{r(s, a) + \gamma \sum_{s'} P(s'|s, a) V(s') \right\}$$

**推论 4.1**　MDP 是随机动态规划的标准框架——强化学习的基础。

### 4.2 值迭代与策略迭代

**值迭代**：
$$V_{k+1}(s) = \max_a \left\{r(s, a) + \gamma \sum_{s'} P(s'|s, a) V_k(s') \right\}$$

**策略迭代**：交替进行策略评估和策略改进。
