# 网络优化

> 图与网络上的优化问题——从最短路到最大流。

## 1. 基本概念

### 1.1 网络模型

**定义 1.1**　**网络**是一个有向图 $G = (V, E)$，每条边 $(i, j) \in E$ 有权重 $c_{ij}$、容量 $u_{ij}$、下界 $l_{ij}$。

**推论 1.1**　许多实际问题可以建模为网络优化问题——运输、通信、物流。

### 1.2 问题类型

| 问题 | 目标 |
|------|------|
| 最短路 | 找两点间的最短路径 |
| 最大流 | 从源到汇的最大流量 |
| 最小费用流 | 满足供需的最小成本 |
| 最小生成树 | 连接所有点的最小权重树 |

---

## 2. 最短路问题

### 2.1 Dijkstra 算法

**算法 2.1**（Dijkstra）：
1. 初始化：$d(s) = 0$，$d(v) = \infty$（$v \neq s$）
2. 选择未访问的最小 $d(u)$
3. 对每条边 $(u, v)$：$d(v) = \min(d(v), d(u) + c_{uv})$
4. 标记 $u$ 为已访问，回到步骤 2

**定理 2.1**：Dijkstra 算法在非负权重下正确找到最短路。

**复杂度**：$O(|V|^2)$ 或 $O((|V| + |E|) \log |V|)$（优先队列）。

### 2.2 Bellman-Ford 算法

**算法 2.2**（Bellman-Ford）：
1. 初始化：$d(s) = 0$，$d(v) = \infty$（$v \neq s$）
2. 对每条边 $(u, v)$：$d(v) = \min(d(v), d(u) + c_{uv})$
3. 重复步骤 2 共 $|V| - 1$ 次

**定理 2.2**：Bellman-Ford 算法可以处理负权重边，并检测负环。

**推论 2.1**　Bellman-Ford 比 Dijkstra 慢但更通用——可以处理负权重。

## 3. 最大流问题

### 3.1 问题定义

**定义 3.1**　**最大流问题**：

$$\max f \quad \text{s.t.} \quad \sum_{j} f_{ij} - \sum_{j} f_{ji} = \begin{cases} f & i = s \\ 0 & i \neq s, t \\ -f & i = t \end{cases}$$

$$0 \leq f_{ij} \leq u_{ij}$$

### 3.2 最小割定理

**定理 3.1**（最大流-最小割）：最大流的值 = 最小割的容量。

$$\max \text{flow} = \min \text{cut}$$

**推论 3.1**　这是图论中最优美的定理之一——流量的上界由"瓶颈"决定。

### 3.3 Ford-Fulkerson 算法

**算法 3.1**（Ford-Fulkerson）：
1. 初始化：$f_{ij} = 0$
2. 在残余网络中找增广路
3. 沿增广路增加流量
4. 重复步骤 2-3 直到无增广路

**推论 3.2**　每次增广至少增加 1 单位流量——算法在整数容量下有限步终止。

## 4. 最小费用流

### 4.1 问题定义

**定义 4.1**　**最小费用流**：

$$\min \sum_{(i,j)} c_{ij} f_{ij} \quad \text{s.t.} \quad \text{流量平衡}, \, l_{ij} \leq f_{ij} \leq u_{ij}$$

**推论 4.1**　最小费用流是网络优化的一般形式——最短路和最大流都是特殊情况。

### 4.2 求解方法

- **网络单纯形法**：利用网络结构的特殊单纯形法
- **原始-对偶算法**：交替更新原始和对偶变量
- **松弛算法**：逐步满足流量平衡约束
