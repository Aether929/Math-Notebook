## 核心思想

运筹学用数学模型帮助做出最优决策：
- **建模**：将实际问题转化为数学问题
- **求解**：用算法找到最优解
- **分析**：理解解的性质和敏感性

## 与其他分支的关系

- **线性代数**：矩阵运算、线性方程组
- **概率论**：随机模型、马尔可夫过程
- **图论**：网络模型、最短路问题
- **微积分**：连续优化、最优控制
