# 数学学习笔记

> 一套系统化的数学学习笔记，涵盖从基础到进阶的核心数学分支。

## 目录结构

```
├── 分析学/
│   ├── 数学分析/          # 极限、连续、微分、积分
│   ├── 实变函数/          # 测度论、Lebesgue 积分
│   ├── 泛函分析/          # 赋范空间、算子理论
│   └── 复变函数/          # 解析函数、留数、共形映射
├── 代数学/
│   ├── 高等代数/          # 多项式理论、行列式、线性方程组、矩阵、线性空间、线性变换、欧氏空间
│   ├── 抽象代数/          # 群论、正规子群与商群、Sylow 定理、环论、UFD/PID、域论与 Galois 理论
│   └── 线性代数/          # 向量空间、特征值、Jordan 标准形、内积空间、正交化、二次型
├── 几何与拓扑/
│   ├── 解析几何/          # 向量、平面、二次曲面
│   ├── 微分几何/          # 曲线、曲面、流形
│   └── 拓扑学/            # 点集拓扑、代数拓扑、曲面分类
├── 概率统计/
│   ├── 概率论/            # 随机变量、分布、大数定律、中心极限定理
│   ├── 数理统计/          # 估计、假设检验、回归、方差分析
│   └── 随机过程/          # Poisson 过程、Markov 链、Brown 运动、鞅论
├── 其他/
│   ├── 离散数学/          # 图论、组合、数理逻辑、布尔代数
│   ├── 常微分方程/        # 一阶方程、高阶线性方程、稳定性理论
│   ├── 偏微分方程/        # 波动方程、热传导方程、位势方程
│   ├── 数值分析/          # 插值、数值积分、ODE/PDE 数值解
│   ├── 运筹学/            # 线性规划、整数规划、网络优化、动态规划、博弈论
│   └── 最优化理论/        # 无约束优化、约束优化、凸优化、非线性规划、组合优化
├── 计算机科学/
│   ├── 数据结构/          # 线性表、栈与队列、串与数组、树与二叉树、图、查找、排序
│   └── 机器学习/          # 监督学习、无监督学习、模型评估
└── 数学家/               # 数学家传记、故事与主要贡献
```
