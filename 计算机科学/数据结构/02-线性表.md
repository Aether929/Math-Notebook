# 线性表

> 最基础的线性结构——顺序存储与链式存储的对偶。

## 1. 基本概念

### 1.1 线性表的定义

**定义 1.1**　**线性表**是由 $n$（$n \geq 0$）个**同类型**数据元素构成的有限序列：

$$L = (a_1, a_2, \ldots, a_n)$$

其中 $n$ 为**表长**，$n = 0$ 时为空表。$a_1$ 为表头元素，$a_n$ 为表尾元素。

**性质 1.1**：除 $a_1$ 外每个元素有唯一前驱；除 $a_n$ 外每个元素有唯一后继。

**推论 1.1**　线性表是元素间构成"一对一"关系的线性结构。

### 1.2 抽象数据类型

**定义 1.2**　线性表的 ADT 基本操作：

| 操作 | 语义 |
|------|------|
| `InitList(L)` | 初始化空表 |
| `ListLength(L)` | 求表长 |
| `GetElem(L, i)` | 取第 $i$ 个元素 |
| `LocateElem(L, e)` | 按值查找 |
| `ListInsert(L, i, e)` | 在第 $i$ 处插入 |
| `ListDelete(L, i)` | 删除第 $i$ 个元素 |

**注意**　操作集定义了接口，具体实现取决于存储结构——顺序或链式。

## 2. 顺序存储结构

### 2.1 顺序表

**定义 2.1**　**顺序表**用一组地址连续的存储单元依次存放线性表元素，逻辑相邻的元素物理位置也相邻。

设首地址为 $\text{LOC}(a_1)$，每个元素占 $c$ 个单元，则：

$$\text{LOC}(a_i) = \text{LOC}(a_1) + (i - 1) \times c$$

**定理 2.1**：顺序表按下标访问任意元素的时间为 $O(1)$（**随机存取**）。

**推论 2.1**　随机存取是顺序存储的核心优势。

### 2.2 插入与删除

**算法 2.1**（插入）：在第 $i$ 个位置插入元素 $e$，需将第 $i$ 至第 $n$ 个元素后移一格。

```
insertList(L, i, e):                     // 顺序表，L.length 为表长
    if i < 1 or i > L.length + 1: return ERROR
    if L.length == MAXSIZE:       return OVERFLOW
    for k from L.length down to i:
        L.data[k] = L.data[k-1]          // 从后往前，逐位后移
    L.data[i-1] = e
    L.length++
    return OK
```

- 移动次数：$n - i + 1$
- 平均移动次数（等概率插入位置）：$\frac{1}{n+1}\sum_{i=1}^{n+1}(n-i+1) = \frac{n}{2}$

**算法 2.2**（删除）：删除第 $i$ 个元素，需将第 $i+1$ 至第 $n$ 个元素前移一格。

```
deleteList(L, i):
    if i < 1 or i > L.length: return ERROR
    for k from i to L.length-1:
        L.data[k-1] = L.data[k]          // 从前往后，逐位前移
    L.length--
    return OK
```

- 移动次数：$n - i$
- 平均移动次数：$\frac{1}{n}\sum_{i=1}^{n}(n-i) = \frac{n-1}{2}$

**定理 2.2**：顺序表插入、删除的平均时间复杂度均为 $O(n)$。

**推论 2.2**　顺序表适合频繁访问、少插入删除的场景；表长需预估，可能溢出。

### 2.3 复杂度小结

| 操作 | 时间复杂度 |
|------|------------|
| 随机访问 | $O(1)$ |
| 尾部插入 | $O(1)$ |
| 任意位置插入 | $O(n)$ |
| 任意位置删除 | $O(n)$ |
| 按值查找 | $O(n)$ |

## 3. 链式存储结构

### 3.1 单链表

**定义 3.1**　**单链表**用一组任意的存储单元存放元素，每个**结点**包含**数据域**与**指针域**：

```
[ data | next ] → [ data | next ] → ... → NULL
```

**头指针**指向首结点；**头结点**是首结点前附加的哑结点，便于统一操作。

**定理 3.1**：在已知前驱结点 $p$ 的前提下，单链表插入/删除结点的时间为 $O(1)$。

```
insertAfter(p, s):                       // 在 p 之后插入 s
    s.next = p.next
    p.next = s                           // 两行顺序不可颠倒

deleteAfter(p):                          // 删除 p 的后继 q
    q = p.next
    p.next = q.next
```

**推论 3.1**　链表插入删除不需移动元素，但定位前驱需 $O(n)$ 的遍历——"已知位置"是前提。

### 3.2 单链表基本操作

**算法 3.1**（头插法建表）：每次将新结点插入头结点之后，生成逆序链表，$O(n)$。

```
createListHead(n):                       // 头插法，结果逆序
    head = new Node; head.next = NULL
    for i from 1 to n:
        s = new Node; read(s.data)
        s.next = head.next
        head.next = s
    return head
```

**算法 3.2**（尾插法建表）：维护尾指针，每次插到表尾，生成正序链表，$O(n)$。

**算法 3.3**（按序号查找）：从头指针出发走 $i - 1$ 步，$O(n)$。

**定理 3.2**：单链表按序号访问的时间复杂度为 $O(n)$（**顺序存取**）。

**推论 3.2**　顺序存取与随机存取的对偶是顺序表与链表的本质区别。

### 3.3 双链表

**定义 3.2**　**双链表**的每个结点有两个指针域：

```
[ prior | data | next ]
```

**定理 3.3**：双链表可 $O(1)$ 访问前驱——删除结点时无需再找前驱。

**推论 3.3**　前插、删除操作的实现比单链表更简洁。

### 3.4 循环链表

**定义 3.3**　**循环链表**的尾结点指针指向头结点，形成环。

**性质 3.2**：从表中任一结点出发均可遍历整个链表。

**定理 3.4**：循环链表判空与判尾条件统一——`p->next == head`。

**推论 3.4**　带尾指针的循环链表，首尾操作均 $O(1)$，适合队列。

### 3.5 静态链表

**定义 3.4**　**静态链表**用数组模拟链表，每个分量含数据域 `data` 与游标 `next`，以游标替代指针。

**注意**　静态链表兼顾数组的连续存储与链表的不移动元素，适用于不支持指针的语言。

### 3.6 存储结构对比

| 维度 | 顺序表 | 单链表 |
|------|--------|--------|
| 存储方式 | 连续 | 任意 |
| 随机访问 | $O(1)$ | $O(n)$ |
| 插入/删除 | $O(n)$ | $O(1)$（已知前驱） |
| 空间开销 | 需预分配，可能浪费 | 每结点额外指针开销 |
| 表长 | 固定，需扩容 | 动态增长 |

**推论 3.5**　选择存储结构应依据操作频率——访问多选顺序，增删多选链式。

## 4. 线性表的应用

### 4.1 有序表

**定义 4.1**　**有序表**是元素按关键字非降（或非增）排列的线性表。

**定理 4.1**：两个有序表合并为有序表的时间为 $O(m + n)$（归并思想）。

**推论 4.1**　有序性使折半查找成为可能，把查找降到 $O(\log n)$。

### 4.2 链表操作技巧

- **带头结点**：统一空表与非空表的操作，减少边界判断
- **哑结点/哨兵**：避免对头结点的特殊处理
- **快慢指针**：一次遍历求中点、判环（Floyd 判圈算法）
- **双指针**：求倒数第 $k$ 个结点、链表相交点

**定理 4.2**（Floyd 判圈）：若链表有环，快指针（走两步）与慢指针（走一步）必在环内相遇。

```
hasCycle(head):                          // 快慢指针，时间 O(n)、空间 O(1)
    slow = fast = head
    while fast != NULL and fast.next != NULL:
        slow = slow.next
        fast = fast.next.next
        if slow == fast: return true
    return false
```

**推论 4.2**　快慢指针以 $O(n)$ 时间、$O(1)$ 空间检测链表的环与中点。

### 4.3 应用场景
- 多项式表示与相加（有序链表/顺序表）
- 内存管理中的空闲块链
- 符号表的链式实现
