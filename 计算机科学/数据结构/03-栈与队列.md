# 栈与队列

> 受限的线性表——后进先出与先进先出。

## 1. 栈

### 1.1 栈的定义

**定义 1.1**　**栈**是只允许在**表尾**进行插入和删除的线性表。允许操作的一端称**栈顶**，另一端称**栈底**。

**性质 1.1**：栈遵循**后进先出**（LIFO，Last In First Out）原则。

**定义 1.2**　栈的基本操作：

| 操作 | 语义 |
|------|------|
| `InitStack(S)` | 初始化空栈 |
| `Push(S, x)` | 入栈 |
| `Pop(S, x)` | 出栈 |
| `GetTop(S, x)` | 读取栈顶 |
| `StackEmpty(S)` | 判空 |

**推论 1.1**　栈是操作受限的线性表——逻辑结构仍为一对一。

### 1.2 顺序栈

**定义 1.3**　**顺序栈**用数组 `data[0..maxsize-1]` 与栈顶指针 `top` 实现，`top == -1` 时为空栈。

**注意**　入栈时 `top` 后移再存值，出栈时先取值再 `top` 前移；需处理**上溢**（满）与**下溢**（空）。

```
push(S, x):                              // 顺序栈
    if S.top == MAXSIZE - 1: return OVERFLOW
    S.data[++S.top] = x
    return OK

pop(S, x):
    if S.top == -1: return UNDERFLOW
    x = S.data[S.top--]
    return OK
```

**共享栈**：两个栈共用一段空间，分别从两端向中间增长，提高空间利用率。

**推论 1.2**　共享栈在两栈空间需求互补时最有效——上溢条件是两栈顶相遇。

### 1.3 链栈

**定义 1.4**　**链栈**用单链表实现，栈顶即链表头，入栈/出栈在头部进行。

**定理 1.1**：链栈的入栈与出栈均为 $O(1)$，且不存在栈满问题。

**推论 1.3**　链栈以指针开销换取动态容量，适合栈深不确定的场景。

| 维度 | 顺序栈 | 链栈 |
|------|--------|------|
| 栈满 | 需判定上溢 | 不会满 |
| 时间 | $O(1)$ | $O(1)$ |
| 空间 | 需预分配 | 动态 |
| 多栈共享 | 支持（共享栈） | 不支持 |

## 2. 栈的应用

### 2.1 括号匹配

**算法 2.1**：遇左括号入栈，遇右括号时弹出栈顶并检查是否匹配；结束时栈必须为空。

**定理 2.1**：括号序列合法 $\iff$ 扫描过程中栈不会在空时出栈，且扫描结束时栈为空。

```
match(str):                              // 括号匹配
    initStack(S)
    for ch in str:
        if ch in "([{":  push(S, ch)
        else:
            if empty(S):             return false
            top = pop(S)
            if not pairs(top, ch):   return false
    return empty(S)                      // 必须栈空
```

**推论 2.1**　栈天然刻画嵌套结构——匹配问题的本质是嵌套。

### 2.2 表达式求值

**定义 2.1**：
- **中缀表达式**：运算符在两操作数之间，如 $a + b$
- **后缀表达式**（逆波兰式）：运算符在两操作数之后，如 $a\ b\ +$
- **前缀表达式**：运算符在两操作数之前，如 $+\ a\ b$

**定理 2.2**：后缀表达式无优先级与括号歧义，可用单个栈从左到右求值，$O(n)$。

**算法 2.2**（中缀转后缀，Dijkstra 双栈/调度场算法）：
1. 遇操作数直接输出
2. 遇运算符：弹出栈中优先级不低于它的运算符，再入栈
3. 遇左括号入栈，遇右括号弹至左括号
4. 扫描结束后弹出栈中剩余运算符

```
toPostfix(expr):                         // 中缀转后缀
    initStack(S)
    for ch in expr:
        if ch is operand:  output(ch)
        elif ch == '(':    push(S, ch)
        elif ch == ')':    while top(S) != '(': output(pop(S))
                           pop(S)
        else:                            // 运算符
            while not empty(S) and priority(top(S)) >= priority(ch):
                output(pop(S))
            push(S, ch)
    while not empty(S): output(pop(S))
```

**推论 2.2**　中缀、前缀、后缀表达式对应二叉树的中序、前序、后序遍历。

### 2.3 递归与栈

**定理 2.3**：任何递归算法都可用栈显式模拟系统栈而改写为迭代。

**注意**　函数调用栈保存返回地址、参数与局部变量；递归深度过大导致**栈溢出**。

**推论 2.3**　尾递归可被编译器优化为迭代，无额外栈开销。

### 2.4 其他经典应用

- 二叉树非递归遍历
- 深度优先搜索（DFS）
- 函数调用与回溯（N 皇后、迷宫求解）
- 单调栈：求下一个更大（更小）元素，$O(n)$

**定理 2.4**（单调栈）：维护单调递减的栈，可在 $O(n)$ 内求出每个元素右侧第一个更大元素。

```
nextGreater(a, n):                       // 单调栈：右侧第一个更大元素
    initStack(S)                         // 存下标，栈内元素单调递减
    for i from 0 to n-1:
        while not empty(S) and a[top(S)] < a[i]:
            ans[pop(S)] = a[i]
        push(S, i)
    while not empty(S): ans[pop(S)] = -1  // 无更大元素
```

**推论 2.4**　每个元素至多入栈、出栈各一次，故单调栈总代价为线性。

## 3. 队列

### 3.1 队列的定义

**定义 3.1**　**队列**是只允许在**队尾**插入、在**队头**删除的线性表。

**性质 3.1**：队列遵循**先进先出**（FIFO，First In First Out）原则。

**定义 3.2**　队列的基本操作：

| 操作 | 语义 |
|------|------|
| `InitQueue(Q)` | 初始化空队列 |
| `EnQueue(Q, x)` | 入队（队尾） |
| `DeQueue(Q, x)` | 出队（队头） |
| `GetHead(Q, x)` | 取队头元素 |
| `QueueEmpty(Q)` | 判空 |

### 3.2 顺序队列与假溢出

**定义 3.3**　**顺序队列**用数组与队头指针 `front`、队尾指针 `rear` 实现。

**注意**　普通顺序队列出队后队头空间无法复用，导致**假溢出**——数组未满却无法入队。

### 3.3 循环队列

**定义 3.4**　**循环队列**把数组视为首尾相接的环，指针以取模运算回绕：

$$\text{front} = (\text{front} + 1) \bmod \text{maxsize}, \quad \text{rear} = (\text{rear} + 1) \bmod \text{maxsize}$$

**定理 3.1**：循环队列的队空与队满条件需区分：
- 牺牲一个单元：队空 `front == rear`，队满 `(rear + 1) % maxsize == front`
- 增设长度变量 `size`：由 `size == 0` 判空，`size == maxsize` 判满
- 增设标志位 `tag`：区分"队空"与"队满"两种 `front == rear`

**推论 3.1**　循环队列的元素个数为 $(\text{rear} - \text{front} + \text{maxsize}) \bmod \text{maxsize}$。

```
enQueue(Q, x):                           // 循环队列，牺牲一个单元区分空/满
    if (Q.rear + 1) % MAXSIZE == Q.front: return OVERFLOW   // 队满
    Q.data[Q.rear] = x
    Q.rear = (Q.rear + 1) % MAXSIZE
    return OK

deQueue(Q, x):
    if Q.front == Q.rear: return ERROR   // 队空
    x = Q.data[Q.front]
    Q.front = (Q.front + 1) % MAXSIZE
    return OK
```

### 3.4 链队列

**定义 3.5**　**链队列**用带头结点的单链表实现，队头指针指向头结点，队尾指针指向最后结点。

**定理 3.2**：链队列的入队与出队均为 $O(1)$，无假溢出问题。

**推论 3.2**　出队时若队列变为空，需将队尾指针重新指向头结点。

### 3.5 双端队列

**定义 3.6**　**双端队列**（deque）允许在两端进行插入与删除。

| 变体 | 允许操作 |
|------|----------|
| 输入受限双端队列 | 只允许一端插入，两端删除 |
| 输出受限双端队列 | 只允许一端删除，两端插入 |

**推论 3.3**　栈与队列都是双端队列的受限形式——栈限制为一端操作，队列限制为两端分工。

### 3.6 存储结构对比

| 维度 | 循环队列 | 链队列 |
|------|----------|--------|
| 假溢出 | 已解决 | 不存在 |
| 时间 | $O(1)$ | $O(1)$ |
| 空间 | 需预分配 | 动态 |
| 实现 | 判空/判满复杂 | 指针操作简单 |

## 4. 队列的应用

### 4.1 广度优先搜索

**定理 4.1**：BFS 用队列保证按层扩展——先访问的结点其邻居先被发现。

**推论 4.1**　队列是 BFS 的数据结构基础，对应 DFS 用栈。

### 4.2 层次遍历

- 二叉树的层序遍历
- 图的层次遍历

### 4.3 缓冲区与调度

- 打印任务队列、进程就绪队列
- 消息队列、生产者—消费者模型

### 4.4 单调队列

**定理 4.2**（单调队列）：维护单调的双端队列，可在 $O(n)$ 内求滑动窗口的最大（最小）值。

**推论 4.2**　单调队列 = 单调栈 + 队头过期淘汰，是滑动窗口问题的标准工具。

## 5. 栈与队列的对比

| 维度 | 栈 | 队列 |
|------|----|----|
| 访问端 | 仅栈顶 | 队头出、队尾入 |
| 顺序 | 后进先出 LIFO | 先进先出 FIFO |
| 典型应用 | 表达式、递归、DFS | 层次遍历、BFS、缓冲 |
| 实现 | 顺序栈/链栈 | 循环队列/链队列 |

**推论 5.1**　栈与队列是操作受限的线性表——限制带来语义，语义带来适用性。
