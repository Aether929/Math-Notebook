# 绪论与算法分析

> 数据结构的语言与度量——抽象数据类型、存储表示与复杂度。

## 1. 基本概念

### 1.1 数据、数据元素与数据项

**定义 1.1**：
- **数据**：信息的载体，能被计算机识别、存储和加工处理的符号集合
- **数据元素**：数据的基本单位，是数据结构中讨论的最小对象
- **数据项**：构成数据元素的不可分割的最小单位

**注意**　一个数据元素可由若干数据项组成，此时数据元素又称**记录**。

### 1.2 数据结构

**定义 1.2**　**数据结构**研究数据元素之间的逻辑关系、在计算机中的表示及相应操作，包含三个方面：

| 方面 | 含义 | 例子 |
|------|------|------|
| 逻辑结构 | 数据元素间的抽象关系 | 线性、树形、图形、集合 |
| 存储结构 | 逻辑结构在内存中的表示 | 顺序、链式、索引、散列 |
| 数据运算 | 施加于数据上的操作 | 插入、删除、查找、遍历 |

**推论 1.1**　逻辑结构与存储结构相互独立——同一种逻辑结构可有多种存储表示。

### 1.3 逻辑结构的分类

**定义 1.3**　按元素间的关系将逻辑结构分为四类：

| 逻辑结构 | 关系特征 | 典型结构 |
|----------|----------|----------|
| 集合 | 元素间无其他关系 | 集合 |
| 线性结构 | 一对一 | 线性表、栈、队列 |
| 树形结构 | 一对多 | 树、二叉树、堆 |
| 图形结构 | 多对多 | 图、网络 |

**推论 1.2**　树形结构与图形结构合称**非线性结构**——元素间存在一对多或多对多关系。

### 1.4 存储结构的分类

**定义 1.4**：
- **顺序存储**：用一组地址连续的存储单元依次存放，逻辑相邻即物理相邻
- **链式存储**：用指针表示元素间的逻辑关系，存储单元可不连续
- **索引存储**：附加索引表记录元素的存储位置
- **散列存储**：由关键字直接计算存储地址

**推论 1.3**　顺序存储支持随机访问但插入删除代价高；链式存储插入删除灵活但不支持随机访问。

### 1.5 抽象数据类型

**定义 1.5**　**抽象数据类型（ADT）** 是一个数学模型及其上定义的一组操作，由三元组表示：

$$\text{ADT} = (D, S, P)$$

其中 $D$ 为数据对象、$S$ 为 $D$ 上的关系集、$P$ 为 $D$ 上的基本操作集。

**注意**　ADT 强调**信息隐藏**与**接口分离**——使用者只关心操作语义，不关心实现细节。

**推论 1.4**　ADT 是面向对象编程中"类"的前身，是模块化设计的理论基础。

## 2. 算法及其特性

### 2.1 算法的定义

**定义 2.1**　**算法**是解决特定问题的求解步骤的有限序列，满足：

| 特性 | 含义 |
|------|------|
| 有穷性 | 在有限步之后终止 |
| 确定性 | 每步含义唯一、无歧义 |
| 可行性 | 每步可通过基本运算实现 |
| 输入 | 有零个或多个输入 |
| 输出 | 有一个或多个输出 |

**推论 2.1**　算法必须有穷——程序可以不满足有穷性（如操作系统常驻）。

### 2.2 算法设计的要求

**定义 2.2**　评价算法的主要指标：
- **正确性**：对合法输入均给出正确结果
- **可读性**：易于理解和交流
- **健壮性**：对非法输入能合理处理
- **高效性**：时间与空间开销尽量小

**推论 2.2**　正确性是前提，效率是核心——二者存在权衡。

### 2.3 算法与程序

**注意**　算法是思想，程序是算法的具体实现；同一算法可有多种语言、多种风格的实现。

## 3. 算法分析

### 3.1 问题规模与语句频度

**定义 3.1**　**算法的时间复杂度**是问题规模 $n$ 的函数 $T(n)$，即算法中基本语句的**频度**之和。

**例 3.1**　求累加和：

```
sum = 0;                    // 1 次
for (i = 1; i <= n; i++)    // n + 1 次
    sum += i;               // n 次
```

则 $T(n) = 1 + (n+1) + n = 2n + 2$。

**推论 3.1**　$T(n)$ 是精确频度，但通常只关心其**增长量级**。

### 3.2 渐近记号

**定义 3.2**　设 $T(n), f(n)$ 为定义在正整数上的函数：

$$T(n) = O(f(n)) \iff \exists c > 0, n_0 > 0,\ \forall n \geq n_0:\ T(n) \leq c f(n)$$

$$T(n) = \Omega(f(n)) \iff \exists c > 0, n_0 > 0,\ \forall n \geq n_0:\ T(n) \geq c f(n)$$

$$T(n) = \Theta(f(n)) \iff T(n) = O(f(n)) \text{ 且 } T(n) = \Omega(f(n))$$

**定义 3.3**（严格记号）：
- $T(n) = o(f(n)) \iff \lim_{n \to \infty} T(n)/f(n) = 0$
- $T(n) = \omega(f(n)) \iff \lim_{n \to \infty} T(n)/f(n) = \infty$

**推论 3.2**　$O$ 给出上界，$\Omega$ 给出下界，$\Theta$ 给出紧确界——即"增长率同阶"。

### 3.3 常见复杂度阶

**定义 3.4**　按增长快慢排序：

$$O(1) < O(\log n) < O(n) < O(n \log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)$$

| 记号 | 名称 | 典型算法 |
|------|------|----------|
| $O(1)$ | 常数阶 | 数组随机访问 |
| $O(\log n)$ | 对数阶 | 折半查找 |
| $O(n)$ | 线性阶 | 顺序查找 |
| $O(n \log n)$ | 线性对数阶 | 归并排序、堆排序 |
| $O(n^2)$ | 平方阶 | 冒泡排序、插入排序 |
| $O(2^n)$ | 指数阶 | 朴素子集枚举 |
| $O(n!)$ | 阶乘阶 | 旅行商朴素解 |

**定理 3.1**：$f(n) = O(g(n))$ 且 $g(n) = O(h(n))$ $\Rightarrow$ $f(n) = O(h(n))$（传递性）。

**推论 3.3**　$O$ 记号具有传递性、自反性，但不具有反对称性——$O(n) = O(n^2)$ 与 $O(n^2) = O(n)$ 并不同真。

### 3.4 空间复杂度

**定义 3.5**　**空间复杂度** $S(n)$ 是算法运行所需辅助存储空间关于问题规模 $n$ 的函数。

**注意**　$S(n)$ 只计**辅助空间**，不计输入本身占用的空间。原地算法（in-place）满足 $S(n) = O(1)$。

**推论 3.4**　时间与空间可相互转化——用空间换时间是常见优化手段（如散列表、动态规划）。

## 4. 递归与递推式的分析

### 4.1 递归算法

**定义 4.1**　**递归**是函数直接或间接调用自身的求解方法，由**递归基**（终止条件）与**递归式**（规模缩减）构成。

**例 4.1**　阶乘：

$$n! = \begin{cases} 1, & n = 0 \\ n \cdot (n-1)!, & n > 0 \end{cases}$$

**伪代码**（递归与迭代的对比）：

```
factorial(n):                 // 递归：时间 O(n)，空间 O(n)
    if n == 0: return 1
    return n * factorial(n - 1)

factorialIter(n):             // 迭代：时间 O(n)，空间 O(1)
    r = 1
    for i from 2 to n: r = r * i
    return r
```

**推论 4.1**　递归的每次调用压入栈帧，空间开销为递归深度 $O(n)$。

### 4.2 递归方程求解

**定义 4.2**　分治算法的运行时间满足递归方程 $T(n) = aT(n/b) + f(n)$，其中 $a$ 为子问题数、$n/b$ 为子问题规模、$f(n)$ 为分解与合并代价。

**定理 4.1**（Master 定理）：记 $c = \log_b a$，则

$$T(n) = \begin{cases} \Theta(n^{c}), & f(n) = O(n^{c - \varepsilon}) \\ \Theta(n^{c} \log^{k+1} n), & f(n) = \Theta(n^{c} \log^{k} n) \\ \Theta(f(n)), & f(n) = \Omega(n^{c + \varepsilon}),\ a f(n/b) \leq \delta f(n) \end{cases}$$

**推论 4.2**　Master 定理的本质是比较 $f(n)$ 与 $n^{\log_b a}$ 的增长速度——谁大由谁主导。

### 4.3 经典实例

| 算法 | 递归方程 | 解 |
|------|----------|----|
| 折半查找 | $T(n) = T(n/2) + O(1)$ | $O(\log n)$ |
| 归并排序 | $T(n) = 2T(n/2) + O(n)$ | $O(n \log n)$ |
| 二叉树遍历 | $T(n) = 2T(n/2) + O(1)$ | $O(n)$ |
| 大整数乘法 | $T(n) = 3T(n/2) + O(n)$ | $O(n^{\log_2 3})$ |

**推论 4.3**　递归方程的详细解法见 [离散数学 §4 递推关系](../../其他/离散数学/04-递推关系.md)。

## 5. 应用

### 5.1 算法设计范式
- 分治、贪心、动态规划、回溯的时间分析均归结为递归方程
- 渐近分析是判断算法可扩展性的通用语言

### 5.2 工程实践
- 选择数据结构时权衡时间与空间复杂度
- 大规模数据下 $O(n \log n)$ 与 $O(n^2)$ 的差距是决定性的
