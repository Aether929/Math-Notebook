# 树与二叉树

> 一对多的层次结构——从二叉树遍历到 Huffman 编码。

## 1. 树

### 1.1 树的定义

**定义 1.1**　**树**是 $n$（$n \geq 0$）个结点的有限集合 $T$。当 $n = 0$ 时为空树；当 $n > 0$ 时：

1. 有且仅有一个特定的**根**结点
2. 其余结点可分为 $m$（$m \geq 0$）个互不相交的有限集 $T_1, \ldots, T_m$，每个集合又是一棵树，称为根的**子树**

**性质 1.1**：树是递归定义的结构——"树由子树构成"。

**推论 1.1**　除根外每个结点有且仅有一个**双亲**，体现一对多的层次关系。

### 1.2 基本术语

**定义 1.2**：

| 术语 | 含义 |
|------|------|
| 结点的度 | 结点拥有的子树数 |
| 树的度 | 树中结点的最大度 |
| 叶子（终端结点） | 度为 0 的结点 |
| 分支结点 | 度不为 0 的结点 |
| 孩子/双亲/兄弟 | 子树根/上层结点/同双亲结点 |
| 层次 | 根为第 1 层，孩子层次加 1 |
| 深度（高度） | 树中结点的最大层次 |
| 有序树 | 子树有先后次序 |

**推论 1.2**　森林是 $m$（$m \geq 0$）棵互不相交的树的集合——删去树的根即为森林。

### 1.3 树的性质

**定理 1.1**：树中结点数 = 所有结点的度之和 $+ 1$。即

$$n = \sum_{i=1}^{n} \deg(v_i) + 1$$

**推论 1.3**　树中边数 $= n - 1$（对每个非根结点，其双亲边唯一）。

**定理 1.2**：度为 $k$ 的树中，若 $n_i$ 为度为 $i$ 的结点数，则

$$\sum_{i=0}^{k} i \cdot n_i = n - 1 = \sum_{i=0}^{k} n_i - 1$$

**推论 1.4**　$n_0 = 1 + \sum_{i=1}^{k} (i - 1) n_i$——叶子数由其余结点的度决定。

### 1.4 树的存储结构

| 存储方式 | 结构 | 特点 |
|----------|------|------|
| 双亲表示法 | 数组存 `(data, parent)` | 找双亲快，找孩子慢 |
| 孩子表示法 | 多重链表/孩子链表 | 找孩子快 |
| 孩子兄弟表示法 | 左孩子右兄弟 | 统一表示任意树，最常用 |

**定理 1.3**：孩子兄弟表示法下，任何树都可表示为二叉树——左指针指第一个孩子，右指针指下一个兄弟。

**推论 1.5**　树的二叉树表示是"树—森林—二叉树"相互转换的基础。

## 2. 二叉树

### 2.1 定义与性质

**定义 2.1**　**二叉树**是 $n$ 个结点的有限集合，每个结点至多有两棵子树（左子树、右子树），且左右子树**有次序**。

**注意**　二叉树是有序树，左右子树交换得到的是不同的二叉树；即使是单分支，也区分左/右。

**性质 2.1**：二叉树第 $i$ 层至多有 $2^{i-1}$ 个结点（$i \geq 1$）。

**性质 2.2**：深度为 $k$ 的二叉树至多有 $2^k - 1$ 个结点。

**性质 2.3**：对任何二叉树，若叶子数为 $n_0$、度为 2 的结点数为 $n_2$，则

$$n_0 = n_2 + 1$$

**推论 2.1**　$n_0 = n_2 + 1$ 是二叉树最基本的计数恒等式。

### 2.2 特殊二叉树

**定义 2.2**：
- **满二叉树**：每层结点数都达到最大，共 $2^k - 1$ 个结点
- **完全二叉树**：结点按层序编号与满二叉树一致（可缺最后一层的右侧结点）
- **二叉排序树**：左子树全小于根、右子树全大于根（见 [07-查找](07-查找.md)）

**定理 2.1**：$n$ 个结点的完全二叉树深度为 $\lfloor \log_2 n \rfloor + 1$。

**定理 2.2**（完全二叉树的编号性质）：结点 $i$ 的双亲为 $\lfloor i/2 \rfloor$，左孩子为 $2i$，右孩子为 $2i+1$。

**推论 2.2**　完全二叉树可用一维数组紧凑存储，无需指针——空间利用率最高。

### 2.3 存储结构

| 方式 | 描述 | 适用 |
|------|------|------|
| 顺序存储 | 数组按下标映射 | 完全二叉树 |
| 链式存储 | `[lchild | data | rchild]` | 一般二叉树 |

**推论 2.3**　顺序存储对退化二叉树（单支树）浪费空间，链式存储更通用。

## 3. 二叉树的遍历

### 3.1 四种遍历

**定义 3.1**　按访问根的时机区分：

| 遍历 | 顺序 | 应用 |
|------|------|------|
| 先序 | 根 → 左 → 右 | 复制树、序列化 |
| 中序 | 左 → 根 → 右 | 二叉排序树得有序序列 |
| 后序 | 左 → 右 → 根 | 释放空间、计算树高 |
| 层序 | 按层从左到右 | 用队列实现，BFS |

```
preOrder(node):                          // 先序：根 → 左 → 右
    if node: visit(node); preOrder(node.left); preOrder(node.right)

inOrder(node):                           // 中序：左 → 根 → 右
    if node: inOrder(node.left); visit(node); inOrder(node.right)

postOrder(node):                         // 后序：左 → 右 → 根
    if node: postOrder(node.left); postOrder(node.right); visit(node)

levelOrder(root):                        // 层序：借助队列
    if root == NULL: return
    initQueue(Q); enQueue(Q, root)
    while not empty(Q):
        node = deQueue(Q); visit(node)
        if node.left:  enQueue(Q, node.left)
        if node.right: enQueue(Q, node.right)
```

**定理 3.1**：先序、中序、后序遍历的时间复杂度均为 $O(n)$，空间复杂度 $O(h)$（$h$ 为树高）。

**推论 3.1**　递归遍历的栈空间由树高决定，退化为单支树时为 $O(n)$。

### 3.2 由遍历序列确定二叉树

**定理 3.2**：由**先序 + 中序**或**后序 + 中序**可唯一确定一棵二叉树。

**注意**　仅由**先序 + 后序**不能唯一确定二叉树——无法区分左右子树的分界。

**推论 3.2**　中序序列提供了左右子树的分界，是重建的关键；先序/后序仅确定根。

### 3.3 非递归遍历

**定理 3.3**：借助显式栈可模拟递归，实现 $O(n)$ 的非递归遍历。

```
inOrderIter(root):                       // 中序非递归
    initStack(S); p = root
    while p != NULL or not empty(S):
        while p != NULL:                 // 一路向左
            push(S, p); p = p.left
        p = pop(S); visit(p)
        p = p.right                      // 转向右子树
```

**推论 3.3**　中序非递归遍历是最常用的形式——沿左链下行，回溯时访问。

### 3.4 Morris 遍历

**定理 3.4**（Morris）：利用叶子结点的空右指针临时指向前驱，可在 $O(n)$ 时间、$O(1)$ 空间完成中序遍历。

**推论 3.4**　Morris 遍历以修改并复原指针为代价换取常数空间。

## 4. 线索二叉树

### 4.1 定义

**定义 4.1**　**线索二叉树**利用空指针域存放前驱/后继指针（**线索**），以加速遍历。增设标志位：

```
[ ltag | lchild | data | rchild | rtag ]
```

- `ltag = 0`：`lchild` 指左孩子；`ltag = 1`：指前驱
- `rtag = 0`：`rchild` 指右孩子；`rtag = 1`：指后继

**定理 4.1**：$n$ 个结点的二叉树有 $n + 1$ 个空指针域，恰好可用于线索化。

**推论 4.1**　线索化使中序遍历无需栈，空间降为 $O(1)$。

### 4.2 中序线索二叉树

**算法 4.1**（线索化）：中序遍历过程中，把当前结点的左空指针指向前驱、前驱的右空指针指向当前结点。

**定理 4.2**：中序线索二叉树中，求后继的规则为——有右孩子则右子树最左结点，否则 `rchild` 即后继。

**推论 4.2**　线索二叉树以存储换时间，适合需频繁查找前驱/后继的场景。

## 5. 树、森林与二叉树的转换

**定理 5.1**：任意树可唯一转换为二叉树（孩子兄弟表示法）；二叉树也可唯一还原为树。

**算法 5.1**（森林转二叉树）：
1. 各棵树先转成二叉树
2. 第一棵树的根作为总根，依次把后一棵树作为前一棵树的右子树

**推论 5.1**　树的遍历对应关系：

| 树的遍历 | 对应二叉树的遍历 |
|----------|------------------|
| 先根遍历 | 先序遍历 |
| 后根遍历 | 中序遍历 |

**推论 5.2**　森林的遍历也与二叉树遍历一一对应，递归结构贯穿始终。

## 6. Huffman 树

### 6.1 定义

**定义 6.1**　**路径长度**是根到结点所经分支数；**带权路径长度** $WPL$ 为

$$WPL = \sum_{i=1}^{n} w_i \cdot l_i$$

其中 $w_i$ 为第 $i$ 个叶子的权，$l_i$ 为其路径长度。

**定义 6.2**　**Huffman 树**是 $WPL$ 最小的二叉树（最优二叉树）。

### 6.2 构造算法

**算法 6.1**（Huffman）：
1. 以每个权值构造单结点树，组成森林
2. 从森林中取权值最小的两棵树，合并为一棵新树（新根权 = 两权之和）
3. 重复步骤 2 直至只剩一棵树

```
buildHuffman(w):                         // 权值数组 w[0..n-1]
    for i from 0 to n-1: T[i] = (w[i], NULL, NULL)
    for i from n to 2n-2:
        (s1, s2) = 取 T 中权值最小的两棵（父指针为空）
        T[i] = (T[s1].w + T[s2].w, s1, s2)      // 合并为新根
        T[s1].parent = T[s2].parent = i
    return 2n-2                          // 根的下标
```

**定理 6.1**：Huffman 算法得到的树是 $WPL$ 最小的。

**推论 6.1**　权值越大的叶子越靠近根——贪心策略由此保证最优性。

**定理 6.2**：Huffman 树中不存在度为 1 的结点，$n$ 个叶子的 Huffman 树共 $2n - 1$ 个结点。

**推论 6.2**　Huffman 树是最优二叉树，但并非唯一——左右交换或等权合并顺序不同可得不同的最优树。

### 6.3 Huffman 编码

**定义 6.3**　**前缀编码**要求任一编码都不是另一编码的前缀，保证解码无歧义。

**定理 6.3**：以字符频率为权构造 Huffman 树，左分支标 0、右分支标 1，即得**最优前缀编码**，总码长 = $WPL$。

**推论 6.3**　Huffman 编码是数据压缩的经典方法——频率高的字符码短。

## 7. 并查集

### 7.1 定义

**定义 7.1**　**并查集**（Union-Find）是维护**不相交集合**的数据结构，支持：
- `Find(x)`：查找 $x$ 所在集合的代表元
- `Union(x, y)`：合并两个集合

**定理 7.1**：并查集用树（森林）表示集合，用数组 `parent[]` 存储双亲，根为集合代表。

```
find(x):                                 // 路径压缩
    while parent[x] != x:
        parent[x] = parent[parent[x]]    // 路径减半
        x = parent[x]
    return x

union(x, y):                             // 按秩合并
    rx = find(x); ry = find(y)
    if rx == ry: return
    if rank[rx] < rank[ry]: swap(rx, ry)
    parent[ry] = rx                      // 矮树接到高树下
    if rank[rx] == rank[ry]: rank[rx]++
```

### 7.2 优化

**优化 1（路径压缩）**：`Find` 时将路径上所有结点直接指向根。

**优化 2（按秩合并）**：把矮树接到高树下，避免树高增长。

**定理 7.2**：路径压缩 + 按秩合并后，单次操作的**均摊**时间复杂度为 $O(\alpha(n))$。

**推论 7.1**　$\alpha(n)$ 为反 Ackermann 函数，对一切实际规模 $n$ 均有 $\alpha(n) \leq 4$——近似常数。

**推论 7.2**　并查集是 Kruskal 算法与等价类划分的核心工具。

## 8. 应用

### 8.1 编码与压缩
- Huffman 编码用于文件压缩（如 DEFLATE 的基础之一）
- 前缀码保证解码唯一

### 8.2 表达式与语法
- 表达式树、语法分析树、决策树
- 人工智能中的博弈树、搜索树

### 8.3 集合与图
- 并查集用于连通性判定、最小生成树
- Trie 树用于字符串检索

### 8.4 数据组织
- 二叉排序树、堆（见 [07-查找](07-查找.md)、[08-排序](08-排序.md)）
- B 树/B+ 树用于数据库与文件系统的索引
