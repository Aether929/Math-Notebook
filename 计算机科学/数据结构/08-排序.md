# 排序

> 把无序变有序——从插入排序到基数排序与外排序。

## 1. 基本概念

### 1.1 排序的定义

**定义 1.1**　**排序**是把一组记录按关键字递增（或递减）重新排列的操作。

**定义 1.2**：
- **内排序**：整个排序过程在内存中完成
- **外排序**：数据量过大，排序过程需借助外存

**定义 1.3**　**稳定性**：排序前后关键字相等的记录相对次序保持不变，则称排序**稳定**。

**推论 1.1**　稳定性对多关键字排序至关重要——先按次要关键字排、再按主要关键字排时，稳定性保证结果正确。

### 1.2 排序方法的分类

| 分类依据 | 类别 |
|----------|------|
| 基本操作 | 插入、交换、选择、归并、基数 |
| 内/外存 | 内排序、外排序 |
| 复杂度 | 简单排序 $O(n^2)$、先进排序 $O(n\log n)$ |

**定理 1.1**（比较排序下界）：任何基于关键字比较的排序算法，最坏情形至少需要 $\Omega(n \log n)$ 次比较。

**推论 1.2**　$O(n \log n)$ 是比较排序的理论下界——归并排序、堆排序、快速排序平均达到该下界。

**注意**　基数排序不基于比较，可突破该下界。

## 2. 插入排序

### 2.1 直接插入排序

**算法 2.1**：把第 $i$ 个记录插入到前面已排好序的子序列中。

```
insertSort(a, n):                        // 直接插入排序，稳定
    for i from 1 to n-1:
        tmp = a[i]; j = i - 1
        while j >= 0 and a[j] > tmp:
            a[j+1] = a[j]; j--           // 后移腾位
        a[j+1] = tmp
```

**定理 2.1**：直接插入排序时间复杂度为 $O(n^2)$，空间 $O(1)$，且是**稳定**的。

**推论 2.1**　当序列基本有序时，直接插入排序退化为 $O(n)$——接近最优。

### 2.2 希尔排序

**算法 2.2**（Shell）：取增量序列 $d_1 > d_2 > \cdots > d_t = 1$，按每个增量分组做插入排序。

```
shellSort(a, n):                         // 希尔排序，不稳定
    for gap = n/2; gap > 0; gap = gap/2:
        for i from gap to n-1:           // 对各组做插入排序
            tmp = a[i]; j = i - gap
            while j >= 0 and a[j] > tmp:
                a[j+gap] = a[j]; j -= gap
            a[j+gap] = tmp
```

**定理 2.2**：希尔排序的时间复杂度依赖增量序列，平均约为 $O(n^{1.3})$，效率高于 $O(n^2)$。

**注意**　希尔排序是**不稳定**的——相同关键字可能被分到不同组而交换次序。

**推论 2.2**　增量序列的选取是希尔排序性能的关键（如 Hibbard、Sedgewick 序列）。

## 3. 交换排序

### 3.1 冒泡排序

**算法 3.1**：相邻元素两两比较，逆序则交换；每趟把最大元素"冒"到末尾。

```
bubbleSort(a, n):                        // 冒泡排序，稳定
    for i from 0 to n-2:
        swapped = false
        for j from 0 to n-2-i:
            if a[j] > a[j+1]:
                swap(a[j], a[j+1]); swapped = true
        if not swapped: break            // 本趟无交换 → 已有序
```

**定理 3.1**：冒泡排序时间复杂度为 $O(n^2)$，空间 $O(1)$，是**稳定**的。

**推论 3.1**　若某趟无交换则序列已有序，可提前终止——最好情形 $O(n)$。

### 3.2 快速排序

**算法 3.2**（QuickSort）：选**枢轴**，一趟划分使左小右大，再递归排序两侧。

```
partition(a, low, high):                 // 一趟划分（Hoare 法）
    pivot = a[low]
    while low < high:
        while low < high and a[high] >= pivot: high--
        a[low] = a[high]
        while low < high and a[low] <= pivot: low++
        a[high] = a[low]
    a[low] = pivot
    return low                           // 枢轴最终位置

quickSort(a, low, high):                 // 不稳定
    if low < high:
        p = partition(a, low, high)
        quickSort(a, low, p-1); quickSort(a, p+1, high)
```

**定理 3.2**：快速排序平均时间复杂度为 $O(n \log n)$，最坏为 $O(n^2)$（每次划分极不均衡）。

**推论 3.2**　枢轴的选取决定性能——随机选取或三数取中可避免最坏情形。

**注意**　快速排序是**不稳定**的；递归栈空间平均 $O(\log n)$、最坏 $O(n)$。

**定理 3.3**（优化）：小数组用插入排序、三路划分处理重复元素，可显著提速。

**推论 3.3**　快速排序的常数因子小、原地排序，实践中常优于归并排序。

## 4. 选择排序

### 4.1 简单选择排序

**算法 4.1**：每趟选出最小（大）元素放到已排序序列末尾。

**定理 4.1**：简单选择排序时间复杂度为 $O(n^2)$，空间 $O(1)$，是**不稳定**的。

**推论 4.1**　简单选择排序的交换次数最少（至多 $n - 1$ 次），适合交换代价高的场景。

### 4.2 堆排序

**定义 4.1**　**堆**是完全二叉树，且满足：大顶堆 $a_i \geq a_{2i}, a_i \geq a_{2i+1}$；小顶堆反之。

**算法 4.2**（堆排序）：
1. 建堆：从 $\lfloor n/2 \rfloor$ 开始向下调整，$O(n)$
2. 反复把堆顶与末尾交换，再调整堆，$O(n \log n)$

```
siftDown(a, k, n):                       // 大顶堆向下调整
    tmp = a[k]
    i = 2*k + 1                          // 左孩子
    while i < n:
        if i+1 < n and a[i+1] > a[i]: i++        // 取较大孩子
        if tmp >= a[i]: break
        a[k] = a[i]; k = i; i = 2*k + 1
    a[k] = tmp

heapSort(a, n):                          // 不稳定
    for k = n/2 - 1 down to 0: siftDown(a, k, n)     // 建堆 O(n)
    for i = n-1 down to 1:
        swap(a[0], a[i]); siftDown(a, 0, i)          // 取堆顶放末尾
```

**定理 4.2**：堆排序时间复杂度为 $O(n \log n)$（最好、最坏、平均均为），空间 $O(1)$。

**推论 4.2**　堆排序是**不稳定**的，但对数据分布不敏感——最坏情形仍为 $O(n \log n)$。

**定理 4.3**：用数组存储完全二叉树，结点 $i$ 的孩子为 $2i$ 与 $2i+1$，无需额外指针。

**推论 4.3**　堆还可实现优先队列、Top-K 问题——建 $k$ 个元素的堆，$O(n \log k)$。

## 5. 归并排序

**算法 5.1**（MergeSort）：把序列二分，递归排序两半，再**归并**成有序序列。

```
mergeSort(a, tmp, low, high):            // 稳定
    if low >= high: return
    mid = (low + high) / 2
    mergeSort(a, tmp, low, mid)
    mergeSort(a, tmp, mid+1, high)
    i = low; j = mid+1; k = low
    while i <= mid and j <= high:        // 归并：<= 保证稳定
        tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++]
    while i <= mid:  tmp[k++] = a[i++]
    while j <= high: tmp[k++] = a[j++]
    把 tmp[low..high] 复制回 a
```

**定理 5.1**：归并排序时间复杂度恒为 $O(n \log n)$，空间 $O(n)$（需辅助数组），是**稳定**的。

**推论 5.1**　归并排序对数据分布不敏感，且适合**链表**与**外排序**。

**定理 5.2**（归并的性质）：两个有序序列的归并可在 $O(m + n)$ 内完成。

**推论 5.2**　归并排序的代价在 $O(n)$ 的辅助空间——空间换时间。

**注意**　多路归并是外排序的基础（见 §8）。

## 6. 基数排序

**定义 6.1**　**基数排序**按关键字的各位依次分配与收集，属**分配式**排序，不比较关键字。

**算法 6.1**（LSD 低位优先）：
1. 从最低位开始，按该位值分配到 0–9 号桶
2. 按桶序收集，形成新序列
3. 对更高位重复，直至最高位

```
radixSort(a, n, d):                      // LSD，稳定
    for k from 0 to d-1:                 // 从低位到高位
        清空 10 个桶
        for each x in a:                 // 分配
            把 x 放入桶 (x / 10^k) % 10
        for b from 0 to 9:               // 收集
            依次把桶 b 中的元素放回 a
```

**定理 6.1**：基数排序时间复杂度为 $O(d(n + r))$，其中 $d$ 为位数、$r$ 为基数。

**推论 6.1**　基数排序是**稳定**的（分配收集不改变同桶内次序），也是链式分配收集稳定的前提。

**注意**　基数排序用于整数或可分解为多关键字的数据，$d$ 较大时可能慢于 $O(n \log n)$。

## 7. 各种内排序的比较

| 排序方法 | 平均 | 最坏 | 最好 | 空间 | 稳定性 | 特点 |
|----------|------|------|------|------|--------|------|
| 直接插入 | $O(n^2)$ | $O(n^2)$ | $O(n)$ | $O(1)$ | 稳定 | 基本有序时快 |
| 希尔排序 | $O(n^{1.3})$ | $O(n^2)$ | $O(n)$ | $O(1)$ | 不稳定 | 增量分组 |
| 冒泡排序 | $O(n^2)$ | $O(n^2)$ | $O(n)$ | $O(1)$ | 稳定 | 简单 |
| 快速排序 | $O(n\log n)$ | $O(n^2)$ | $O(n\log n)$ | $O(\log n)$ | 不稳定 | 实践最快 |
| 简单选择 | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 不稳定 | 交换次数少 |
| 堆排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(1)$ | 不稳定 | 最坏也优 |
| 归并排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(n)$ | 稳定 | 适合链表/外排 |
| 基数排序 | $O(d(n+r))$ | $O(d(n+r))$ | $O(d(n+r))$ | $O(n+r)$ | 稳定 | 非比较排序 |

**推论 7.1**　选择排序算法的依据：数据规模、初始有序程度、稳定性要求、空间限制。

## 8. 外排序

### 8.1 基本思想

**定义 8.1**　**外排序**分两阶段：**内部排序**生成有序归并段（run），**多路归并**合并归并段。

**算法 8.1**：把大文件分成若干可容纳于内存的块，各块内部排序后写回外存，再做多路归并。

### 8.2 多路平衡归并与败者树

**定义 8.2**　**$k$ 路归并**每次选 $k$ 个归并段中的最小者输出。

**定理 8.1**（败者树）：用败者树选最小者，每次比较次数为 $\lceil \log_2 k \rceil$，与 $k$ 无关。

**推论 8.1**　败者树使归并的比较代价只依赖归并路数的对数。

### 8.3 置换—选择排序

**算法 8.2**（置换选择）：利用堆，一次扫描生成平均长度为 $2w$（$w$ 为内存容量）的归并段。

**推论 8.2**　置换选择加长了初始归并段，减少归并趟数。

### 8.4 最佳归并树

**定理 8.2**：把归并段长度作为权，构造 **Huffman 树**，可得 I/O 次数最少的最佳归并树。

**推论 8.3**　外排序的最优归并方案与 Huffman 编码同源——权值大的段靠近根部。

## 9. 应用

### 9.1 系统与工程
- 标准库排序（如 `std::sort` 用内省排序：快排 + 堆排 + 插排）
- 数据库的 `ORDER BY`、大规模数据排序

### 9.2 大数据
- 外排序处理超出内存的数据集
- 分布式排序（MapReduce、外部归并）

### 9.3 相关算法
- Top-K、中位数、第 $k$ 小（快速选择，期望 $O(n)$）
- 逆序对计数（归并排序的副产品）
