# 串与数组

> 字符序列的模式匹配与多维数组的压缩存储。

## 1. 串

### 1.1 串的定义

**定义 1.1**　**串**（字符串）是由零个或多个字符组成的有限序列：

$$S = "a_1 a_2 \cdots a_n"$$

$n$ 为**串长**，$n = 0$ 时为空串。**子串**是串中任意个连续字符组成的子序列。

**定义 1.2**　**主串**是包含子串的串，**子串在主串中的位置**指子串首字符在主串中的序号。

**注意**　空串与空格串不同——空串长度为 0，空格串由空格字符组成。

**推论 1.1**　串是元素为字符的线性表，其特殊性在于整体（子串）操作的语义。

### 1.2 串的存储结构

| 存储方式 | 描述 | 特点 |
|----------|------|------|
| 定长顺序存储 | 用定长数组存放 | 需处理截断 |
| 堆分配存储 | 动态分配字符数组 | 长度灵活，动态扩容 |
| 块链存储 | 每结点存若干字符 | 插入删除灵活，存储密度低 |

**推论 1.2**　块链存储的存储密度 $\approx \frac{\text{字符域大小}}{\text{结点大小}}$，通常低于顺序存储。

## 2. 模式匹配

### 2.1 问题定义

**定义 2.1**　**模式匹配**：在主串 $S$ 中查找子串 $T$（模式串），返回 $T$ 首次出现的位置。

**定义 2.2**　设 $|S| = n$、$|T| = m$。

### 2.2 朴素匹配（BF 算法）

**算法 2.1**（Brute Force）：从 $S$ 的每个位置出发逐个比较，失配则主串指针回退一位重新开始。

```
indexBF(S, T):                           // |S|=n, |T|=m，未找到返回 -1
    i = 0; j = 0
    while i < n and j < m:
        if S[i] == T[j]: i++; j++
        else:            i = i - j + 1; j = 0   // 主串指针回退
    if j == m: return i - m
    return -1
```

**定理 2.1**：BF 算法最坏时间复杂度为 $O(nm)$。

**推论 2.1**　BF 的主要缺陷是失配后主串指针回退，造成重复比较。

### 2.3 KMP 算法

**定义 2.3**　**前缀函数** $\pi[i]$：模式串 $T[0..i]$ 中既是真前缀又是真后缀的最长长度。

$$\pi[i] = \max\{k < i+1 : T[0..k-1] = T[i-k+1..i]\}$$

**定理 2.2**（KMP）：利用 $\pi$ 数组，失配时保持主串指针不回退，仅移动模式串指针：

$$j \leftarrow \pi[j-1] \quad (\text{当 } S[i] \neq T[j])$$

```
getNext(T, next):                        // 求前缀函数，next[0] = -1
    i = 0; j = -1
    while i < len(T):
        if j == -1 or T[i] == T[j]:
            i++; j++; next[i] = j
        else:
            j = next[j]

indexKMP(S, T, next):                    // 匹配，主串指针不回退
    i = 0; j = 0
    while i < n and j < m:
        if j == -1 or S[i] == T[j]: i++; j++
        else:                       j = next[j]
    if j == m: return i - m
    return -1
```

**定理 2.3**：KMP 算法的时间复杂度为 $O(n + m)$。

**推论 2.2**　KMP 的核心思想是：已匹配的部分包含自重复结构，可据此跳过不可能成功的位置。

**定理 2.4**（$\pi$ 数组的递推）：$\pi$ 可在 $O(m)$ 内递推求出——利用 $\pi[i]$ 与 $\pi[i-1]$ 的关系避免重复比较。

| 算法 | 预处理 | 匹配 | 总时间 |
|------|--------|------|--------|
| BF | — | $O(nm)$ | $O(nm)$ |
| KMP | $O(m)$ | $O(n)$ | $O(n + m)$ |

**推论 2.3**　KMP 用 $O(m)$ 的预处理换取线性匹配——预处理与匹配的代价平衡。

### 2.4 其他匹配算法

- **Boyer–Moore**：从右向左比较，坏字符与好后缀规则可跳过多个位置，实践中很快
- **Rabin–Karp**：滚动哈希，平均 $O(n + m)$
- **AC 自动机**：KMP 在多模式串上的推广，基于 Trie 与失配指针

**推论 2.4**　模式匹配的演进体现了"复用已匹配信息"这一通用优化思想。

## 3. 数组

### 3.1 数组的定义

**定义 3.1**　**数组**是下标与数组元素构成一一映射的线性结构；一维数组即顺序表，$n$ 维数组是每个元素为 $n-1$ 维数组的递归结构。

**定理 3.1**：数组是随机存取的——给定下标可 $O(1)$ 定位元素。

**推论 3.1**　数组的随机存取依赖于元素地址与下标的线性映射。

### 3.2 数组的存储映射

**定义 3.2**　**行优先**（C/C++/Python）：按行依次存放；**列优先**（Fortran/MATLAB）：按列依次存放。

**定理 3.2**（行优先寻址）：$m$ 行 $n$ 列的二维数组 $A[i][j]$ 的地址为：

$$\text{LOC}(A[i][j]) = \text{LOC}(A[0][0]) + (i \times n + j) \times c$$

**推论 3.2**　行优先与列优先的寻址公式不同，跨语言移植时需注意存储顺序。

## 4. 矩阵的压缩存储

### 4.1 对称矩阵

**定义 4.1**　**对称矩阵**满足 $a_{ij} = a_{ji}$。只需存储下三角（含对角线）共 $\frac{n(n+1)}{2}$ 个元素。

**定理 4.1**（压缩寻址）：按行优先存储下三角，$a_{ij}$（$i \geq j$）对应一维下标：

$$k = \frac{i(i+1)}{2} + j$$

当 $i < j$ 时，$a_{ij} = a_{ji}$，按上式以 $(j, i)$ 代入。

**推论 4.1**　对称矩阵压缩后空间由 $O(n^2)$ 降为 $O(n^2/2)$。

### 4.2 三角矩阵

**定义 4.2**：
- **上三角矩阵**：对角线以下元素全为常数
- **下三角矩阵**：对角线以上元素全为常数

**推论 4.2**　三角矩阵的压缩方式与对称矩阵类似，常数部分只需存一个。

### 4.3 对角矩阵

**定义 4.3**　**对角矩阵**（带状矩阵）中非零元素集中在主对角线附近的若干条对角线上。

例如三对角矩阵只需存 $3n - 2$ 个元素，寻址公式为 $k = 2i + j$。

### 4.4 稀疏矩阵

**定义 4.4**　**稀疏矩阵**中非零元素个数远少于矩阵元素总数（一般小于 5%）。

**表示方法**：

| 方法 | 结构 | 特点 |
|------|------|------|
| 三元组表 | `(row, col, value)` | 顺序存储，需转置运算 |
| 行逻辑链接 | 三元组 + 各行起始位置 | 加速按行访问 |
| 十字链表 | 每行每列各成链表 | 插入删除灵活 |

**定理 4.2**：三元组表转置可在 $O(\text{cols} + \text{terms})$ 内完成（快速转置）。

```
transpose(A, B):                         // 三元组表快速转置
    for col from 0 to A.cols-1: num[col] = 0
    for each term in A: num[term.col]++
    cp[0] = 0
    for col from 1 to A.cols-1: cp[col] = cp[col-1] + num[col-1]
    for each term in A:                  // 一次扫描定位
        B.data[cp[term.col]] = (term.col, term.row, term.value)
        cp[term.col]++
```

**推论 4.3**　稀疏矩阵的存储把 $O(mn)$ 降为 $O(\text{非零元数})$。

## 5. 广义表

### 5.1 定义

**定义 5.1**　**广义表**是 $n$ 个元素 $a_1, a_2, \ldots, a_n$ 的有限序列，其中 $a_i$ 可以是原子（单元素），也可以是子表。

$$LS = (a_1, a_2, \ldots, a_n)$$

**定义 5.2**：
- **表头** `Head(LS)`：第一个元素 $a_1$
- **表尾** `Tail(LS)`：除表头外的其余元素组成的表

**注意**　表尾一定是广义表，表头可能是原子也可能是子表。

**例 5.1**　$A = (a, (b, c), d)$，则 `Head(A) = a`，`Tail(A) = ((b, c), d)`。

### 5.2 深度与递归性

**定义 5.3**　广义表的**深度**是括号嵌套的最大层数；**长度**是顶层元素个数。

**定理 5.1**：广义表可用头尾链表或扩展线性链表表示，且可递归定义（表可作为自身的元素）。

**推论 5.1**　广义表是线性表的推广——允许元素为表，是树的层次结构的雏形。

**推论 5.2**　广义表的求深度、复制、判等操作天然适合递归实现。

## 6. 应用

### 6.1 文本处理
- KMP/BM 用于编辑器查找、DNA 序列比对
- 正则表达式引擎基于自动机匹配

### 6.2 科学计算
- 稀疏矩阵广泛应用于有限元、图算法、机器学习
- 带状矩阵用于三对角方程组的追赶法

### 6.3 数据表示
- 多维数组是图像、张量数据的基本存储
- 广义表可表示 Lisp 风格的结构化数据
