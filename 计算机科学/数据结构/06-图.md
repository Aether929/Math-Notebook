# 图

> 多对多的关系网络——遍历、最短路、生成树与关键路径。

## 1. 基本概念

### 1.1 图的定义

**定义 1.1**　**图** $G = (V, E)$ 由顶点集 $V$ 和边集 $E$ 组成。$|V| = n$ 为顶点数，$|E| = e$ 为边数。

| 术语 | 含义 |
|------|------|
| 有向图/无向图 | 边是有序对 $(u,v)$ / 无序对 $\{u,v\}$ |
| 完全图 | 任意两点间均有边 |
| 稠密图/稀疏图 | $e$ 接近 / 远小于 $n^2$ |
| 权 | 边上的数值（带权图 = 网） |
| 子图 | 顶点与边均为原图的子集 |

**定义 1.2**：
- **度** $\deg(v)$：与 $v$ 关联的边数（自环计 2）
- **入度/出度**：有向图中指向/离开 $v$ 的弧数
- **路径**：顶点序列，相邻顶点间有边
- **回路（环）**：起点等于终点的路径
- **简单路径**：顶点不重复的路径

**定理 1.1**（握手定理）：$\sum_{v \in V} \deg(v) = 2e$。

**推论 1.1**　无向图中奇度顶点个数为偶数；有向图中 $\sum \deg^+(v) = \sum \deg^-(v) = e$。

### 1.2 连通性

**定义 1.3**：
- **连通图**：无向图中任意两顶点间有路径
- **连通分量**：极大连通子图
- **强连通图**：有向图中任意两点互相可达
- **生成树**：包含全部 $n$ 个顶点的极小连通子图，恰有 $n - 1$ 条边

**定理 1.2**：$n$ 个顶点的连通图至少有 $n - 1$ 条边；若 $e > n - 1$ 则必含回路。

**推论 1.2**　生成树存在 $\iff$ 图连通；非连通图有生成森林。

## 2. 图的存储结构

### 2.1 邻接矩阵

**定义 2.1**　**邻接矩阵** $A = (a_{ij})_{n \times n}$：

$$a_{ij} = \begin{cases} 1, & (v_i, v_j) \in E \\ 0, & \text{否则} \end{cases}$$

带权图则存权值，无边存 $\infty$。

**定理 2.1**：邻接矩阵的空间为 $O(n^2)$，判定两点是否相邻为 $O(1)$；无向图的矩阵对称。

**推论 2.1**　邻接矩阵适合稠密图；稀疏图浪费大量空间。

### 2.2 邻接表

**定义 2.2**　**邻接表**为每个顶点建一个单链表，存储其所有邻接点。

**定理 2.2**：邻接表的空间为 $O(n + e)$；求某顶点的所有邻接点效率高，但判定两点是否相邻需 $O(\deg(v))$。

**推论 2.2**　邻接表适合稀疏图；有向图的逆邻接表便于求入度。

### 2.3 其他存储

| 结构 | 描述 | 适用 |
|------|------|------|
| 十字链表 | 同时存出边与入边链表 | 有向图 |
| 邻接多重表 | 每条边一个结点 | 无向图 |
| 边集数组 | 存所有边 | Kruskal、边遍历 |

**推论 2.3**　存储结构的选择应匹配算法需求——Dijkstra 用邻接矩阵或邻接表，Kruskal 用边集数组。

## 3. 图的遍历

### 3.1 深度优先搜索

**算法 3.1**（DFS）：从起点出发，沿一条路径尽可能深入，不能前进时回溯，用**栈**或递归实现。

```
visited[0..n-1] = false
dfs(u):                                  // 邻接表 DFS
    visit(u); visited[u] = true
    for v in adj[u]:
        if not visited[v]: dfs(v)
```

**定理 3.1**：DFS 的时间复杂度为 $O(n + e)$（邻接表）或 $O(n^2)$（邻接矩阵）。

**推论 3.1**　DFS 的递归深度可达 $O(n)$，需注意栈溢出。

### 3.2 广度优先搜索

**算法 3.2**（BFS）：从起点出发，按层次逐层扩展，用**队列**实现。

```
bfs(s):                                  // 无权图单源最短路
    dist[0..n-1] = INF; dist[s] = 0
    initQueue(Q); enQueue(Q, s)
    while not empty(Q):
        u = deQueue(Q)
        for v in adj[u]:
            if dist[v] == INF:           // 首次到达即最短
                dist[v] = dist[u] + 1
                enQueue(Q, v)
```

**定理 3.2**：BFS 的时间复杂度与 DFS 相同；且 BFS 给出无权图的**最短路径**（边数最少）。

**推论 3.2**　BFS 的层序性质是求无权图单源最短路的依据。

### 3.3 遍历的应用

**定理 3.3**：DFS 可求连通分量、判环、求割点与桥、拓扑排序；BFS 可求最短路、二分图判定。

**推论 3.3**　DFS/BFS 是图算法的两大骨架——许多算法是它们的具体化。

## 4. 最小生成树

### 4.1 问题定义

**定义 4.1**　**最小生成树（MST）** 是带权连通无向图中权值和最小的生成树。

### 4.2 Prim 算法

**算法 4.1**（Prim）：从任一顶点出发，每次选取连接生成树与树外顶点的最小权边，加入树中。

```
prim(G, s):                              // 邻接矩阵，O(n^2)
    dist[] = G[s][*]; S = {s}
    while S != V:
        u = 使 dist[v] 最小的顶点 v ∉ S
        S = S ∪ {u}
        for each v ∉ S:                  // 松弛
            if G[u][v] < dist[v]: dist[v] = G[u][v]
```

**定理 4.1**：Prim 算法的时间复杂度为 $O(n^2)$（邻接矩阵），适合**稠密图**。

**推论 4.1**　Prim 是"加点法"——生成树逐步生长，每次纳入最近顶点。

### 4.3 Kruskal 算法

**算法 4.2**（Kruskal）：把所有边按权值升序排列，依次选取不构成回路的边。

```
kruskal(G):                              // 边集 + 并查集
    sort edges by weight ascending
    for each v: parent[v] = v
    cnt = 0
    for (u, v, w) in edges:
        if find(u) != find(v):           // 两端不同集 → 不成环
            union(u, v); 选入边 (u, v); cnt++
            if cnt == n - 1: break       // 已含 n-1 条边
```

**定理 4.2**：Kruskal 算法的时间复杂度为 $O(e \log e)$，适合**稀疏图**；用并查集判环。

**推论 4.2**　Kruskal 是"加边法"——用并查集维护连通性，判环为 $O(\alpha(n))$。

### 4.4 正确性

**定理 4.3**（割性质）：对任意割 $(S, V \setminus S)$，横跨该割的最小权边属于某棵 MST。

**定理 4.4**（圈性质）：对任意回路，回路中最大权边不属于任何 MST。

**推论 4.3**　Prim 与 Kruskal 均基于割性质/圈性质的贪心——局部最优累积为全局最优。

| 算法 | 时间 | 适用 | 数据结构 |
|------|------|------|----------|
| Prim | $O(n^2)$ | 稠密图 | 邻接矩阵 + 距离数组 |
| Kruskal | $O(e \log e)$ | 稀疏图 | 边集 + 并查集 |

## 5. 最短路径

### 5.1 单源最短路

**定义 5.1**　**单源最短路径**：求源点到其余各顶点的最短路径。

**算法 5.1（Dijkstra）**：贪心式扩展，每次选取距离最小的未确定顶点，松弛其邻接点。

```
dijkstra(G, s):                          // 非负权，O(n^2)
    dist[] = G[s][*]; S = {s}
    while S != V:
        u = 使 dist[v] 最小的顶点 v ∉ S  // 贪心选取
        S = S ∪ {u}
        for each v ∉ S:
            if dist[u] + G[u][v] < dist[v]:      // 松弛
                dist[v] = dist[u] + G[u][v]
```

$$dist[v] = \min(dist[v],\ dist[u] + w(u, v))$$

**定理 5.1**：Dijkstra 的时间复杂度为 $O(n^2)$；用优先队列优化为 $O(e \log n)$。

**注意**　Dijkstra **不适用于负权边**——贪心前提是已确定顶点不再被改进。

**算法 5.2（Bellman–Ford）**：对所有边反复松弛 $n - 1$ 轮。

**定理 5.2**：Bellman–Ford 的时间复杂度为 $O(ne)$，可处理**负权边**，并能检测**负权回路**。

**推论 5.1**　Dijkstra 快但限于非负权；Bellman–Ford 慢但更通用。

### 5.2 各顶点对最短路

**算法 5.3（Floyd–Warshall）**：动态规划，逐步允许中间顶点集扩大：

$$D^{(k)}[i][j] = \min\left(D^{(k-1)}[i][j],\ D^{(k-1)}[i][k] + D^{(k-1)}[k][j]\right)$$

**定理 5.3**：Floyd 算法的时间复杂度为 $O(n^3)$，空间 $O(n^2)$，可处理负权（无负回路）。

**推论 5.2**　Floyd 的 DP 状态含义是"只允许经过前 $k$ 个顶点中转时的最短路"。

### 5.3 算法对比

| 算法 | 问题 | 时间 | 负权 | 负回路检测 |
|------|------|------|------|-----------|
| Dijkstra | 单源 | $O(e \log n)$ | 否 | 否 |
| Bellman–Ford | 单源 | $O(ne)$ | 是 | 是 |
| Floyd | 全源 | $O(n^3)$ | 是 | 是 |

## 6. 有向无环图

### 6.1 拓扑排序

**定义 6.1**　**AOV 网**：以顶点表示活动、弧表示活动间先后关系的有向图。

**定义 6.2**　**拓扑排序**：将 $V$ 中所有顶点排成线性序列，使每条弧的起点都排在终点之前。

**算法 6.1**（Kahn）：重复选取入度为 0 的顶点输出并删除其出边。

```
topoSort(G):
    for each v: indeg[v] = 入度(v)
    initQueue(Q)
    for each v: if indeg[v] == 0: enQueue(Q, v)
    while not empty(Q):
        u = deQueue(Q); output(u)
        for v in adj[u]:
            if --indeg[v] == 0: enQueue(Q, v)
    if 输出顶点数 < n: 存在有向环          // 无拓扑序
```

**定理 6.1**：AOV 网存在拓扑排序 $\iff$ 无有向回路；Kahn 算法的时间复杂度为 $O(n + e)$。

**推论 6.1**　拓扑排序可用于判断依赖关系是否可行（如课程安排、构建顺序）。

### 6.2 关键路径

**定义 6.3**　**AOE 网**：以顶点表示事件、弧表示活动及其持续时间的有向带权图。

**定义 6.4**：
- 从源点到汇点的最长路径称**关键路径**，其上活动称**关键活动**
- 活动 $a$ 的**最早开始时间** $e(a)$ 与**最迟开始时间** $l(a)$

**定理 6.2**：活动 $a$ 是关键活动 $\iff e(a) = l(a)$（时间余量为 0）。

**推论 6.2**　关键路径决定工程总工期——缩短关键活动才能缩短工期。

**推论 6.3**　求关键路径需先拓扑排序，再按逆拓扑序计算各顶点的最早/最迟时间，时间复杂度 $O(n + e)$。

## 7. 其他经典算法

| 问题 | 算法 | 复杂度 |
|------|------|--------|
| 强连通分量 | Tarjan / Kosaraju | $O(n + e)$ |
| 二分图匹配 | 匈牙利算法 / Hopcroft–Karp | $O(ne)$ / $O(e\sqrt{n})$ |
| 网络最大流 | Ford–Fulkerson / Dinic | $O(e \cdot f)$ / $O(n^2 e)$ |
| 割点与桥 | Tarjan | $O(n + e)$ |

**推论 7.1**　最大流最小割定理（见 [离散数学 §2 图论基础](../../其他/离散数学/02-图论基础.md)）是网络优化的核心对偶性。

**定理 7.1**：$\sum_{v \in V} \deg(v) = 2e$ 与遍历的 $O(n+e)$ 复杂度共同说明——图算法的时间下界由顶点和边共同决定。

## 8. 应用

### 8.1 网络与通信
- 路由算法（最短路）、网络可靠性（生成树）
- 最大流用于流量调度、二分图匹配

### 8.2 工程与项目
- 拓扑排序用于任务调度与依赖解析
- 关键路径用于项目工期优化（PERT/CPM）

### 8.3 计算机科学
- 编译器的数据流分析、调用图分析
- 社交网络分析、网页排名（PageRank 基于图迭代）
