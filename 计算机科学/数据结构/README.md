## 学习路线

```
绪论与算法分析 → 线性表 → 栈与队列 → 串与数组
                  ↓
              树与二叉树 → 图 → 查找 → 排序
                  ↓
            算法设计与分析（复杂度、正确性、稳定性）
```

## 知识框架

```
数据结构
├── 线性结构        线性表、栈、队列、串
├── 非线性结构      树、图
└── 操作
    ├── 查找        静态查找、动态查找、散列
    └── 排序        内排序、外排序
```

## 笔记约定

- **理论** → **定义/定理/推论** → **伪代码块**：核心算法附伪代码，与正文定理编号对应
- 伪代码为**中立的算法描述**（非特定语言），使用 `=` 赋值、缩进表示嵌套、`O(...)` 标注复杂度
- 只给**核心片段**，省略输入输出与边界样板；完整实现可据此改写为 C/Python

## 与其他分支的联系

- **离散数学**：图论、集合与关系是数据结构的形式基础
- **运筹学**：最短路、最小生成树、网络流是图算法的直接应用
- **最优化理论**：贪心与动态规划策略贯穿图算法设计
- **代数学**：多项式与矩阵运算对应串与数组的存储结构
- **算法分析**：递归式的求解依赖 [离散数学 §4 递推关系](../../其他/离散数学/04-递推关系.md)
